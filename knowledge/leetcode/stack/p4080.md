## 题目

给定一个经过编码的字符串 `s`，请按照指定规则对字符串进行解码，并返回解码后的结果。

编码规则为 `k[encoded_string]`，表示将方括号内部的字符串重复 `k` 次，其中 `k` 为正整数。

编码字符串可能包含多层嵌套，需要从内向外逐层解码。

**输入格式**

输入一个字符串 `s`，表示经过编码的字符串。

**输出格式**

输出解码后的字符串。

**输入示例**

```text
3[a]2[bc]
```

**输出示例**

```text
aaabcbc
```

**另一个示例**

```text
3[a2[c]]
```

**输出示例**

```text
accaccacc
```

**说明**

对于 `3[a2[c]]`：

-   `2[c]` 解码为 `cc`。
-   `a2[c]` 解码为 `acc`。
-   `3[acc]` 解码为 `accaccacc`。

**注意**

-   输入字符串保证合法，方括号正确匹配。
-   重复次数 `k` 可能是多位整数。
-   原始字符串不包含数字，数字仅用于表示重复次数。
-   字符串可以包含嵌套编码。

## 思路

-   遍历字符串，将字符依次加入栈 `stack`。
-   遇到 `]`时，持续弹出字符直到 `[`，反转得到括号内的字符串。
-   继续弹出数字字符，反转得到重复次数 `num`，支持多位整数。
-   将字符串重复 `num`次后重新入栈，最终拼接栈中所有元素。

## 代码

```python
class Solution:
    def decodeString(self, s: str) -> str:
        stack = []
        for i in range(len(s)):
            ch = s[i]
            if ch == ']':
                tmp = []
                while stack and stack[-1] != '[':
                    tmp.append(stack.pop())

                stack.pop()
                num_stack = []
                while stack and stack[-1].isdigit():
                    num_stack.append(stack.pop())
                num =  ''.join(num_stack)
                num = num[::-1]
                num = int(num)

                tmp_s = []
                while tmp:
                    tmp_s.append(tmp.pop())

                tmp_s = ''.join(tmp_s)
                tmp_s *= num
                stack.append(tmp_s)

            else:
                stack.append(ch)

        return ''.join(stack)
```
