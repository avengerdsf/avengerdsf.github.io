## 题目

给定一个由非负整数组成的数组 `heights`，其中每个元素表示柱状图中一根柱子的高度，每根柱子的宽度均为 `1`。

请计算在该柱状图中，能够构成的最大矩形面积。

要求矩形必须由**连续的柱子**组成，矩形高度不能超过所覆盖柱子中的最小高度。

**输入格式**

第一行输入一个整数 `n`，表示柱子的数量。

第二行输入 `n` 个非负整数，表示数组 `heights`。

**输出格式**

输出一个整数，表示柱状图中的最大矩形面积。

**输入示例**

```text
6
2 1 5 6 2 3
```

**输出示例**

```text
10
```

**说明**

选择高度为 `5` 和 `6` 的两根相邻柱子：

```text
高度 = min(5, 6) = 5
宽度 = 2
面积 = 5 × 2 = 10
```

因此最大矩形面积为 `10`。

## 思路

-   初始化：建立单调递增栈，栈中存储柱子下标，用 `-1`作为左边界，并在末尾虚拟添加高度为 `0`的柱子，确保所有柱子完成计算。
-   遍历柱子：当前高度小于等于栈顶时，弹出栈顶，计算对应矩形面积。
-   计算面积：弹出后，栈顶为左边界，`i`为右边界，宽度为 `i - left - 1`，不断更新最大面积。

## 代码

```python
class Solution:
    def largestRectangleArea(self, heights) -> int:
        stacks = [-1]
        ans = -1
        for i in range(len(heights) + 1):
            val = heights[i] if i < len(heights) else 0
            while stacks[-1] != -1 and heights[stacks[-1]] >= val:
                k = stacks.pop()
                h = heights[k]
                left = stacks[-1]

                width = i - left - 1
                ans = max(ans, h * width)
            stacks.append(i)
        return ans
```
