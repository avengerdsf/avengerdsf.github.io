## 题目

请设计一个栈，支持普通栈的压入、弹出、获取栈顶元素操作，并且能够在常数时间内查询栈中的最小元素。

要求以下所有操作的时间复杂度均为 `O(1)`：

-   `push(val)`：将元素 `val` 压入栈中。
-   `pop()`：删除栈顶元素。
-   `top()`：获取栈顶元素。
-   `getMin()`：获取栈中的最小元素。

**输入格式**

第一行输入一个整数 `m`，表示操作次数。

接下来输入 `m` 行，每行表示一次操作：

```text
push val
pop
top
getMin
```

**输出格式**

对于每次 `top` 和 `getMin` 操作，输出对应的查询结果。

**输入示例**

```text
7
push -2
push 0
push -3
getMin
pop
top
getMin
```

**输出示例**

```text
-3
0
-2
```

**说明**

依次执行：

-   `push(-2)`：栈为 `[-2]`。
-   `push(0)`：栈为 `[-2, 0]`。
-   `push(-3)`：栈为 `[-2, 0, -3]`。
-   `getMin()`：当前最小值为 `-3`。
-   `pop()`：删除栈顶元素 `-3`。
-   `top()`：当前栈顶元素为 `0`。
-   `getMin()`：当前最小值为 `-2`。

**数据范围**

-   `-2^31 <= val <= 2^31 - 1`
-   操作次数不超过 `30000`
-   `pop`、`top` 和 `getMin` 操作保证在非空栈上执行。

## 思路

-   使用两个栈：`cache`存储所有元素，`min_stack`存储历史最小值。
-   `push`：元素加入 `cache`，若 `val <= min_stack[-1]`，则同时加入 `min_stack`。
-   `pop`：弹出 `cache`栈顶，若等于当前最小值，则同时弹出 `min_stack`栈顶。
-   `top`：返回 `cache[-1]`；`getMin`：返回 `min_stack[-1]`。

## 代码

```python
class MinStack:
    def __init__(self):
        self.cache = []
        self.min_stack = []

    def push(self, val: int) -> None:
        self.cache.append(val)

        if not self.min_stack or val <= self.min_stack[-1]:
            self.min_stack.append(val)

    def pop(self) -> None:
        if self.cache:
            top_element = self.cache.pop()

            if top_element == self.min_stack[-1]:
                self.min_stack.pop()

    def top(self) -> int:
        if self.cache:
            return self.cache[-1]
        return -1

    def getMin(self) -> int:
        return self.min_stack[-1]

def main():
    # 读取操作次数
    q = int(input().strip())

    # 创建最小栈对象
    stack = MinStack()

    # 依次处理每个操作
    for _ in range(q):
        parts = input().split()
        op = parts[0]

        if op == "push":
            stack.push(int(parts[1]))
        elif op == "pop":
            stack.pop()
        elif op == "top":
            print(stack.top())
        elif op == "getMin":
            print(stack.getMin())

if __name__ == "__main__":
    main()
```
