## 题目

给定一个长度为 `n` 的整数数组 `nums`，请判断数组中是否存在三个下标 `i、j、k`，满足：

-   `i < j < k`
-   `nums[i] < nums[k] < nums[j]`

如果存在这样的三元组，则称数组中存在一个 **132 模式**。

请判断数组中是否存在 132 模式。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个整数，表示数组 `nums`。

**输出格式**

如果存在 132 模式，输出：

```text
true
```

否则输出：

```text
false
```

**输入示例**

```text
4
3 1 4 2
```

**输出示例**

```text
true
```

**说明**

选择下标 `i = 1`、`j = 2`、`k = 3`，对应的元素为：

```text
1 4 2
```

满足：

```text
1 < 2 < 4
```

因此存在 132 模式。

**另一个示例**

```text
4
1 2 3 4
```

**输出示例**

```text
false
```

**说明**

数组严格递增，不存在满足条件的 132 模式。

## 思路

-   从左往右遍历，`i` 记录当前最小值的下标，作为 `132` 中的 `1`。
-   维护单调递减栈，存储 `(j, i)`，其中 `j` 是候选 `3` 的下标，`i` 是 `j` 左侧最小值的下标。
-   把当前 `idx` 当作 `2`，先弹出所有 `nums[j] <= nums[idx]` 的候选，保证剩余栈顶满足 `nums[j] > nums[idx]`。
-   如果栈顶保存的 `i` 还满足 `nums[i] < nums[idx]`，就找到了 `132`；否则将 `(idx, i)` 入栈，作为后续的候选。

## 代码

```python
class Solution:
    def find132pattern(self, nums: List[int]) -> bool:
        i = 0
        stack = []
        for idx in range(len(nums)):
            if nums[i] > nums[idx]:
                i = idx

            while stack and nums[stack[-1][0]] <= nums[idx]:
                stack.pop()

            if stack and nums[stack[-1][1]] < nums[idx]:
                return True

            stack.append((idx, i))

        return False
```
