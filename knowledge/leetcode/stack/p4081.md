## 题目

给定一个整数数组 `temperatures`，表示每天的温度。

请返回一个数组 `answer`，其中 `answer[i]` 表示第 `i` 天需要等待多少天，才能遇到比当天温度更高的一天。

如果之后没有更高的温度，则对应位置填 `0`。

**输入格式**

第一行输入一个整数 `n`，表示温度数组的长度。

第二行输入 `n` 个整数，表示每天的温度。

**输出格式**

输出一个长度为 `n` 的整数数组，表示每天需要等待多少天才能遇到更高温度。

**输入示例**

```text
8
73 74 75 71 69 72 76 73
```

**输出示例**

```text
1 1 4 2 1 1 0 0
```

**说明**

-   温度为 `73` 的第 1 天，等待 `1` 天后遇到更高温度 `74`。
-   温度为 `75` 的第 3 天，等待 `4` 天后遇到更高温度 `76`。
-   温度为 `76` 的第 7 天，之后没有更高温度，因此结果为 `0`。

**数据范围**

-   `1 <= n <= 100000`
-   `30 <= temperatures[i] <= 100`

## 思路

-   维护单调递减栈，栈中存储尚未找到更高温度的日期下标。
-   当当前温度 `val > temperatures[stack[-1]]`时，弹出栈顶，计算 `i - stack[-1]`作为等待天数（弹出前计算）。
-   当前下标入栈，继续寻找后续更高温度；最终未弹出的下标保持结果为 `0`。

## 代码

```python
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        stack = []
        res = [0] * len(temperatures)

        for i in range(len(temperatures)):
            val = temperatures[i]
            while stack and temperatures[stack[-1]] < val:
                res[stack[-1]] = i - stack[-1]
                stack.pop()  # 修改：直接弹出，不再放回栈中

            stack.append(i)

        return res
```
