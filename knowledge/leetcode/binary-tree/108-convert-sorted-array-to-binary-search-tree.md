题目：[LeetCode 108 · 将有序数组转换为二叉搜索树](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)。给定严格递增的数组 `nums`，构造一棵高度平衡的二叉搜索树，返回根节点。

**核心思路：取中间元素作为根，左半部分递归建左子树，右半部分递归建右子树。**

## 二叉搜索树是什么

对于每一个节点，**左子树中的所有值都小于它，右子树中的所有值都大于它**，左右子树也要满足同样的规则。比较的是整棵子树，不只是直接相连的两个孩子。这里采用力扣的严格大小关系，不允许重复值，参见 [LeetCode 98 的定义](https://leetcode.cn/problems/validate-binary-search-tree/)。

例如，下面是你的代码根据 `[-10, -3, 0, 5, 9]` 建出的树：

```text
        0
       / \
    -10   5
       \   \
       -3   9
```

对根节点 `0`，左子树的 `-10、-3` 都小于 `0`，右子树的 `5、9` 都大于 `0`。对节点 `-10`，它的右孩子 `-3` 大于 `-10`；对节点 `5`，它的右孩子 `9` 大于 `5`。每个节点都符合要求，所以这是一棵二叉搜索树。

**高度平衡是另一项要求：每个节点的左右子树高度差都不能超过 1。** 上面根节点两侧的子树高度相同；`-10` 和 `5` 都是一侧为空、另一侧有一个叶子节点，高度差为 `1`，也满足平衡。二叉搜索树并不天然平衡，本题要求两者同时满足。

下面这棵树则不是二叉搜索树：

```text
        5
       / \
      1   6
         / \
        3   7
```

`3` 是 `6` 的左孩子，`3 < 6` 这一项没有错。但 `3` 同时位于 `5` 的右子树中，还必须满足 `3 > 5`。它不满足，所以整棵树不合法。**只检查每个节点与直接孩子的大小关系是不够的。**

## 递归建树的过程

`dfs(l, r)` 表示：用数组下标闭区间 `[l, r]` 中的元素建树，返回这棵子树的根节点。

以这组 ACM 输入为例，第一行的 `5` 是数组长度，第二行才是待转换的数组，不是树的层序表示：

```text
5
-10 -3 0 5 9
```

先调用 `dfs(0, 4)`，`mid = 2`，选中 `nums[2] = 0` 作为整棵树的根。接下来按代码顺序，先构造左子树，再构造右子树。

左边调用 `dfs(0, 1)`，`mid = 0`，选中 `-10`。它左侧的区间 `[0, -1]` 为空，返回 `None`；右侧的区间 `[1, 1]` 只有 `-3`，建出叶子节点 `-3`。随后返回以 `-10` 为根、右孩子为 `-3` 的子树。

右边调用 `dfs(3, 4)`，`mid = 3`，选中 `5`。它左侧的区间 `[3, 2]` 为空，返回 `None`；右侧的区间 `[4, 4]` 只有 `9`，建出叶子节点 `9`。随后返回以 `5` 为根、右孩子为 `9` 的子树。

两棵子树都返回后，`TreeNode(self.nums[mid], left, right)` 创建节点 `0`，并把它们接到左右两侧，得到上面的合法示例。你的层序输出函数会输出：

```text
0 -10 5 null -3 null 9
```

数组有序，保证左半部分的值小于当前根、右半部分的值大于当前根；每一层都从中间划分，使左右两部分的元素数量最多相差一个，递归建出的树也就满足高度平衡。

## 关键代码

保留原来的 `Solution`、变量名和递归写法。`TreeNode` 由 LeetCode 的题目模板提供，输入读取和层序输出不是建树算法的一部分。

```python
class Solution:
    def __init__(self):
        self.nums = None

    def sortedArrayToBST(self, nums):
        self.nums = nums
        return self.dfs(0, len(nums) - 1)

    def dfs(self, l, r):
        # 区间为空，返回 None
        if l > r:
            return

        # 选取当前区间的中间元素
        mid = (l + r) // 2

        # 分别构建左右子树，不再包含已经选中的 mid
        left = self.dfs(l, mid - 1)
        right = self.dfs(mid + 1, r)

        # 创建当前根节点，并连接左右子树
        return TreeNode(self.nums[mid], left, right)
```

`left` 和 `right` 保存的是递归返回的子树根节点，不是数组或下标。`l > r` 才表示没有元素；`l == r` 时仍然需要创建一个节点，不能直接结束。

`(l + r) // 2` 在区间长度为偶数时选靠左的中点，所以这里建出的左子树以 `-10` 为根、右子树以 `5` 为根。选择靠右的中点也可以得到合法答案，树形不必与题目展示的答案完全一致。

每个元素只创建一个节点，时间复杂度为 `O(n)`；递归栈的额外空间为 `O(log n)`。另外，返回的树本身占用 `O(n)` 空间。
