## 题目

给定一棵二叉树的根节点 `root`，请计算二叉树中任意两个节点之间的最长路径长度。

两个节点之间的路径不一定经过根节点。

路径长度按照路径上经过的边数计算。

**输入格式**

输入一棵二叉树的层序遍历序列，其中 `null` 表示空节点。

**输出格式**

输出一个整数，表示二叉树中两个节点之间的最长路径长度。

**输入示例**

```text
1 2 3 4 5
```

**输出示例**

```text
3
```

**说明**

对应的二叉树为：

```text
        1
       / \
      2   3
     / \
    4   5
```

最长路径可以是：

```text
4 -> 2 -> 1 -> 3
```

一共经过 `3` 条边，因此答案为 `3`。

## 思路

-   用 DFS 分别求当前节点**左子树和右子树的最大深度**。
-   经过当前节点的最长路径节点数为 `left + right + 1`。
-   用 `self.max_len` 记录所有节点中出现过的**最大路径节点数**。
-   DFS 向上返回当前节点的最大深度，即 `max(left, right) + 1`。
-   最后因为题目按**边数**计算长度，所以返回 `self.max_len - 1`

## 代码

```python
class Solution:
    def __init__(self):
        self.max_len = 0

    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        self.dfs(root)
        return self.max_len - 1

    def dfs(self, node):
        if not node:
            return 0

        right = self.dfs(node.right)
        left = self.dfs(node.left)

        cur_node = max(left, right) + 1
        max_len = max(cur_node, left + right + 1)
        self.max_len = max(self.max_len, max_len)

        return cur_node
```
