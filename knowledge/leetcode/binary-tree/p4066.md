## 题目

给定一棵二叉树的根节点 `root`，以及树中的两个节点 `p` 和 `q`，请找到它们的最近公共祖先。

最近公共祖先是指：同时是 `p` 和 `q` 的祖先，并且距离它们最近的那个节点。

一个节点也可以是它自己的祖先。

**输入格式**

第一行输入一棵二叉树的层序遍历序列，其中 `null` 表示空节点。

第二行输入节点 `p` 的值。

第三行输入节点 `q` 的值。

**输出格式**

输出 `p` 和 `q` 的最近公共祖先节点值。

**输入示例**

```text
3 5 1 6 2 0 8 null null 7 4
5
1
```

**输出示例**

```text
3
```

**说明**

对应的二叉树为：

```text
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4
```

节点 `5` 和节点 `1` 的最近公共祖先为 `3`。

## 思路

-   使用 **DFS 中序遍历**，统计当前子树中包含 `p`、`q` 的数量 `cnt`。
-   当前节点是 `p` 或 `q` 时，`cnt += 1`，并累加左右子树返回的数量。
-   左右子树都统计完成后，第一次出现 `cnt == 2` 的节点就是最近公共祖先。
-   将当前 `cnt` 返回给父节点继续统计。

## 代码

```python
class Solution:
    def __init__(self):
        self.q = None
        self.p = None
        self.res = None

    def lowestCommonAncestor(self, root, p, q):
        self.p = p
        self.q = q
        self.dfs(root)
        return self.res

    def dfs(self, node):
        if not node:
            return 0

        cnt = 0
        cnt += self.dfs(node.left)
        if node == self.q or node == self.p:
            cnt += 1
        cnt += self.dfs(node.right)

        if not self.res and cnt == 2:
            self.res = node

        return cnt
```
