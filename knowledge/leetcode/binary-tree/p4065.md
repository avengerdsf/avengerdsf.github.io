## 题目

给定一棵二叉树的根节点 `root` 和一个整数 `targetSum`。

请统计二叉树中路径和等于 `targetSum` 的路径数量。

路径不要求从根节点开始，也不要求在叶子节点结束，但是路径必须沿着父节点到子节点的方向向下连续经过。

**输入格式**

第一行输入一棵二叉树的层序遍历序列，其中 `null` 表示空节点。

第二行输入一个整数 `targetSum`。

**输出格式**

输出路径和等于 `targetSum` 的路径数量。

**输入示例**

```text
10 5 -3 3 2 null 11 3 -2 null 1
8
```

**输出示例**

```text
3
```

**说明**

满足路径和为 `8` 的路径共有 `3` 条。

路径可以从任意节点开始，但必须保持：

```text
父节点 -> 子节点 -> 子节点 ...
```

即只能沿树向下连续移动。

## 思路

-   外层 `dfs`：把**每一个节点都当作路径起点**，逐个尝试。
-   内层 `findTarget`：从当前起点开始，只沿**父 → 子方向**继续向左或向右累加路径和。
-   每走到一个节点就更新 `cur_sum`，如果 `cur_sum == targetSum`，答案加 `1`。
-   因为每个节点都会被当作起点，所以可以覆盖**不一定从根节点开始**的所有合法路径。

## 代码

```python
class Solution:
    def __init__(self):
        self.target_sum = None
        self.cnt = 0

    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> int:
        self.target_sum = targetSum
        self.dfs(root)
        # 在这里实现
        return self.cnt

    def dfs(self, node):
        if not node:
            return

        self.findTarget(node, 0)

        self.dfs(node.left)
        self.dfs(node.right)
        

    def findTarget(self, node, cur_sum):
        if not node:
            return

        cur_sum += node.val

        if cur_sum == self.target_sum:
            self.cnt += 1

        self.findTarget(node.left, cur_sum)
        self.findTarget(node.right, cur_sum)
```
