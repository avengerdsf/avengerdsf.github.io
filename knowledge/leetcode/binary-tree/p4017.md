## 题目

给定一棵二叉树的根节点 `root`，请按照中序遍历的顺序返回所有节点的值。

中序遍历的顺序为：

```text
左子树 -> 根节点 -> 右子树
```

**输入格式**

输入一棵二叉树的层序遍历序列，其中 `null` 表示空节点。

**输出格式**

输出二叉树的中序遍历结果，节点值之间用空格分隔。

**输入示例**

```text
1 null 2 3
```

**输出示例**

```text
1 3 2
```

**说明**

对应的二叉树为：

```text
1
 \
  2
 /
3
```

按照中序遍历：

```text
左子树 -> 根节点 -> 右子树
```

得到：

```text
1 3 2
```

## 思路

使用 **DFS 递归中序遍历**，按照 **左子树 → 根节点 → 右子树** 的顺序访问节点，并把节点值依次加入 `res`。

## 代码

```python
def inorderTraversal(root):
    res = []
    dfs(root, res)
    return res

def dfs(child_node, res):
    if not child_node:
        return

    dfs(child_node.left, res)
    res.append(child_node.val)
    dfs(child_node.right, res)

```
