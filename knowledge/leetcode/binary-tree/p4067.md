## 题目

给定一棵二叉树的根节点 `root`，请找出其中任意一条路径，使路径上的节点值之和最大，并返回这个最大路径和。

路径可以从任意节点开始，也可以在任意节点结束，但同一个节点在一条路径中最多只能出现一次。

路径不一定经过根节点。

**输入格式**

输入一棵二叉树的层序遍历序列，其中 `null` 表示空节点。

**输出格式**

输出一个整数，表示二叉树中的最大路径和。

**输入示例**

```text
-10 9 20 null null 15 7
```

**输出示例**

```text
42
```

**说明**

对应的二叉树为：

```text
      -10
      /  \
     9   20
        /  \
       15   7
```

最大路径为：

```text
15 -> 20 -> 7
```

路径和为：

```text
15 + 20 + 7 = 42
```

## 思路

-   递归获取左右子树的最大向下路径和。
-   用 `left_max + node.val + right_max` 更新全局最大路径和。
-   返回父节点时路径不能分叉，所以返回 `max(left_max, right_max) + node.val`。

## 代码

```python
class Solution:
    def __init__(self):
        self.max_len = -10 * 18

    def maxPathSum(self, root):
        self.dfs(root)
        return self.max_len

    def dfs(self, node):
        if not node:
            return 0

        left_max = max(self.dfs(node.left), 0)
        right_max = max(self.dfs(node.right), 0)

        self.max_len = max((left_max + right_max + node.val), self.max_len)

        return max(max(left_max, right_max) + node.val, node.val)
```

## 注意点

-   左右子树的路径和**只有大于** `0` **才会对最大路径产生正贡献**，否则按 `0` 处理。
