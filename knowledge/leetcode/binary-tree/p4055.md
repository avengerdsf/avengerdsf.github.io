## 题目

给定一棵二叉树的根节点 `root`，请判断这棵二叉树是否关于中心轴对称。

如果一棵树的左子树和右子树互为镜像，则这棵树是轴对称的。

**输入格式**

输入一棵二叉树的层序遍历序列，其中 `null` 表示空节点。

**输出格式**

如果二叉树是轴对称的，输出：

```text
true
```

否则输出：

```text
false
```

**输入示例**

```text
1 2 2 3 4 4 3
```

**输出示例**

```text
true
```

**说明**

对应的二叉树为：

```text
        1
      /   \
     2     2
    / \   / \
   3   4 4   3
```

左子树和右子树互为镜像，因此该二叉树是轴对称的。

## 思路

从根节点的左右子树开始递归比较，两个节点都为空则对称，只有一个为空则不对称；否则先判断**当前节点值是否相等**，再分别比较 `a.left` **和** `b.right`、`a.right` **和** `b.left`，两组都对称才返回 `True`。

## 代码

```python
class Solution:
    def isSymmetric(self, root):
        return self.dfs(root.right, root.left)

    def dfs(self, a, b):
        if not a and not b:
            return True
        elif not a or not b:
            return False

        is_symmetric = self.dfs(a.left, b.right) and self.dfs(b.left, a.right)

        is_symmetric = a.val == b.val and is_symmetric

        return is_symmetric

```

## 注意点

-   不能判断左右子树**各自是否对称**，而要判断它们是否**互为镜像**。
-   不能只比较 `node.left.val == node.right.val`，还要继续比较**更深层的镜像位置**。
-   镜像对应关系是 **左的左** **↔** **右的右，左的右** **↔** **右的左**。
