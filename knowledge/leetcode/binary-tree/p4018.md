## 题目

给定一棵二叉树的层序遍历序列，请计算这棵二叉树的最大深度。

二叉树的最大深度是指从根节点到最远叶子节点所经过的节点数。

**输入格式**

输入一棵二叉树的层序遍历序列，其中 `null` 表示空节点。

**输出格式**

输出一个整数，表示二叉树的最大深度。

**输入示例**

```text
3 9 20 null null 15 7
```

**输出示例**

```text
3
```

**说明**

对应的二叉树为：

```text
    3
   / \
  9  20
     /  \
    15   7
```

从根节点到最深叶子节点共有 `3` 层，因此最大深度为 `3`。

## 思路

使用 **DFS** 遍历二叉树，每向下一层就 `cnt += 1`；当遇到空节点时，用当前 `cnt`更新最大深度** `**max_len`，最后返回最大值

## 代码

```python
class Solution:
    def __init__(self):
        self.max_len = 0

    def maxDepth(self, root):
        self.dfs(root, 0)
        return self.max_len
    
    def dfs(self, node, cnt):
        if not node:
            self.max_len = max(self.max_len, cnt)
            return

        cnt += 1
        self.dfs(node.left, cnt)
        self.dfs(node.right, cnt)
```
