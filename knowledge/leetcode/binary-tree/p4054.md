## 题目

给定一棵二叉树的根节点 `root`，请将这棵二叉树进行镜像翻转，并返回翻转后的根节点。

镜像翻转是指：对于树中的每个节点，交换它的左子树和右子树。

**输入格式**

输入一棵二叉树的层序遍历序列，其中 `null` 表示空节点。

**输出格式**

输出镜像翻转后的二叉树层序遍历结果。

**输入示例**

```text
4 2 7 1 3 6 9
```

**输出示例**

```text
4 7 2 9 6 3 1
```

**说明**

原二叉树：

```text
        4
      /   \
     2     7
    / \   / \
   1   3 6   9
```

镜像翻转后：

```text
        4
      /   \
     7     2
    / \   / \
   9   6 3   1
```

## 思路

使用 **DFS 后序遍历**，先递归处理左子树和右子树，再执行 `node.left, node.right = node.right, node.left`，把当前节点的左右子树交换，最终整棵树完成镜像翻转。

## 代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def invertTree(self, root):
        self.dfs(root)
        return root

    def dfs(self, node):
        if not node:
            return

        self.dfs(node.left)
        self.dfs(node.right)

        node.left, node.right = node.right, node.left
```
