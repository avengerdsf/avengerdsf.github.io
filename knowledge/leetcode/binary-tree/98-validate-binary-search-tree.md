## 题目

**题目链接：** [LeetCode 98 · 验证二叉搜索树](https://leetcode.cn/problems/validate-binary-search-tree/description/?envType=study-plan-v2&envId=top-100-liked)

给定二叉树的根节点 `root`，判断整棵树是否满足二叉搜索树的规则，返回 `true` 或 `false`。

对每个节点，左子树中的**所有节点值都必须严格小于它**，右子树中的**所有节点值都必须严格大于它**；左右子树也要满足同样的规则。不能只比较当前节点和直接孩子，也不允许重复值。

本题不要求高度平衡，与第 108 题的要求不同。

**示例 1**

```text
输入：root = [2,1,3]
输出：true

    2
   / \
  1   3
```

`1 < 2 < 3`，左右两侧都是叶子节点，整棵树满足要求。

**示例 2**

```text
输入：root = [5,1,4,null,null,3,6]
输出：false

    5
   / \
  1   4
     / \
    3   6
```

节点 `4` 位于 `5` 的右子树中，却小于 `5`，因此不是二叉搜索树。

**数据范围**

```text
1 <= 节点数量 <= 10000
-2^31 <= Node.val <= 2^31 - 1
```

题目中的数组表示树的层序结构，`null` 表示空位置，不是需要排序的数组。

**ACM 输入输出**

你的完整程序直接读取以空格分隔的层序数据，**不需要先输入节点数量**，也不带方括号和逗号。例如：

```text
输入：
5 1 4 null null 3 6

输出：
false
```

## 解答

**核心思路：每个节点带着允许的上下界向下递归，检查它是否满足 `lower < root.val < upper`。**

根节点的初始范围是负无穷到正无穷。进入右子树，把下界收紧为当前节点值，保留原上界；进入左子树，把上界收紧为当前节点值，保留原下界。这样既检查了父节点的要求，也没有丢掉祖先节点的限制。

### 关键代码

保留你的变量名和先右后左的递归顺序。`TreeNode` 使用 LeetCode 提供的定义；输入读取、层序建树和结果打印不属于判断算法。

```python
class Solution:
    def isValidBST(self, root, lower=float("-inf"), upper=float("inf")):
        if not root:
            return True

        # 当前节点必须位于允许的上下限之间
        if not lower < root.val < upper:
            return False

        right_node = root.right
        left_node = root.left

        return (
            self.isValidBST(right_node, root.val, upper)
            and self.isValidBST(left_node, lower, root.val)
        )
```

### 上下界怎样传递

先看示例 1。节点 `2` 在 `(-inf, inf)` 中；随后先检查右孩子 `3`，允许范围是 `(2, inf)`，通过；它的两个空孩子都返回 `True`。再检查左孩子 `1`，允许范围是 `(-inf, 2)`，也通过，它的两个空孩子同样返回 `True`。左右子树都通过，最终返回 `True`。

再看一个**自拟反例**，说明为什么不能只比较父子节点：

```text
输入：root = [5,1,6,null,null,3,7]
输出：false

    5
   / \
  1   6
     / \
    3   7
```

节点 `3` 小于父节点 `6`，符合“左孩子小于父节点”。但它还位于 `5` 的右子树中，必须大于 `5`，这一点不满足。

按你的代码顺序，先检查根节点 `5`，范围是 `(-inf, inf)`，通过。进入右子树的节点 `6`，范围变为 `(5, inf)`，也通过。

接着先检查 `6` 的右孩子 `7`，范围是 `(6, inf)`。`7` 通过，两个空孩子返回 `True`，这一支返回 `True`。

然后检查 `6` 的左孩子 `3`。这次保留原来的下界 `5`，把上界收紧为 `6`，所以必须满足 `5 < 3 < 6`。条件不成立，立即返回 `False`。

这个 `False` 从节点 `6` 传回节点 `5`。根节点处的 `and` 已经得到右子树为 `False`，不会继续检查左子树的节点 `1`，整棵树返回 `False`。

**关键就在于：从 `6` 走向左孩子时，传入的是 `(5, 6)`，不是 `(-inf, 6)`。下界 `5` 保留下来，才能发现对祖先节点的违反。**

### 易错点与复杂度

必须使用严格不等号。自拟用例 `[2,2,3]` 应返回 `False`，左孩子不能与根节点相等。

空节点返回 `True`，表示这一侧没有违反规则，不是说整棵树已经通过。`and` 两侧必须都为 `True`，当前子树才通过；左边表达式一旦为 `False`，右边表达式就不再执行。这里表达式左边写的是右子树，所以代码先查右子树。

初始边界使用正负无穷，不能直接把题目允许的最小、最大整数作为严格边界，否则合法的极值节点会被排除。

最坏时间复杂度为 `O(n)`，递归栈的额外空间为 `O(h)`，其中 `h` 是树高。树平衡时为 `O(log n)`，退化成链时为 `O(n)`，不能默认所有二叉搜索树都是平衡的。

本地运行极深的链状树时，递归写法可能触及 Python 的递归深度限制，参见 [Python 官方说明](https://docs.python.org/3/library/sys.html#sys.getrecursionlimit)。
