## 题目

**题目链接：** [LeetCode 98 · 验证二叉搜索树](https://leetcode.cn/problems/validate-binary-search-tree/description/?envType=study-plan-v2&envId=top-100-liked)

给定二叉树的根节点 `root`，判断整棵树是否满足二叉搜索树的规则，返回 `true` 或 `false`。

对每个节点，左子树中的**所有节点值都必须严格小于它**，右子树中的**所有节点值都必须严格大于它**；左右子树也要满足同样的规则。不能只比较当前节点和直接孩子，也不允许重复值。

本题不要求高度平衡，与第 108 题的要求不同。

**示例 1**

```text
输入：root = [2,1,3]
输出：true

    2
   / \
  1   3
```

`1 < 2 < 3`，左右两侧都是叶子节点，整棵树满足要求。

**示例 2**

```text
输入：root = [5,1,4,null,null,3,6]
输出：false

    5
   / \
  1   4
     / \
    3   6
```

节点 `4` 位于 `5` 的右子树中，却小于 `5`，因此不是二叉搜索树。

**数据范围**

```text
1 <= 节点数量 <= 10000
-2^31 <= Node.val <= 2^31 - 1
```

题目中的数组表示树的层序结构，`null` 表示空位置，不是需要排序的数组。

**ACM 输入输出**

你的完整程序直接读取以空格分隔的层序数据，**不需要先输入节点数量**，也不带方括号和逗号。例如：

```text
输入：
5 1 4 null null 3 6

输出：
false
```

## 解答

**核心思路：每个节点带着允许的上下界向下递归，检查它是否满足 `low < node.val < upper`。**

`isValidBST(root)` 调用 `self.dfs(root)`，由 `dfs(node, low, upper)` 判断当前子树。根节点的初始范围是 `(-10**18, 10**18)`。进入左子树，把上界收紧为当前节点值，保留原下界；进入右子树，把下界收紧为当前节点值，保留原上界。这样既检查了父节点的要求，也没有丢掉祖先节点的限制。

### 关键代码

使用你的 `isValidBST`、`dfs` 结构，保留变量名、初始边界和先左后右的递归顺序。仅将原代码中的 `low <= node.val <= upper` 修正为严格不等式，避免放过重复值。`TreeNode` 使用 LeetCode 提供的定义；输入读取、层序建树和结果打印不属于判断算法。

```python
class Solution:
    def isValidBST(self, root):
        return self.dfs(root)

    def dfs(self, node, low = -10**18, upper = 10**18):
        if not node:
            return True

        if not low < node.val < upper:
            return False

        return self.dfs(node.left, low, node.val) and self.dfs(node.right, node.val, upper)
```

### 上下界怎样传递

先看示例 1。节点 `2` 在 `(-10**18, 10**18)` 中；随后先检查左孩子 `1`，允许范围是 `(-10**18, 2)`，通过，它的两个空孩子都返回 `True`。再检查右孩子 `3`，允许范围是 `(2, 10**18)`，也通过，它的两个空孩子同样返回 `True`。左右子树都通过，最终返回 `True`。

再看一个**自拟反例**，说明为什么不能只比较父子节点：

```text
输入：root = [5,1,6,null,null,3,7]
输出：false

    5
   / \
  1   6
     / \
    3   7
```

节点 `3` 小于父节点 `6`，符合“左孩子小于父节点”。但它还位于 `5` 的右子树中，必须大于 `5`，这一点不满足。

按你的代码顺序，先检查根节点 `5`，范围是 `(-10**18, 10**18)`，通过。随后检查左孩子 `1`，范围是 `(-10**18, 5)`，通过；它的两个空孩子都返回 `True`，根节点的左子树检查完成。

接着进入右子树的节点 `6`，范围变为 `(5, 10**18)`，也通过。先检查它的左孩子 `3`：保留原来的下界 `5`，把上界收紧为 `6`，必须满足 `5 < 3 < 6`。条件不成立，立即返回 `False`。

节点 `6` 的左子树已经返回 `False`，`and` 短路，不再检查它的右孩子 `7`。这个 `False` 传回节点 `5`，整棵树返回 `False`。实际检查的非空节点顺序是 `5 → 1 → 6 → 3`，不会检查 `7`。

**关键就在于：从 `6` 走向左孩子时，传入的是 `(5, 6)`，不是 `(-10**18, 6)`。下界 `5` 保留下来，才能发现对祖先节点的违反。**

### 易错点与复杂度

必须使用严格不等号。自拟用例 `[2,2,3]` 应返回 `False`，左孩子不能与根节点相等。原来的 `low <= node.val <= upper` 会让左孩子 `2` 通过上界检查，错误返回 `True`；改成 `low < node.val < upper` 后，`2 < 2` 不成立，正确返回 `False`。

空节点返回 `True`，表示这一侧没有违反规则，不是说整棵树已经通过。`and` 两侧必须都为 `True`，当前子树才通过；左边表达式一旦为 `False`，右边表达式就不再执行。这里表达式左边写的是左子树，所以代码先查左子树。

`-10**18` 和 `10**18` 严格覆盖本题允许的节点值范围，作为初始上下界是有效的，不需要改成正负无穷。不能直接把题目允许的最小、最大整数作为严格边界，否则合法的极值节点会被排除。

最坏时间复杂度为 `O(n)`，递归栈的额外空间为 `O(h)`，其中 `h` 是树高。树平衡时为 `O(log n)`，退化成链时为 `O(n)`，不能默认所有二叉搜索树都是平衡的。

本地运行极深的链状树时，递归写法可能触及 Python 的递归深度限制，参见 [Python 官方说明](https://docs.python.org/3/library/sys.html#sys.getrecursionlimit)。
