## 题目

给定一棵二叉树的根节点 `root`。

想象自己站在二叉树的右侧，请按照从上到下的顺序，返回每一层最右侧能够看到的节点值。

**输入格式**

输入一棵二叉树的层序遍历序列，其中 `null` 表示空节点。

**输出格式**

输出从右侧看到的节点值，节点之间用空格分隔。

**输入示例**

```text
1 2 3 null 5 null 4
```

**输出示例**

```text
1 3 4
```

**说明**

对应的二叉树为：

```text
    1
   / \
  2   3
   \   \
    5   4
```

每一层最右侧的节点分别为：

```text
1 3 4
```

## 思路

-   使用 **BFS 按层遍历**，当前层节点都从 `q` 中取出，下一层节点暂存在 `tmp`。
-   因为当前层按 **从左到右** 出队，所以最后一个 `cur_node` 就是**这一层最右侧节点**。
-   每层结束后把 `cur_node.val` 加入 `res`，再把 `tmp` 中的节点放回队列继续下一层。

## 代码

```python
class Solution:
    def __init__(self):
        self.res = []

    def rightSideView(self, root):
        self.bfs(root)
        return self.res

    def bfs(self, root):
        if not root:
            return 
        q = deque()
        q.append(root)
        while q:
            tmp = []
            while q:
                cur_node = q.popleft()
                left_node = cur_node.left if cur_node.left else None
                right_node = cur_node.right if cur_node.right else None
                
                if left_node:
                    tmp.append(left_node)
                if right_node:
                    tmp.append(right_node)
                    
            self.res.append(cur_node.val)
            for node in tmp:
                q.append(node)
```
