## 题目

给定一棵二叉树的根节点 `root`，请按照从上到下、从左到右的顺序，逐层返回二叉树中各节点的值。

**输入格式**

输入一棵二叉树的层序遍历序列，其中 `null` 表示空节点。

**输出格式**

按层输出二叉树中的节点值，每一层输出一行。

**输入示例**

```text
3 9 20 null null 15 7
```

**输出示例**

```text
3
9 20
15 7
```

**说明**

对应的二叉树为：

```text
    3
   / \
  9  20
     /  \
    15   7
```

按照从上到下、从左到右的顺序逐层遍历，得到：

```text
3
9 20
15 7
```

## 思路

使用 **BFS + 队列**，先把 `root` 放入队列，每次取出当前节点，再把它的 **left 和 right 依次加入队列**，`None` 不加入，直到队列为空。

## 代码

```python
class Solution:
    def levelOrder(self, root):
        q = deque()
        q.append(root)
        cnt = 1
        res = []
        while q:
            tmp = []
            cur_cnt = 0
            while cnt > 0:
                cur_node = q.popleft()
                tmp.append(cur_node.val)
                cnt -= 1
                
                if cur_node.left:
                    q.append(cur_node.left)
                    cur_cnt += 1
                
                if cur_node.right:
                    q.append(cur_node.right)
                    cur_cnt += 1
                
            cnt = cur_cnt
            res.append(tmp)
        
        return res
```
