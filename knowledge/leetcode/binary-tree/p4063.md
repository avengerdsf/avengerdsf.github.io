## 题目

给定一棵二叉树的根节点 `root`，请将这棵树原地展开为一个单链表。

展开后的链表需要满足：

-   使用原来的 `TreeNode` 节点。
-   每个节点的 `left` 都为 `null`。
-   每个节点的 `right` 指向链表中的下一个节点。
-   链表中的节点顺序与二叉树的**前序遍历顺序**一致。

**输入格式**

输入一棵二叉树的层序遍历序列，其中 `null` 表示空节点。

**输出格式**

输出展开后的链表节点值。

**输入示例**

```text
1 2 5 3 4 null 6
```

**输出示例**

```text
1 2 3 4 5 6
```

**说明**

原二叉树：

```text
        1
       / \
      2   5
     / \   \
    3   4   6
```

前序遍历结果为：

```text
1 2 3 4 5 6
```

展开后：

```text
1 -> 2 -> 3 -> 4 -> 5 -> 6
```

并且所有节点的 `left` 都为 `null`。

## 思路

-   递归展开左右子树，并分别得到**左子树尾节点** `left_tail`**和右子树尾节点** `right_tail`。
-   如果存在左子树，就把它接到当前节点右侧，再让 `left_tail.right` **接回原来的右子树**。
-   返回当前子树最终的尾节点：**有** `right_tail` **就返回它；否则返回** `left_tail`**；左右都没有就返回** `node`。

## 代码

```python
class Solution:
    def __init__(self):
        pass

    def flatten(self, root):
        self.dfs(root)

    def dfs(self, node):
        if not node:
            return

        left_node = node.left
        right_node = node.right

        left_tail = self.dfs(node.left)
        right_tail = self.dfs(node.right)

        if left_node:
            node.left = None
            node.right = left_node
            left_tail.right = right_node

        return right_tail or left_tail or node

```
