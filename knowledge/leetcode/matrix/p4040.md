## 题目

给定一个 `n × n` 的二维矩阵 `matrix`，请将矩阵顺时针旋转 `90°`。

要求必须在原矩阵上直接修改，不能使用额外的矩阵进行旋转。

**输入格式**

第一行输入一个整数 `n`，表示矩阵的行数和列数。

接下来输入 `n` 行，每行包含 `n` 个整数，表示矩阵。

**输出格式**

输出顺时针旋转 `90°` 后的矩阵。

**输入示例**

```text
3
1 2 3
4 5 6
7 8 9
```

**输出示例**

```text
7 4 1
8 5 2
9 6 3
```

**数据范围**

-   `1 <= n <= 1000`
-   `-10^9 <= matrix[i][j] <= 10^9`

## 思路

-   先将矩阵的**上下两行进行对称交换**，完成上下翻转。
-   再沿**主对角线**遍历，只遍历 `j > i` 的部分，交换 `matrix[i][j]` 和 `matrix[j][i]`。
-   两步完成后，即得到**顺时针旋转 90°** 的矩阵。

## 代码

```python
n = int(input())

matrix = [list(map(int, input().split())) for _ in range(n)]

l, r = 0, n - 1
while l <= r:
    matrix[l], matrix[r] = matrix[r], matrix[l]
    l += 1
    r -= 1

for i in range(n):
    for j in range(i, n):
        matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

for arr in matrix:
    print(' '.join(map(str, arr)))
```
