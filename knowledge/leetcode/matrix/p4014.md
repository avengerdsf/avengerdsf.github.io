## 题目

**P4014. 螺旋矩阵**

给定一个 `m × n` 的矩阵 `matrix`，请按照顺时针螺旋顺序，返回矩阵中的所有元素。

**输入格式**

第一行输入两个整数 `m` 和 `n`，分别表示矩阵的行数和列数。

接下来输入 `m` 行，每行包含 `n` 个整数，表示矩阵。

**输出格式**

按照顺时针螺旋顺序输出矩阵中的所有元素。

**输入示例**

```text
3 3
1 2 3
4 5 6
7 8 9
```

**输出示例**

```text
1 2 3 6 9 8 7 4 5
```

**说明**

按照“上 → 右 → 下 → 左”的顺序不断向内遍历矩阵。

**数据范围**

-   `1 <= m, n <= 1000`
-   `-10^9 <= matrix[i][j] <= 10^9`

## 思路

-   设置四个边界：`l、r、top、bottom`。
-   遍历**上边界**，然后 `top += 1`。
-   遍历**右边界**，然后 `r -= 1`。
-   若 `top <= bottom`，遍历**下边界**，然后 `bottom -= 1`。
-   若 `l <= r`，遍历**左边界**，然后 `l += 1`。
-   当 `l <= r and top <= bottom` 时继续循环。

## 代码

```python
class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        top, bottom = 0, len(matrix)
        left, right = 0, len(matrix[0])
        res = []

        while top < bottom and left < right:
            for j in range(left, right):
                res.append(matrix[top][j])
            top += 1

            for i in range(top, bottom):
                res.append(matrix[i][right - 1])
            right -= 1

            if top < bottom:
                for j in range(right - 1, left - 1, -1):
                    res.append(matrix[bottom - 1][j])
                bottom -= 1

            if left < right:
                for i in range(bottom - 1, top - 1, -1):
                    res.append(matrix[i][left])
                left += 1

        return res
```
