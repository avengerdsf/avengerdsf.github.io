## 题目

给定一个 `m × n` 的整数矩阵 `matrix` 和一个目标值 `target`。

矩阵满足：

-   每一行的元素从左到右升序排列。
-   每一列的元素从上到下升序排列。

请判断 `target` 是否存在于矩阵中。

**输入格式**

第一行输入两个整数 `m` 和 `n`，分别表示矩阵的行数和列数。

接下来输入 `m` 行，每行包含 `n` 个整数，表示矩阵。

最后一行输入一个整数 `target`。

**输出格式**

如果矩阵中存在 `target`，输出：

```text
true
```

否则输出：

```text
false
```

**输入示例**

```text
5 5
1 4 7 11 15
2 5 8 12 19
3 6 9 16 22
10 13 14 17 24
18 21 23 26 30
5
```

**输出示例**

```text
true
```

**说明**

目标值 `5` 存在于矩阵中，因此输出 `true`。

**数据范围**

-   `1 <= m, n <= 1000`
-   `-10^9 <= matrix[i][j], target <= 10^9`

## 思路

从**右上角**开始：

-   如果 **当前值 > target**，向左走。
-   如果 **当前值 < target**，向下走。
-   如果相等，返回 `true`

## 代码

```python
m, n = map(int, input().split())

matrix = [list(map(int, input().split())) for _ in range(m)]
target = int(input())

i, j = 0, n - 1
while 0 <= i < m and 0 <= j < n:
    if matrix[i][j] == target:
        print("true")
        exit()
    elif matrix[i][j] > target:
        j -= 1
    else:
        i += 1

print("false")
```
