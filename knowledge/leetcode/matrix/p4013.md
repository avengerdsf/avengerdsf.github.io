## 题目

给定一个 `m × n` 的整数矩阵 `matrix`，如果矩阵中的某个元素为 `0`，则将该元素所在的整行和整列都置为 `0`。

要求在原矩阵上进行修改。

**输入格式**

第一行输入两个整数 `m` 和 `n`，分别表示矩阵的行数和列数。

接下来输入 `m` 行，每行包含 `n` 个整数，表示矩阵 `matrix`。

**输出格式**

输出置零后的矩阵，共 `m` 行，每行 `n` 个整数。

**输入示例**

```text
3 3
1 1 1
1 0 1
1 1 1
```

**输出示例**

```text
1 0 1
0 0 0
1 0 1
```

**说明**

原矩阵中第 `2` 行第 `2` 列的元素为 `0`，因此将它所在的整行和整列全部置为 `0`。

**数据范围**

-   `1 <= m, n <= 1000`
-   `-10^9 <= matrix[i][j] <= 10^9`

## 思路

-   先记录**第一行和第一列本身是否存在** `0`，因为后面要借用它们做标记。
-   遍历除第一行、第一列外的区域，若 `matrix[i][j] == 0`，就把对应的 `matrix[i][0]` **和** `matrix[0][j]` **置为** `0`。
-   再遍历内部区域，根据第一行和第一列的标记，**将对应位置置为** `0`。
-   最后根据最开始记录的状态，**单独处理第一行和第一列**。

## 代码

```python
lass Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        is_row_zero = False
        for j in range(len(matrix[0])):
            if matrix[0][j] == 0:
                is_row_zero = True
                break

        is_colomn_zero = False
        for i in range(len(matrix)):
            if matrix[i][0] == 0:
                is_colomn_zero = True

        for i in range(1, len(matrix)):
            for j in range(1, len(matrix[0])):
                if matrix[i][j] == 0:
                    matrix[0][j], matrix[i][0] = 0, 0

        for i in range(1, len(matrix)):
            for j in range(1, len(matrix[0])):
                if matrix[0][j] == 0 or matrix[i][0] == 0:
                    matrix[i][j] = 0

        matrix[0] = [0] * len(matrix[0])  if is_row_zero  else matrix[0]
        if is_colomn_zero:
            for i in range(len(matrix)):
                matrix[i][0] = 0

```
