## 题目

给定一个整数数组 `nums`，请找出数组中乘积最大的非空连续子数组，并返回该子数组对应的乘积。

连续子数组是指数组中位置连续的一段元素，至少包含一个元素。

测试用例保证答案在 32 位整数范围内。

**输入格式**

输入一组整数，表示数组 `nums`，整数之间用空格分隔。

**输出格式**

输出一个整数，表示连续子数组的最大乘积。

**输入示例**

```text
2 3 -2 4
```

**输出示例**

```text
6
```

**说明**

乘积最大的连续子数组为：

```text
2 3
```

其乘积为 `2 × 3 = 6`。

**另一个示例**

```text
-2 0 -1
```

**输出示例**

```text
0
```

**说明**

不能选择不连续的 `-2` 和 `-1` 相乘，因此最大乘积为 `0`。

## 思路

## 8.1. 思路

**1\. 定义状态**

-   `max_dp[i]` 表示**以** `nums[i-1]` **结尾的最大连续子数组乘积**。
-   `min_dp[i]` 表示**以** `nums[i-1]` **结尾的最小连续子数组乘积**。

**2\. 状态转移方程**

由于当前数字可能为负数，**最大值和最小值可能互相转换**，因此需要同时维护两个状态：

$$
max\_dp[i] = \max(nums[i-1],\ max\_dp[i-1]\cdot nums[i-1],\ min\_dp[i-1]\cdot nums[i-1])
$$

$$
min\_dp[i] = \min(nums[i-1],\ max\_dp[i-1]\cdot nums[i-1],\ min\_dp[i-1]\cdot nums[i-1])
$$

-   **之前的最大乘积 × 当前元素**：当前元素为正数时，可能产生最大乘积。
-   **之前的最小乘积 × 当前元素**：当前元素为负数时，可能产生最大乘积。
-   **当前元素本身**：从当前位置重新开始。

**3\. 初始状态和边界条件**

-   `max_dp[0] = min_dp[0] = 1`，作为乘法初始值。
-   当 `nums[i-1] = 0` 时，当前乘积归零，后续可以重新开始。
-   最终结果不能包含初始化的 `dp[0]`。

**4\. 状态转移方程求解**

-   从左到右遍历数组，**同时更新最大乘积和最小乘积**。
-   最后返回 `max(max_dp[1:])`，因为最大乘积不一定以最后一个元素结尾。

## 代码

```python
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        n = len(nums)
        min_dp = [1] * (n + 1)
        max_dp = [1] * (n + 1)

        for i in range(1, n + 1):
            min_dp[i] = min(nums[i - 1], min_dp[i - 1]*nums[i - 1], max_dp[i - 1]* nums[i - 1])
            max_dp[i] = max(nums[i - 1], min_dp[i - 1]*nums[i - 1], max_dp[i - 1]* nums[i - 1])

        return max(max_dp[1:])
```
