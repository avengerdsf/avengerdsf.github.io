## 题目

给定一个整数 `numRows`，请生成杨辉三角的前 `numRows` 行。

杨辉三角满足以下规律：

-   每一行的第一个和最后一个数字都是 `1`。
-   除两端外，每个数字等于它**左上方和右上方两个数字之和**。
-   第 `i` 行包含 `i` 个数字（行数从 `1` 开始）。

**输入格式**

输入一个整数 `numRows`，表示需要生成的行数。

**输出格式**

输出杨辉三角的前 `numRows` 行，每行数字之间用空格分隔。

**输入示例**

```text
5
```

**输出示例**

```text
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

**说明**

杨辉三角中的每个内部数字，都等于上一行相邻两个数字之和。

例如，第 5 行中的 `6`：

```text
     3   3
       6
```

因此 `6 = 3 + 3`。

**数据范围**

-   `1 <= numRows <= 30`

## 思路

### 定义状态

`row_s[j]` 表示正在生成的第 `i` 行中下标为 `j` 的数字，行号 `i` 从 1 开始。生成完成的行依次存入 `res`，因此 `res[i-1]` 对应第 `i` 行。

### 状态转移方程

对于第 `i` 行的内部位置，当前数字等于上一行相邻两个数字之和：

$$
\mathrm{row\_s}[j] = \mathrm{res}[i-2][j-1] + \mathrm{res}[i-2][j]
$$

这里 `i > 2`，且 `1 <= j < i-1`。

### 初始状态和边界条件

`res` 初始为空列表。每一行先用 `[1] * i` 初始化，首尾数字保持为 1。前两行没有需要递推的内部位置。

### 状态转移方程求解

依次生成第 1 行到第 `numRows` 行。当 `i > 2` 时，按 `j = 1, …, i-2` 更新中间数字，上一行此时已经存入 `res`。完成当前行后执行 `res.append(row_s)`，最后返回 `res`。

## 代码

```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        res = []
        for i in range(1, numRows + 1):
            row_s = [1] * i

            if i > 2:
                for j in range(1, i - 1):
                    row_s[j] = res[i - 2][j - 1] + res[i - 2][j]

            res.append(row_s)
        # 请在这里实现
        return res
```
