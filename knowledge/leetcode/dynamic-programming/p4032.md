## 题目

给定一个整数 `numRows`，请生成杨辉三角的前 `numRows` 行。

杨辉三角满足以下规律：

-   每一行的第一个和最后一个数字都是 `1`。
-   除两端外，每个数字等于它**左上方和右上方两个数字之和**。
-   第 `i` 行包含 `i` 个数字（行数从 `1` 开始）。

**输入格式**

输入一个整数 `numRows`，表示需要生成的行数。

**输出格式**

输出杨辉三角的前 `numRows` 行，每行数字之间用空格分隔。

**输入示例**

```text
5
```

**输出示例**

```text
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

**说明**

杨辉三角中的每个内部数字，都等于上一行相邻两个数字之和。

例如，第 5 行中的 `6`：

```text
     3   3
       6
```

因此 `6 = 3 + 3`。

**数据范围**

-   `1 <= numRows <= 30`

## 思路

逐行生成杨辉三角，每行先用 `[1] * i`初始化，保证首尾元素为 `1`；再根据上一行的相邻两个元素之和 `res[i-2][j-1] + res[i-2][j]`更新当前行的中间元素。

## 代码

```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        res = []
        for i in range(1, numRows + 1):
            row_s = [1] * i

            if i > 2:
                for j in range(1, i - 1):
                    row_s[j] = res[i - 2][j - 1] + res[i - 2][j]

            res.append(row_s)
        # 请在这里实现
        return res
```
