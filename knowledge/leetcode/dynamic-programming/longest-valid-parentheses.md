## 题目

给定一个只包含 `'('` 和 `')'` 的字符串 `s`，请找出其中最长的有效括号子串，并返回该子串的长度。

有效括号子串需要满足：

-   每个左括号 `'('` 都有对应的右括号 `')'`。
-   括号必须按照正确的顺序匹配。
-   子串必须**连续**。

**输入格式**

输入一个字符串 `s`，仅包含 `'('` 和 `')'`。

**输出格式**

输出一个整数，表示最长有效括号子串的长度。

如果不存在有效括号子串，则输出 `0`。

**输入示例**

```text
(()
```

**输出示例**

```text
2
```

**说明**

最长有效括号子串为：

```text
()
```

因此长度为 `2`。

**另一个示例**

```text
)()())
```

**输出示例**

```text
4
```

**说明**

最长有效括号子串为：

```text
()()
```

因此长度为 `4`。

**数据范围**

-   `0 <= len(s) <= 30000`
-   `s` 仅包含 `'('` 和 `')'`。

## 思路

### 定义状态

`dp[i]` 表示**以** `s[i-1]` **结尾的最长连续有效括号子串长度**，栈中保存**未匹配的左括号下标**。

### 状态转移方程

遇到右括号 `)` 且栈非空时，弹出匹配的左括号下标 `j`：

$$
dp[i] = dp[j] + i - j
$$

-   `dp[j]`：**左括号之前紧邻的有效子串长度**。
-   `i-j`：**当前匹配的整段括号长度**。

### 初始状态和边界条件

-   字符串长度小于 2 时直接返回 `0`。
-   `dp` 的长度为 `n + 1`，初始值全部为 `0`；`dp[0]` 表示空前缀，初始化栈为空。
-   遇到 `(`：**下标入栈**，`dp[i] = 0`。
-   遇到 `)` 且栈为空：**无法匹配**，`dp[i] = 0`。

### 状态转移方程求解

-   从左到右遍历字符串，遇到 `(` 入栈，遇到 `)` 尝试匹配并更新 `dp[i]`。
-   最后返回 `max(dp[1:])`，因为最长有效括号子串不一定以最后一个字符结尾。

## 代码

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        n = len(s)
        if n < 2:
            return 0

        dp = [0] * (n + 1)
        dp[0] = 0
        stack = []

        for i in range(1, n + 1):
            ch = s[i - 1]
            if ch == "(":
                stack.append(i - 1)
                dp[i] = 0
            else:
                if stack:
                    j = stack.pop()
                    if i - 1 > j:
                        dp[i] = dp[j] + i - j
                else:
                    dp[i] = 0
        return max(dp[1:])
```
