## 题目

给定一个非负整数数组 `nums`，其中 `nums[i]` 表示第 `i` 间房屋中存放的现金金额。

你是一名小偷，计划沿街偷窃这些房屋。

相邻的两间房屋装有相互连通的防盗系统，如果同一晚上偷窃两间相邻的房屋，就会触发警报。

请计算在不触发警报的情况下，能够偷窃到的最大金额。

**输入格式**

第一行输入一个整数 `n`，表示房屋数量。

第二行输入 `n` 个非负整数，表示每间房屋的现金金额。

**输出格式**

输出一个整数，表示能够获得的最大金额。

**输入示例**

```text
5
2 7 9 3 1
```

**输出示例**

```text
12
```

**说明**

选择第 `1`、`3`、`5` 间房屋：

```text
2 + 9 + 1 = 12
```

由于所选房屋互不相邻，因此不会触发警报，最大收益为 `12`。

**另一个示例**

```text
4
1 2 3 1
```

**输出示例**

```text
4
```

**说明**

选择第 `1` 和第 `3` 间房屋，可以获得最大收益 `1 + 3 = 4`。

## 思路

### 定义状态

`dp[i]` 表示**前** `i+1` **间房屋能够获得的最大收益**。

### 状态转移方程

当前房屋有**偷或不偷**两种选择：

$$
dp[i] = \max(dp[i-1],\ dp[i-2]+nums[i])
$$

-   `dp[i-1]`：**不偷当前房屋**，继承之前的最大收益。
-   `dp[i-2] + nums[i]`：**偷当前房屋**，因此不能偷前一间房屋。

### 初始状态和边界条件

-   `n = 0`：返回 `0`。
-   `dp[0] = nums[0]`，只有一间房屋时的最大收益。
-   `dp[1] = max(nums[0], nums[1])`，两间房屋只能选择其中一间。

### 状态转移方程求解

-   从 `i = 2` 开始遍历，比较**偷与不偷当前房屋**的收益，更新 `dp[i]`。
-   最后返回 `dp[n-1]`，即所有房屋的最大收益。

## 代码

```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 0:
            return 0

        if n == 1:
            return nums[0]

        dp = [0] * (n + 1)
        dp[0] = nums[0]
        dp[1] = max(nums[0], nums[1])

        for i in range(2, n):
            dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])

        return dp[n - 1]
```
