## 题目

给定一个只包含正整数的非空数组 `nums`，请判断是否可以将数组分割成两个子集，使得两个子集的元素和相等。

**注意：**

-   每个元素只能被使用一次。
-   两个子集不要求连续。
-   两个子集必须包含原数组中的所有元素。

**输入格式**

输入一组正整数，表示数组 `nums`，整数之间用空格分隔。

**输出格式**

如果可以分割成两个元素和相等的子集，输出 `true`，否则输出 `false`。

**输入示例**

```text
1 5 11 5
```

**输出示例**

```text
true
```

**说明**

可以将数组分为：

```text
[1, 5, 5]
[11]
```

两个子集的元素和均为 `11`，因此输出 `true`。

**另一个示例**

```text
1 2 3 5
```

**输出示例**

```text
false
```

**说明**

数组总和为 `11`，无法分成两个元素和相等的子集。

**数据范围**

-   `1 <= len(nums) <= 200`
-   `1 <= nums[i] <= 100`

## 思路

## 一维 DP 解法

### 定义状态

`dp[j]` 表示**从已遍历的数字中，能否选出若干个数字，使其和恰好为** `j`。

### 状态转移方程

对于当前数字 `num`，有**选或不选**两种情况：

$$
dp[j] = dp[j] \lor dp[j-num]
$$

-   `dp[j]`：**不选当前数字**，保留原来的结果。
-   `dp[j-num]`：**选当前数字**，如果剩余金额能够凑出，则当前金额也能凑出。

### 初始状态和边界条件

-   如果 `sum(nums)` **为奇数**，无法均分，直接返回 `False`。
-   目标和为 `target = sum(nums) // 2`。
-   `dp[0] = True`，表示不选任何数字可以凑出 `0`。
-   其余 `dp[j]` 初始化为 `False`。

### 状态转移方程求解

-   依次遍历每个数字 `num`，对 `j` 从 `target` **到** `num` **倒序遍历**。
-   倒序更新保证 **每个数字只能使用一次**，避免重复选取。
-   最后返回 `dp[target]`，判断能否凑出总和的一半。

## 代码

```python
from typing import List

class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        n = len(nums)
        sum_num = sum(nums)
        if sum_num % 2 != 0 or n <= 1:
            return False

        target = sum_num // 2  # 修改1：目标是总和的一半
        dp = [False] * (target + 1)  # 修改2：只需要记录到 target
        dp[0] = True  # 修改3：不选任何数字可以凑出0

        # 修改4：删除原来提前标记所有 nums[i] 的循环
        for i in range(n):
            # 修改5：倒序遍历，确保每个数字只能使用一次
            for j in range(target, nums[i] - 1, -1):
                # 修改6：不选当前数字 or 选当前数字
                dp[j] = dp[j] or dp[j - nums[i]]

        return dp[target]  # 修改7：判断是否能凑出总和的一半

def main():
    nums = list(map(int, input().split()))
    print(str(Solution().canPartition(nums)).lower())

if __name__ == "__main__":
    main()
```

## 一维 DP 注意点

-   目标值错误：应该判断能否凑出 `sum_num // 2`，而不是 `sum_num`。
-   初始化错误：应该设置 `dp[0] = True`，表示不选任何数字可以凑出 `0`。
-   递推公式错误：应该是 `dp[j] = dp[j] or dp[j - nums[i]]`，分别表示不选和选当前数字。
-   遍历方向错误：必须先遍历数字，再倒序遍历目标金额，避免同一个数字被重复使用。

## 二维 DP 解法

### 定义状态

`dp[i][j]` 表示只从前 `i` 个数字 `nums[0]` 到 `nums[i - 1]` 中，能否选出若干个数字，使它们的和恰好为 `j`。

数组总和为偶数时，目标是凑出 `target = sum(nums) // 2`，剩余数字的和自然也是 `target`。

### 状态转移方程

对于第 `i` 个数字 `nums[i - 1]`，有选或不选两种情况：

-   **不选当前数字**：从前 `i - 1` 个数字中凑出 `j`，对应 `dp[i - 1][j]`。
-   **选当前数字**：当 `j >= nums[i - 1]` 时，从前 `i - 1` 个数字中凑出剩余的 `j - nums[i - 1]`，对应 `dp[i - 1][j - nums[i - 1]]`。

当 `j >= nums[i - 1]` 时：

$$
dp[i][j] = dp[i-1][j] \lor dp[i-1][j-nums[i-1]]
$$

当 `j < nums[i - 1]` 时，当前数字大于当前要凑出的和 `j`，只能不选它，即 `dp[i][j] = dp[i - 1][j]`。

两种情况都读取上一行，保证每个数字最多使用一次。

### 初始状态和边界条件

-   如果数组只有一个数字，或数组总和为奇数，直接返回 `False`。
-   建立 `n + 1` 行、`target + 1` 列的二维数组，初始值均为 `False`。
-   `dp[i][0] = True`：无论考虑前多少个数字，都可以通过不选任何数字凑出 `0`。
-   `dp[0][j] = False`（`j > 0`）：没有数字时，无法凑出正数。

### 状态转移方程求解

-   `i` 从 `1` 遍历到 `n`，当前数字为 `nums[i - 1]`。
-   `j` 从 `1` 遍历到 `target`，根据上一行的状态计算当前行。每个状态只读取上一行，因此 `j` 可以正序遍历。
-   最后返回 `dp[n][target]`，判断能否从全部数字中选出和为总和一半的子集。
-   时间复杂度为 `O(n × target)`，空间复杂度为 `O(n × target)`。

### 代码

```python
from typing import List

class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        n = len(nums)
        sum_num = sum(nums)
        if sum_num % 2 != 0 or n <= 1:
            return False

        target = sum_num // 2
        dp = [[False] * (target + 1) for _ in range(n + 1)]
        for i in range(n + 1):
            dp[i][0] = True

        for i in range(1, n + 1):
            num = nums[i - 1]
            for j in range(1, target + 1):
                dp[i][j] = dp[i - 1][j]
                if j >= num:
                    dp[i][j] = dp[i][j] or dp[i - 1][j - num]

        return dp[n][target]

def main():
    nums = list(map(int, input().split()))
    print(str(Solution().canPartition(nums)).lower())

if __name__ == "__main__":
    main()
```
