## 题目

给定一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。

请判断是否可以利用字典中的一个或多个单词，拼接得到完整的字符串 `s`。

**注意：**

-   不要求使用字典中的所有单词。
-   字典中的单词可以**重复使用**。
-   拼接后的字符串必须与 `s` 完全相同。

**输入格式**

第一行输入一个字符串 `s`。

第二行输入若干个字符串，空格分隔，表示字典 `wordDict`。

**输出格式**

如果可以利用字典中的单词拼接出 `s`，输出 `true`，否则输出 `false`。

**输入示例**

```text
leetcode
leet code
```

**输出示例**

```text
true
```

**说明**

`leetcode = leet + code`，两个单词均存在于字典中。

**另一个示例**

```text
applepenapple
apple pen
```

**输出示例**

```text
true
```

**说明**

`applepenapple = apple + pen + apple`，其中 `apple` 被重复使用。

**第三个示例**

```text
catsandog
cats dog sand and cat
```

**输出示例**

```text
false
```

**数据范围**

-   `1 <= len(s) <= 300`
-   `1 <= len(wordDict) <= 1000`
-   `1 <= len(wordDict[i]) <= 20`
-   字符串仅由小写英文字母组成。
-   `wordDict` 中所有单词互不相同。

## 思路

### 定义状态

`dp[i]` 表示**字符串前** `i` **个字符能否由字典中的单词拼接得到**。

### 状态转移方程

枚举切分位置 `j`，若 `dp[j] = True` 且 `s[j:i]` **存在于字典中**，则说明前 `i` 个字符可以成功拆分：

$$
dp[i] = dp[i] \lor (dp[j] \land (s[j:i] \in wordDict))
$$

-   `dp[j]`：**前** `j` **个字符可以成功拆分**。
-   `s[j:i]`：**剩余子串必须是字典中的完整单词**。

### 初始状态和边界条件

-   `dp[0] = True`，表示空字符串可以成功拆分。
-   其余 `dp[i]` 初始化为 `False`。
-   `0 <= j < i <= n`，保证切分位置合法。

### 状态转移方程求解

-   从左到右遍历 `i`，枚举之前所有切分位置 `j`。
-   当 `dp[j] = True` **且** `s[j:i]` **在字典中**时，令 `dp[i] = True`，并结束当前内层循环。
-   最后返回 `dp[n]`，判断整个字符串能否成功拆分。

## 代码

```python
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        n = len(s)
        dp = [False] * (n + 1)
        dp[0] = True

        for i in range(1, n + 1):
            for j in range(i):
                if dp[j] and s[j:i] in wordDict:
                    dp[i] = True
                    break

        return dp[n]
```
