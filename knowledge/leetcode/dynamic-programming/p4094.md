## 题目

给定一个整数数组 `nums`，请找到其中最长严格递增子序列的长度。

子序列是指从原数组中删除若干个元素（也可以不删除），但不能改变剩余元素的相对顺序。

严格递增要求子序列中每个元素都大于前一个元素。

**输入格式**

输入一组整数，表示数组 `nums`，整数之间用空格分隔。

**输出格式**

输出一个整数，表示最长严格递增子序列的长度。

**输入示例**

```text
10 9 2 5 3 7 101 18
```

**输出示例**

```text
4
```

**说明**

最长严格递增子序列之一为：

```text
2 3 7 101
```

因此最长长度为 `4`。

**另一个示例**

```text
0 1 0 3 2 3
```

**输出示例**

```text
4
```

**第三个示例**

```text
7 7 7 7 7 7 7
```

**输出示例**

```text
1
```

**数据范围**

-   `1 <= len(nums) <= 2500`
-   `-10^4 <= nums[i] <= 10^4`

## 思路

### 定义状态

`dp[i]` 表示以 `nums[i]` 结尾的最长严格递增子序列长度，代码采用零基下标。`ans` 保存所有已计算结尾状态中的最大长度。

### 状态转移方程

当 `0 <= j < i` 且 `nums[j] < nums[i]` 时，可以把当前元素接在以 `nums[j]` 结尾的递增子序列后面：

$$
dp[i] = \max(dp[i],\ dp[j]+1)
$$

枚举当前位置之前的所有元素，保留最长的候选方案。

### 初始状态和边界条件

每个元素单独构成长度为 1 的子序列，因此 `dp = [1] * n`。题目中的数组非空，`ans` 初始为 1。`dp[0]` 对应以第一个元素结尾的状态，也参与答案比较。

### 状态转移方程求解

外层按 `i = 0, …, n-1` 遍历，内层按 `j = 0, …, i-1` 查找能接在前面的结尾。完成当前状态后执行 `ans = max(ans, dp[i])`，最后返回 `ans`，结果等于非空数组上的 `max(dp)`。

## 代码

```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [1] * n
        ans = 1
        
        for i in range(n):
            for j in range(i):
                if nums[j] < nums[i]:
                    dp[i] = max(dp[i], dp[j] + 1 )
                    
            ans = max(ans, dp[i])
            
        return ans
```
