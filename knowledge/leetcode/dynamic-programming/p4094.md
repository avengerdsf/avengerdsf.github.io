## 题目

给定一个整数数组 `nums`，请找到其中最长严格递增子序列的长度。

子序列是指从原数组中删除若干个元素（也可以不删除），但不能改变剩余元素的相对顺序。

严格递增要求子序列中每个元素都大于前一个元素。

**输入格式**

输入一组整数，表示数组 `nums`，整数之间用空格分隔。

**输出格式**

输出一个整数，表示最长严格递增子序列的长度。

**输入示例**

```text
10 9 2 5 3 7 101 18
```

**输出示例**

```text
4
```

**说明**

最长严格递增子序列之一为：

```text
2 3 7 101
```

因此最长长度为 `4`。

**另一个示例**

```text
0 1 0 3 2 3
```

**输出示例**

```text
4
```

**第三个示例**

```text
7 7 7 7 7 7 7
```

**输出示例**

```text
1
```

**数据范围**

-   `1 <= len(nums) <= 2500`
-   `-10^4 <= nums[i] <= 10^4`

## 思路

**1\. 定义状态**

`dp[i]` 表示**以** `nums[i-1]` **结尾的最长严格递增子序列长度**。

**2\. 状态转移方程**

当 `nums[j-1] < nums[i-1]` 时，当前元素可以接在之前的递增子序列后面：

$$
dp[i] = \max(dp[i],\ dp[j]+1)
$$

-   `dp[j] + 1`：**当前元素接在之前的子序列后面，长度加 1**。
-   `max()`：**从所有符合条件的子序列中选择最长的一个**。

**3\. 初始状态和边界条件**

-   `dp[0] = 0`，表示未选择任何元素。
-   `dp[i] = 1`，每个元素自身都能构成长度为 `1` 的子序列。
-   `1 <= j < i <= n`，只考虑当前位置之前的元素。

**4\. 状态转移方程求解**

-   从左到右遍历 `i`，枚举之前的所有位置 `j`。
-   只有满足 `nums[j-1] < nums[i-1]` 时，才能更新 `dp[i]`。
-   最后返回 `max(dp[1:])`，因为最长递增子序列不一定以最后一个元素结尾。

## 代码

```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [1] * n
        ans = 1
        
        for i in range(n):
            for j in range(i):
                if nums[j] < nums[i]:
                    dp[i] = max(dp[i], dp[j] + 1 )
                    
            ans = max(ans, dp[i])
            
        return ans
```
