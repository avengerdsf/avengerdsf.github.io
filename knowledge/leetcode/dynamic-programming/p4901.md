## 题目

给定一个长度为 `n` 的整数数组 `nums`，请找出其中最长严格递增子序列的长度。

子序列是指从原数组中删除若干个元素，但不改变剩余元素的相对顺序。

**注意：子序列不要求连续，但必须严格递增。**

**输入格式**

第一行输入整数 `n`，表示数组长度。

第二行输入 `n` 个整数，表示数组 `nums`。

**输出格式**

输出一个整数，表示最长严格递增子序列的长度。

**输入示例**

```text
8
10 9 2 5 3 7 101 18
```

**输出示例**

```text
4
```

**说明**

最长严格递增子序列之一为：

```text
2 3 7 101
```

因此最长长度为 `4`。

## 思路

### 定义状态

`dp[i]` 表示**以** `nums[i-1]` **结尾的最长严格递增子序列长度**。

### 状态转移方程

当 `nums[j-1] < nums[i-1]` 时，当前元素可以接在之前的递增子序列后面：

$$
dp[i] = \max(dp[i], dp[j]+1)
$$

-   `dp[j] + 1`：**当前元素接在之前的子序列后面，长度加 1**。
-   `max()`：**选择所有符合条件的子序列中最长的一个**。

### 初始状态和边界条件

-   `dp[0] = 0`，表示未选择任何元素。
-   `dp[i] = 1`，每个元素自身都能构成长度为 `1` 的子序列。
-   `1 <= j < i <= n`，只考虑当前位置之前的元素。代码直接设置 `dp[1]`，因此要求数组至少有一个元素。

### 状态转移方程求解

-   从左到右遍历 `i`，枚举之前的所有位置 `j`。
-   满足 `nums[j-1] < nums[i-1]` 时，更新 `dp[i]`。
-   最后返回 `max(dp[1:])`，因为最长递增子序列不一定以最后一个元素结尾。

## 代码

```python
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [1] * (n + 1)  # 修改1：每个元素自身就是长度为1的子序列
        dp[0] = 0
        dp[1] = 1

        for i in range(1, n + 1):
            for j in range(1, i):
                if nums[i - 1] > nums[j - 1]:  # 修改2：修正下标
                    dp[i] = max(dp[i], dp[j] + 1)  # 修改3：更新dp[i]，长度+1

        return max(dp[1:])
```
