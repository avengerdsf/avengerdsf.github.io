## 题目

假设你正在爬楼梯，需要爬 `n` 阶才能到达楼顶。

每次可以选择爬 `1` 阶或 `2` 阶，请计算有多少种不同的方法可以到达楼顶。

**输入格式**

输入一个整数 `n`，表示楼梯的台阶数。

**输出格式**

输出一个整数，表示到达楼顶的不同方案数。

**输入示例**

```text
3
```

**输出示例**

```text
3
```

**说明**

当 `n = 3` 时，共有以下三种方案：

-   `1 + 1 + 1`
-   `1 + 2`
-   `2 + 1`

因此输出 `3`。

**数据范围**

-   `1 <= n <= 45`

## 思路

使用动态规划 DP，到达第 `i`阶只能从第 `i-1`阶走 1 步或第 `i-2`阶走 2 步，因此 `f[i] = f[i-1] + f[i-2]`。

## 代码

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        f = [1] * (n + 1)

        for i in range(2, n + 1):
            f[i] = f[i - 1] + f[i - 2]

        return f[n]
```
