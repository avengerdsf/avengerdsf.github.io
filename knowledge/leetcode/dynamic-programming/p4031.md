## 题目

假设你正在爬楼梯，需要爬 `n` 阶才能到达楼顶。

每次可以选择爬 `1` 阶或 `2` 阶，请计算有多少种不同的方法可以到达楼顶。

**输入格式**

输入一个整数 `n`，表示楼梯的台阶数。

**输出格式**

输出一个整数，表示到达楼顶的不同方案数。

**输入示例**

```text
3
```

**输出示例**

```text
3
```

**说明**

当 `n = 3` 时，共有以下三种方案：

-   `1 + 1 + 1`
-   `1 + 2`
-   `2 + 1`

因此输出 `3`。

**数据范围**

-   `1 <= n <= 45`

## 思路

### 定义状态

`f[i]` 表示到达第 `i` 阶楼梯的不同方案数，状态下标就是台阶数。

### 状态转移方程

到达第 `i` 阶的最后一步可以走 1 阶，也可以走 2 阶，分别接在到达第 `i-1` 阶和第 `i-2` 阶的方案后面：

$$
f[i] = f[i-1] + f[i-2]
$$

### 初始状态和边界条件

`f[0] = 1`，表示还没有迈步时的一种空方案；`f[1] = 1`，表示走一阶只有一种方式。代码用 `[1] * (n + 1)` 初始化数组，后续计算覆盖 `f[2]` 到 `f[n]`。

### 状态转移方程求解

按 `i = 2, 3, …, n` 从小到大计算，保证 `f[i-1]` 和 `f[i-2]` 已经得到。最后返回 `f[n]`；当 `n = 1` 时循环不执行，直接得到初值 1。

## 代码

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        f = [1] * (n + 1)

        for i in range(2, n + 1):
            f[i] = f[i - 1] + f[i - 2]

        return f[n]
```
