## 题目

给定一个整数数组 `coins`，表示不同面额的硬币，以及一个整数 `amount`，表示需要凑出的总金额。

每种面额的硬币可以**无限次使用**。

请计算凑成总金额 `amount` 所需的最少硬币数量。

如果无法凑出该金额，则返回 `-1`。

**输入格式**

第一行输入一个整数 `n`，表示硬币面额的数量。

第二行输入 `n` 个正整数，表示硬币面额数组 `coins`。

第三行输入一个整数 `amount`，表示目标金额。

**输出格式**

输出一个整数，表示凑成目标金额所需的最少硬币数量。

## 思路

使用**动态规划 DP**，`dp[i]` 表示凑成金额 `i` 所需的最少硬币数量，遍历所有满足 `coin <= i` 的硬币，递推公式为：

$$
dp[i] = \min(dp[i],\ dp[i-coin]+1)
$$

其中 `dp[i-coin]` **表示剩余金额所需的最少硬币数**，再加上当前选择的一枚硬币。

**注意点**

初始化 `dp[0] = 0`，其余位置为无穷大；如果最终仍为无穷大，说明**无法凑出目标金额**，返回 `-1`。

## 代码

```python
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        n = len(coins)
        dp = [10 ** 18] * (amount + 1)

        dp[0] = 0
        for i in range(1, amount + 1):
            for coin in coins:
                if i - coin >= 0:
                    dp[i] = min(dp[i], dp[i-coin] + 1)
        
        return dp[amount] if dp[amount] != 10**18 else -1
```
