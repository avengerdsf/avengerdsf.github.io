## 题目

给定一个整数数组 `coins`，表示不同面额的硬币，以及一个整数 `amount`，表示需要凑出的总金额。

每种面额的硬币可以**无限次使用**。

请计算凑成总金额 `amount` 所需的最少硬币数量。

如果无法凑出该金额，则返回 `-1`。

**输入格式**

第一行输入一个整数 `n`，表示硬币面额的数量。

第二行输入 `n` 个正整数，表示硬币面额数组 `coins`。

第三行输入一个整数 `amount`，表示目标金额。

**输出格式**

输出一个整数，表示凑成目标金额所需的最少硬币数量。

## 思路

### 定义状态

`dp[i]` 表示凑出金额 `i` 所需的最少硬币数量。每种面额可以重复选取。

### 状态转移方程

对于满足 `coin <= i` 的硬币，先凑出剩余金额 `i-coin`，再选取当前硬币：

$$
dp[i] = \min(dp[i],\ dp[i-coin]+1)
$$

遍历所有可选面额，保留硬币数量最少的方案。

### 初始状态和边界条件

数组长度为 `amount + 1`，`dp[0] = 0`。其他状态初始化为 `10**18`，作为不可达标记。当目标金额为 0 时，答案就是 0。

### 状态转移方程求解

外层按金额 `i = 1, …, amount` 从小到大计算，内层遍历所有硬币面额。只有 `i - coin >= 0` 时才参与转移，此时剩余金额的状态已经计算完成。最后检查 `dp[amount]`：仍等于不可达标记则返回 `-1`，否则返回该最少硬币数。

## 代码

```python
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        n = len(coins)
        dp = [10 ** 18] * (amount + 1)

        dp[0] = 0
        for i in range(1, amount + 1):
            for coin in coins:
                if i - coin >= 0:
                    dp[i] = min(dp[i], dp[i-coin] + 1)
        
        return dp[amount] if dp[amount] != 10**18 else -1
```
