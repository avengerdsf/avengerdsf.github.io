## 题目

给定一个正整数 `n`，请将其拆分为若干个完全平方数之和，并返回所需的最少完全平方数数量。

完全平方数是指可以表示为某个整数平方的数，例如 `1、4、9、16、25`。

每个完全平方数可以重复使用。

**输入格式**

输入一个正整数 `n`。

**输出格式**

输出一个整数，表示组成 `n` 所需的最少完全平方数数量。

**输入示例**

```text
12
```

**输出示例**

```text
3
```

**说明**

12 = 4 + 4 + 4，因此最少需要 `3` 个完全平方数。

**另一个示例**

```text
13
```

**输出示例**

```text
2
```

**说明**

13 = 4 + 9，因此最少需要 `2` 个完全平方数。

## 思路

使用**动态规划 DP**，`dp[i]` 表示组成整数 `i` 所需的最少完全平方数数量，遍历所有满足 `j² <= i` 的平方数，递推公式为：

$$
dp[i] = \min(dp[i],\ dp[i-j^2]+1)
$$

其中 `dp[i-j²]` **表示剩余部分的最优解**，再加上当前选择的一个平方数。

## 代码

```python
class Solution:
    def numSquares(self, n: int) -> int:
        dp = [n + 1] *(n + 1)
        dp[0] = 0
        for i in range(1, n + 1):
            for j in range(i + 1):
                if i - j * j >=0:
                    dp[i] = min(dp[i], dp[i-j * j] + 1)
                else:
                    break

        return dp[n]
```
