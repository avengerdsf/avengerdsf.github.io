## 题目

给定一个正整数 `n`，请将其拆分为若干个完全平方数之和，并返回所需的最少完全平方数数量。

完全平方数是指可以表示为某个整数平方的数，例如 `1、4、9、16、25`。

每个完全平方数可以重复使用。

**输入格式**

输入一个正整数 `n`。

**输出格式**

输出一个整数，表示组成 `n` 所需的最少完全平方数数量。

**输入示例**

```text
12
```

**输出示例**

```text
3
```

**说明**

12 = 4 + 4 + 4，因此最少需要 `3` 个完全平方数。

**另一个示例**

```text
13
```

**输出示例**

```text
2
```

**说明**

13 = 4 + 9，因此最少需要 `2` 个完全平方数。

## 思路

### 定义状态

`dp[i]` 表示将整数 `i` 写成若干个完全平方数之和所需的最少项数。

### 状态转移方程

选取一个满足 `j² <= i` 的完全平方数 `j²`，剩余部分需要 `dp[i-j²]` 项，再加上当前选取的一项：

$$
dp[i] = \min(dp[i],\ dp[i-j^2]+1)
$$

### 初始状态和边界条件

`dp[0] = 0`，表示组成 0 无需选取任何数。其余位置初始化为 `n + 1`；对于 `i <= n`，使用 `i` 个 1 就能组成 `i`，所以这个初值大于有效答案。

### 状态转移方程求解

外层按 `i = 1, …, n` 计算，内层枚举 `j`。当 `i - j*j < 0` 时结束内层循环。代码从 `j = 0` 开始枚举，这一次比较不会降低当前答案；正平方数的转移依赖更小的整数状态。最后返回 `dp[n]`。

## 代码

```python
class Solution:
    def numSquares(self, n: int) -> int:
        dp = [n + 1] *(n + 1)
        dp[0] = 0
        for i in range(1, n + 1):
            for j in range(i + 1):
                if i - j * j >=0:
                    dp[i] = min(dp[i], dp[i-j * j] + 1)
                else:
                    break

        return dp[n]
```
