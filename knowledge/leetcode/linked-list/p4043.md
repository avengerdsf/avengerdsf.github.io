## 题目

给定一个单链表的头节点 `head`，请判断链表中是否存在环。

如果链表中的某个节点可以通过不断沿着 `next` 指针再次被访问到，则说明链表中存在环。

**输入格式**

第一行输入一个整数 `n`，表示链表节点数量。

第二行输入 `n` 个整数，表示链表中各节点的值。

第三行输入一个整数 `pos`，表示链表尾节点连接到链表中的位置下标。

如果 `pos = -1`，表示链表中没有环。

**输出格式**

如果链表中存在环，输出：

```text
true
```

否则输出：

```text
false
```

**输入示例**

```text
4
3 2 0 -4
1
```

**输出示例**

```text
true
```

**说明**

链表尾节点连接到下标 `1` 的节点，因此链表中存在环。

**数据范围**

-   `0 <= n <= 100000`
-   `-1 <= pos < n`
-   `-10^9 <= val <= 10^9`

## 思路

-   判断是否存在环：用**快慢指针**，`slow` 每次走 1 步，`fast` 每次走 2 步，若两者相遇则说明存在环。

## 代码

```python
class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        fast, slow = head, head
        while fast and fast.next:
            fast = fast.next.next
            slow = slow.next
            if fast == slow:
                return True 

        return False
```
