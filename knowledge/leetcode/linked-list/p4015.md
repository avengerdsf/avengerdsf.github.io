## 题目

给定两个单链表的头节点 `headA` 和 `headB`，请找出并返回两个链表相交的起始节点。

如果两个链表不相交，则返回 `null`。

两个链表相交是指它们从某个节点开始，后续节点完全相同，即两个链表共享同一段链表节点。

**输入格式**

输入两个链表以及它们可能的公共部分。

**输出格式**

如果两个链表相交，输出相交起始节点的值。

如果不相交，输出：

```text
null
```

**输入示例**

```text
A: 4 1 8 4 5
B: 5 6 1 8 4 5
```

其中两个链表从值为 `8` 的节点开始相交。

**输出示例**

```text
8
```

**说明**

链表结构为：

```text
      A: 4 -> 1
               \
                8 -> 4 -> 5
               /
B: 5 -> 6 -> 1
```

两个链表从节点 `8` 开始共享后续节点，因此返回该节点。

**数据范围**

-   两个链表的节点数均不超过 `100000`
-   节点值范围为 `-10^9 <= val <= 10^9`

## 思路

-   构造 A：创建链表，并记录 `skipA` 位置的**公共节点**。
-   构造 B：到 `skipB` 时直接连接这个**公共节点**。
-   双指针：分别遍历两个链表，走到末尾后**切换到另一个链表头**。
-   判断结果：最终在**相交节点相遇**；不相交则同时到 `None`。

## 代码

```python
n, skipA = map(int, input().split())
listA = list(map(int, input().split()))

m, skipB = map(int, input().split())
listB = list(map(int, input().split()))

class ListNode:
    def __init__(self, val):
        self.val = val
        self.next = None

list_nodeA = ListNode(0)
cur_node = list_nodeA

cur_idx = 0
for num in listA:
    cur_node.next = ListNode(num)
    cur_node = cur_node.next
    if cur_idx == skipA:
        common_node = cur_node
    cur_idx += 1

list_nodeB = ListNode(0)
cur_node = list_nodeB

cur_idx = 0
for num in listB:
    cur_node.next = ListNode(num)
    cur_node = cur_node.next
    if cur_idx == skipB:
        cur_node.next = common_node
        break
    cur_idx += 1

headA = list_nodeA.next
headB = list_nodeB.next
pA, pB = headA, headB
while pA != pB:
    pA = headB if pA is None else pA.next
    pB = headA if pB is None else pB.next

if pA:
    print(pA.val)
else:
    print(0)

```
