## 题目

给定一个单链表的头节点 `head` 和一个整数 `k`，请将链表中的节点每 `k` 个一组进行翻转，并返回翻转后的链表头节点。

如果最后剩余的节点数量不足 `k` 个，则保持原有顺序不变。

要求不能只修改节点内部的值，而需要实际修改节点之间的连接关系。

**输入格式**

第一行输入一个整数 `n`，表示链表节点数量。

第二行输入 `n` 个整数，表示链表中各节点的值。

第三行输入一个整数 `k`，表示每组翻转的节点数量。

**输出格式**

输出每 `k` 个节点翻转后的链表，节点值之间用空格分隔。

**输入示例**

```text
5
1 2 3 4 5
2
```

**输出示例**

```text
2 1 4 3 5
```

**说明**

原链表为：

```text
1 -> 2 -> 3 -> 4 -> 5
```

每 `2` 个节点一组翻转后：

```text
2 -> 1 -> 4 -> 3 -> 5
```

最后剩余的节点数量不足 `2` 个，因此保持不变。

**数据范围**

-   `0 <= n <= 100000`
-   `1 <= k <= n`
-   `-10^9 <= val <= 10^9`

## 思路

-   先从当前组起点向后走 `k` 个节点，**判断剩余节点是否足够一组**；不足 `k` 个直接结束。
-   记录下一组起点 `next_node`，然后把当前这 `k` 个节点**原地反转**，并让最后一个节点连接到 `next_node`。
-   反转完成后，让 `prev` 移到**当前组翻转后的尾节点**，`cur` 移到下一组起点，继续处理。

## 代码

```python
class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        dummy = ListNode(0)
        dummy.next = head
        prev = dummy
        cur = head

        while cur:
            cnt = 0
            while cur and cnt < k:
                cur = cur.next
                cnt += 1

            if cnt < k:  
                break

            next_node = cur if cur else None
            cur_ptr = prev.next
            prev_ptr = next_node
            while cur_ptr != cur:
                next_ptr = cur_ptr.next
                cur_ptr.next = prev_ptr
                prev_ptr = cur_ptr
                cur_ptr = next_ptr

            tail_node = prev.next 
            prev.next = prev_ptr
            prev = tail_node  
            cur = next_node if next_node else None

        return dummy.next
```
