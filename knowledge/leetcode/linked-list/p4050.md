## 题目

给定单链表的头节点 `head`，请将链表按节点值从小到大排序，并返回排序后的链表。

要求尽量使用 `O(n log n)` 的时间复杂度。

**输入格式**

第一行输入一个整数 `n`，表示链表节点数量。

第二行输入 `n` 个整数，表示链表中各节点的值。

**输出格式**

输出排序后的链表，节点值之间用空格分隔。

**输入示例**

```text
4
4 2 1 3
```

**输出示例**

```text
1 2 3 4
```

**说明**

原链表为：

```text
4 -> 2 -> 1 -> 3
```

排序后为：

```text
1 -> 2 -> 3 -> 4
```

**数据范围**

-   `0 <= n <= 100000`
-   `-10^9 <= val <= 10^9`

## 思路

-   用**快慢指针找到链表中点**，把链表拆成左右两部分。 （见3.2）
-   分别递归排序左右链表。
-   最后像**合并两个有序链表**一样，将两部分合并。

## 代码

```python
class Solution:
    def sortList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return head
        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        mid = slow.next
        slow.next = None

        left = self.sortList(head)
        right = self.sortList(mid)

        cur1, cur2 = left, right
        dummy = ListNode(0)
        res_head = dummy
        while cur1 and cur2:
            if cur1.val >= cur2.val:
                res_head.next = cur2
                cur2 = cur2.next
            else:
                res_head.next = cur1
                cur1 = cur1.next

            res_head = res_head.next

        res_head.next = cur1 if cur1 else cur2
        
        return dummy.next
```
