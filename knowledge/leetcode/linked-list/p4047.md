## 题目

给定一个单链表的头节点 `head`，请两两交换其中相邻的节点，并返回交换后的链表头节点。

要求不能只修改节点内部的值，而需要实际交换节点。

**输入格式**

第一行输入一个整数 `n`，表示链表节点数量。

第二行输入 `n` 个整数，表示链表中各节点的值。

**输出格式**

输出两两交换后的链表，节点值之间用空格分隔。

**输入示例**

```text
4
1 2 3 4
```

**输出示例**

```text
2 1 4 3
```

**说明**

原链表为：

```text
1 -> 2 -> 3 -> 4
```

两两交换后：

```text
2 -> 1 -> 4 -> 3
```

**数据范围**

-   `0 <= n <= 100000`
-   `-10^9 <= val <= 10^9`

## 思路

-   用 `prev` 指向**当前这一对节点的前一个节点**，`cur_node` 指向这一对的第一个节点。
-   记录第二个节点 `other` 和下一组起点 `next_node`。
-   依次修改指针：`other -> cur_node -> next_node`，再让 `prev.next = other`。
-   交换完成后，`prev` 移到 `cur_node`，`cur_node` 移到 **下一组起点**，继续处理

## 代码

```python
class Solution:
    def swapPairs(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head:
            return
        dummy = ListNode(0)
        dummy.next = head
        cur_node, prev = head, dummy
        while cur_node and cur_node.next:
            other = cur_node.next
            next_node = other.next

            other.next = cur_node
            cur_node.next = next_node
            prev.next = other

            prev = cur_node
            cur_node = next_node

        return dummy.next
```
