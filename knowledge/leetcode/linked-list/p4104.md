## 题目

给定一个单链表的头节点 `head`，如果链表中存在环，请返回环开始的第一个节点。

如果链表中不存在环，则返回 `null`。

要求不能修改链表结构。

**输入格式**

第一行输入一个整数 `n`，表示链表节点数量。

第二行输入 `n` 个整数，表示链表中各节点的值。

第三行输入一个整数 `pos`，表示链表尾节点连接到链表中的位置下标。

如果 `pos = -1`，表示链表中没有环。

**输出格式**

如果链表中存在环，输出环入口节点的值。

如果不存在环，输出：

```text
null
```

**输入示例**

```text
4
3 2 0 -4
1
```

**输出示例**

```text
2
```

**说明**

链表尾节点连接到下标 `1` 的节点，因此环入口节点的值为 `2`。

**数据范围**

-   `0 <= n <= 100000`
-   `-1 <= pos < n`
-   `-10^9 <= val <= 10^9`

## 思路

-   判断是否存在环：用**快慢指针**，`slow` 每次走 1 步，`fast` 每次走 2 步，若两者相遇则说明存在环。
-   找环入口：第一次相遇后，将 `slow` 放回 `head`，再让两个指针**每次都走 1 步**，再次相遇的位置就是环入口。

## 代码

```python

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = fast = head
        while fast and fast.next:
            fast = fast.next.next
            slow = slow.next
            if fast == slow:
                slow = head
                while fast != slow:
                    fast = fast.next
                    slow = slow.next
                return slow

        return None

```
