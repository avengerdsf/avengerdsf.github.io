## 题目

请设计并实现一个满足 LRU（最近最少使用）缓存约束的数据结构。

缓存具有固定容量 `capacity`，支持以下两种操作：

-   `get key`：如果 `key` 存在，返回对应的值，并将该键标记为**最近使用**；如果不存在，返回 `-1`。
-   `put key value`：插入或更新键值对，并将该键标记为**最近使用**；如果缓存容量已满，则删除**最久未使用**的键值对。

**输入格式**

第一行输入两个整数 `capacity` 和 `m`，分别表示缓存容量和操作次数。

接下来 `m` 行，每行表示一次操作：

```text
put key value
```

或：

```text
get key
```

**输出格式**

对于每次 `get` 操作，输出查询结果。

**输入示例**

```text
2 9
put 1 1
put 2 2
get 1
put 3 3
get 2
put 4 4
get 1
get 3
get 4
```

**输出示例**

```text
1
-1
-1
3
4
```

**说明**

缓存容量为 `2`。

执行 `get 1` 后，键 `1` 变为最近使用。

执行 `put 3 3` 时，键 `2` 是最久未使用的，因此被删除。

执行 `put 4 4` 时，键 `1` 是最久未使用的，因此被删除。

**数据范围**

-   `1 <= capacity <= 10000`
-   `1 <= m <= 100000`
-   `0 <= key, value <= 10^9`

## 思路

相关笔记：[P4899 · LRU缓存（哈希表）](leetcode/hash-table/p4899.md)。

两种实现都维护缓存的使用顺序：最前面是最久未使用的元素，最后面是最近使用的元素。`get` 命中和 `put` 更新都会把对应元素移动到末尾。

## 解法一 OrderedDict

### 思路

-   使用 `OrderedDict` 保存缓存，**前面表示最久未使用，后面表示最近使用**。
-   `get`：不存在返回 `-1`；存在则先 `pop` 再重新插入，使它移动到**最后面**。
-   `put`：如果原来存在就先更新其使用顺序，再写入新值；超过容量时用 `popitem(False)`**删除最前面的元素**。

### 代码

```python
class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.cache = OrderedDict()

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1

        val = self.cache.pop(key)
        self.cache[key] = val
        return val

    def put(self, key: int, value: int) -> None:
        val = self.get(key)
        self.cache[key] = value

        if len(self.cache) > self.capacity:
            self.cache.popitem(False)

```

### 注意点

#### OrderedDict的使用

独立运行时需要先导入 `from collections import OrderedDict`。

-   `OrderedDict()`：创建一个**维护插入顺序的字典**。
-   `key in cache`：判断 `key` **是否存在**，不能用 `cache.get(key)` 代替存在性判断。
-   `cache.pop(key)`：删除指定 `key`，并返回对应的 `value`。
-   `cache[key] = value`：将键值对插入到**末尾**。
-   `cache.popitem(False)`：删除**最前面的键值对**，适合淘汰最久未使用的数据。
-   `cache.popitem()`：默认删除**最后面的键值对**。

## 解法二 哈希表与双向链表

### 思路

-   **初始化**：使用哈希表存储 `key → 节点`，双向链表维护使用顺序，头部最久未使用，尾部最近使用。
-   **put**：若 `key` 已存在，更新节点值并移动到尾部；否则创建节点并插入尾部。
-   **容量检查**：若超过 `capacity`，通过 `head.next` 删除最久未使用的节点，并同步删除哈希表记录。
-   **get**：通过哈希表快速定位节点，存在则先摘除节点，再插到当前 `tail.prev` 后面并返回值；不存在则返回 `-1`。

哈希表定位节点、双向链表摘除节点和尾部插入都只需要常数次操作，因此 `get` 和 `put` 的平均时间复杂度为 `O(1)`，空间复杂度为 `O(capacity)`。

### 代码

```python
class ListNode:
    def __init__(self, key, val):
        self.key = key
        self.val = val
        self.prev = None
        self.next = None


class LRU:
    def __init__(self, capacity):
        self.cache = {}
        self.capacity = capacity
        self.head = ListNode(0, 0)
        self.tail = ListNode(0, 0)

    def put(self, key, value):
        if key in self.cache:
            self.cache[key].val = value
            self.get(key)
            return

        node = ListNode(key, value)
        if not self.head.next and not self.tail.next:
            self.head.next = node
            node.prev = self.head
        else:
            tail_node = self.tail.prev
            tail_node.next = node
            node.prev = tail_node

        node.next = self.tail
        self.tail.prev = node
        self.cache[key] = node

        if len(self.cache.keys()) > self.capacity:
            head_node = self.head.next
            print(f"pop:{head_node.key}")
            next_node = head_node.next
            self.head.next = next_node
            next_node.prev = self.head

            self.cache.pop(head_node.key)

            print(f"head_node:{self.head.next.val}")
            print(f"capacity:{self.capacity}")

    def get(self, key):
        if self.cache.get(key):
            node = self.cache[key]
            pre_node = node.prev
            next_node = node.next

            pre_node.next = next_node
            next_node.prev = pre_node

            tail_node = self.tail.prev
            tail_node.next = node
            node.prev = tail_node
            node.next = self.tail
            self.tail.prev = node

            return node.val
        else:
            return -1


def main():
    capacity, m = map(int, input().split())
    lru = LRU(capacity)

    for _ in range(m):
        datas = list(input().split())
        typ = datas[0]
        if typ == "put":
            key, val = map(int, datas[1:])
            lru.put(key, val)
        if typ == "get":
            key = int(datas[1])
            val = lru.get(key)
            print(val)


if __name__ == "__main__":
    main()
```

### 注意点

-   `head` 和 `tail` 是哨兵节点，真实节点位于两者之间；`head.next` 指向最久未使用的节点，`tail.prev` 指向最近使用的节点。这段实现在首次 `put` 时连接链表。
-   移动节点时先修复原位置的前后指针，再读取当前 `tail.prev` 并插入尾部；这样可以处理被访问节点原本就在尾部的情况。
-   `cache` 保存节点对象，`self.cache.get(key)` 返回的是节点；即使节点的 `val` 为 `0`，仍然可以正常命中。
-   淘汰节点时的三条 `print` 会额外输出 `pop:`、`head_node:`、`capacity:`。题目要求只输出 `get` 的结果，提交时需要去掉这三条调试输出，保留 `main` 中输出查询结果的 `print(val)`。
