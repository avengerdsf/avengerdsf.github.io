## 题目

请设计并实现一个满足 LRU（最近最少使用）缓存约束的数据结构。

缓存具有固定容量 `capacity`，支持以下两种操作：

-   `get key`：如果 `key` 存在，返回对应的值，并将该键标记为**最近使用**；如果不存在，返回 `-1`。
-   `put key value`：插入或更新键值对，并将该键标记为**最近使用**；如果缓存容量已满，则删除**最久未使用**的键值对。

**输入格式**

第一行输入两个整数 `capacity` 和 `m`，分别表示缓存容量和操作次数。

接下来 `m` 行，每行表示一次操作：

```text
put key value
```

或：

```text
get key
```

**输出格式**

对于每次 `get` 操作，输出查询结果。

**输入示例**

```text
2 9
put 1 1
put 2 2
get 1
put 3 3
get 2
put 4 4
get 1
get 3
get 4
```

**输出示例**

```text
1
-1
-1
3
4
```

**说明**

缓存容量为 `2`。

执行 `get 1` 后，键 `1` 变为最近使用。

执行 `put 3 3` 时，键 `2` 是最久未使用的，因此被删除。

执行 `put 4 4` 时，键 `1` 是最久未使用的，因此被删除。

**数据范围**

-   `1 <= capacity <= 10000`
-   `1 <= m <= 100000`
-   `0 <= key, value <= 10^9`

## 思路

-   使用 `OrderedDict` 保存缓存，**前面表示最久未使用，后面表示最近使用**。
-   `get`：不存在返回 `-1`；存在则先 `pop` 再重新插入，使它移动到**最后面**。
-   `put`：如果原来存在就先更新其使用顺序，再写入新值；超过容量时用 `popitem(False)`**删除最前面的元素**。

## 代码

```python
class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.cache = OrderedDict()

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1

        val = self.cache.pop(key)
        self.cache[key] = val
        return val

    def put(self, key: int, value: int) -> None:
        val = self.get(key)
        self.cache[key] = value

        if len(self.cache) > self.capacity:
            self.cache.popitem(False)

```

## 注意点

### OrderedDict的使用

-   `OrderedDict()`：创建一个**维护插入顺序的字典**。
-   `key in cache`：判断 `key` **是否存在**，不能用 `cache.get(key)` 代替存在性判断。
-   `cache.pop(key)`：删除指定 `key`，并返回对应的 `value`。
-   `cache[key] = value`：将键值对插入到**末尾**。
-   `cache.popitem(False)`：删除**最前面的键值对**，适合淘汰最久未使用的数据。
-   `cache.popitem()`：默认删除**最后面的键值对**。
