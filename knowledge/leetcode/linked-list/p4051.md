## 题目

给定一个链表数组 `lists`，其中每个链表都已经按升序排列。

请将所有链表合并为一个升序链表，并返回合并后的链表。

**输入格式**

第一行输入一个整数 `k`，表示链表的数量。

接下来依次输入 `k` 个链表：

每个链表先输入一个整数 `n`，表示该链表的节点数量。

下一行输入 `n` 个整数，表示该升序链表中的节点值。

**输出格式**

输出合并后的升序链表，节点值之间用空格分隔。

**输入示例**

```text
3
3
1 4 5
3
1 3 4
2
2 6
```

**输出示例**

```text
1 1 2 3 4 4 5 6
```

**说明**

三个链表分别为：

```text
1 -> 4 -> 5
1 -> 3 -> 4
2 -> 6
```

合并后为：

```text
1 -> 1 -> 2 -> 3 -> 4 -> 4 -> 5 -> 6
```

**数据范围**

-   `0 <= k <= 10000`
-   所有链表节点总数不超过 `100000`
-   `-10^9 <= val <= 10^9`

## 思路

-   分治：把 `lists`**从中间分成两半**，递归合并左右两部分。
-   合并：得到两个有序链表后，使用双指针，**每次连接较小的节点**。
-   收尾：其中一个链表结束后，把**另一个链表剩余部分直接接到末尾**。
-   返回：递归不断合并，最终得到一个完整的升序链表。

## 代码

```python
class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        n = len(lists)
        if n == 0:
            return None
        if n == 1:
            return lists[-1]

        lists1 = self.mergeKLists(lists[:n//2])
        lists2 = self.mergeKLists(lists[n//2:])

        dummy = ListNode(0)
        cur = dummy

        l1, l2 = lists1, lists2
        while l1 and l2:
            if l1.val >= l2.val:
                cur.next = l2
                l2 = l2.next
            else:
                cur.next = l1
                l1 = l1.next

            cur = cur.next

        cur.next = l1 if l1 else l2

        return dummy.next
```
