## 题目

给定一个单链表的头节点 `head`，将链表中节点的连接方向反转，并返回反转后的头节点。

反转后，原来的尾节点成为新的头节点，节点排列顺序与原来相反。

每个节点包含整数值 `val` 和指向后继节点的指针 `next`。如果链表为空，`head` 为 `None`。

**输入描述**

第一行输入整数 `n`，表示链表的节点数量。

第二行输入 `n` 个整数，依次表示原链表从头到尾的节点值。

如果采用函数形式作答，输入参数为头节点 `head`，类型为 `Optional[ListNode]`。

**输出描述**

输出反转后的节点值，数字之间用空格分隔。

如果采用函数形式作答，返回反转后的头节点，类型为 `Optional[ListNode]`。

**数据范围**

-   `0 ≤ n ≤ 5000`。
-   `-5000 ≤ val ≤ 5000`。

**样例 1**

输入：

```text
4
1 -2 3 -4
```

输出：

```text
-4 3 -2 1
```

说明：原链表为 `1 → -2 → 3 → -4`，反转后为 `-4 → 3 → -2 → 1`。

**样例 2**

输入：

```text
1
42
```

输出：

```text
42
```

说明：链表只有一个节点，反转后不变。

**样例 3**

输入：

```text
6
2 2 0 -1 5 5
```

输出：

```text
5 5 -1 0 2 2
```

说明：将原链表的节点顺序完全反转，新的头节点为原来的最后一个节点。

## 思路

-   **保存下一个节点，再让当前节点指向前一个节点**。
-   `pre_node` 移到当前节点，`cur_node` 移到保存的下一个节点。
-   重复直到 `cur_node` 为空，`pre_node` **就是反转后的头节点**。

## 代码

```python
n = int(input())
nums = list(map(int, input().split()))

class ListNode:
    def __init__(self, val):
        self.val = val
        self.next = None

head_node = ListNode(0)
cur_node = head_node

for i in range(n):
    cur_node.next = ListNode(nums[i])
    cur_node = cur_node.next

cur_node = head_node.next
pre_node = None
while cur_node:
    next_node = cur_node.next
    cur_node.next = pre_node
    pre_node = cur_node
    cur_node = next_node

res = []
while pre_node:
    res.append(pre_node.val)
    pre_node = pre_node.next

print(' '.join(map(str, res)))
```
