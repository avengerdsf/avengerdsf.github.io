## 题目

给定一个单链表的头节点 `head` 和一个整数 `n`，请删除链表的倒数第 `n` 个结点，并返回删除后的链表头节点。

**输入格式**

第一行输入一个整数 `m`，表示链表节点数量。

第二行输入 `m` 个整数，表示链表中各节点的值。

第三行输入一个整数 `n`，表示要删除倒数第 `n` 个结点。

**输出格式**

输出删除指定节点后的链表，节点值之间用空格分隔。

**输入示例**

```text
5
1 2 3 4 5
2
```

**输出示例**

```text
1 2 3 5
```

**说明**

原链表为：

```text
1 -> 2 -> 3 -> 4 -> 5
```

倒数第 `2` 个结点为 `4`，删除后得到：

```text
1 -> 2 -> 3 -> 5
```

**数据范围**

-   `1 <= m <= 100000`
-   `1 <= n <= m`
-   `-10^9 <= val <= 10^9`

## 思路

-   先让 `fast`提前走** `**n` **步**。
-   再让 `fast`、`slow` 同时移动，并用 `prev` 记录 `slow` **的前一个节点**。
-   当 `fast` 到末尾时，`slow` 正好指向**倒数第** `n` **个节点**。
-   执行 `prev.next = slow.next` 删除该节点，最后返回 `dummy.next`。

## 代码

```python
class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        fast, slow = head, head
        dummy = ListNode(0)
        dummy.next = head
        prev = dummy
        move_cnt = 0
        while fast:
            if move_cnt < n:
                move_cnt += 1
                fast = fast.next
                continue

            fast = fast.next
            prev = slow
            slow = slow.next

        prev.next = slow.next
        
        return dummy.next
```
