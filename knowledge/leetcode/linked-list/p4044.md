## 题目

给定两个按升序排列的单链表 `list1` 和 `list2`，请将它们合并为一个新的升序链表。

新链表由原来两个链表中的所有节点组成。

**输入格式**

第一行输入一个整数 `n`，表示第一个链表的节点数量。

第二行输入 `n` 个整数，表示第一个升序链表。

第三行输入一个整数 `m`，表示第二个链表的节点数量。

第四行输入 `m` 个整数，表示第二个升序链表。

**输出格式**

输出合并后的升序链表，节点值之间用空格分隔。

**输入示例**

```text
3
1 2 4
3
1 3 4
```

**输出示例**

```text
1 1 2 3 4 4
```

**说明**

两个链表分别为：

```text
1 -> 2 -> 4
1 -> 3 -> 4
```

合并后为：

```text
1 -> 1 -> 2 -> 3 -> 4 -> 4
```

**数据范围**

-   `0 <= n, m <= 100000`
-   `-10^9 <= val <= 10^9`

## 思路

-   用两个指针分别遍历两个有序链表，每次把**较小的节点接到新链表后面**。
-   其中一个链表遍历结束后，把**另一个链表剩余部分直接接到末尾**。

## 题目

```python
class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        cur1, cur2 = list1, list2
        dummy = ListNode(0)
        node = dummy
        while cur1 and cur2:
            if cur1.val <= cur2.val:
                node.next = cur1
                cur1 = cur1.next
            else:
                node.next = cur2
                cur2 = cur2.next
                
            node = node.next
            
        if cur1:
            node.next = cur1
        else:
            node.next = cur2
            
        return dummy.next
```
