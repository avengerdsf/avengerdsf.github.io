## 题目

给定一个单链表的头节点 `head`，请判断该链表是否为回文链表。

如果链表从前往后和从后往前读取的节点值完全相同，则该链表是回文链表。

**输入格式**

第一行输入一个整数 `n`，表示链表节点数量。

第二行输入 `n` 个整数，表示链表中各节点的值。

**输出格式**

如果链表是回文链表，输出：

```text
true
```

否则输出：

```text
false
```

**输入示例**

```text
4
1 2 2 1
```

**输出示例**

```text
true
```

**说明**

链表为：

```text
1 -> 2 -> 2 -> 1
```

正向和反向读取结果相同，因此是回文链表。

**数据范围**

-   `1 <= n <= 100000`
-   `-10^9 <= val <= 10^9`

## 思路

-   构造链表：根据数组依次创建节点。
-   找中点：用**快慢指针**定位链表中间位置。

-   `slow` 从**头节点**开始。
-   `fast` 从**下一个节点**开始。
-   `slow` 每次走 1 步，`fast` 每次走 2 步。
-   循环结束后，`slow.next` **就是后半段起点** `mid`。

-   反转后半部分：从 `mid` 开始**反转链表后半段**。
-   前后比较：从链表头和反转后的后半部分同时遍历，**逐个比较节点值**，全部相同则为回文链表。。

## 代码

```python
n = int(input())
nums = list(map(int, input().split()))

class ListNode:
    def __init__(self, val):
        self.val = val
        self.next = None

head_node = ListNode(0)
cur_node = head_node
for num in nums:
    cur_node.next = ListNode(num)
    cur_node = cur_node.next

fast_node, slow_node = head_node.next, head_node.next
cnt = 0
while fast_node and fast_node.next:
    fast_node = fast_node.next.next
    slow_node = slow_node.next

mid_node = slow_node if cnt % 2 == 0 else slow_node.next

cur_node = mid_node
pre_node = None
while cur_node:
    next_node = cur_node.next
    cur_node.next = pre_node
    pre_node = cur_node
    cur_node = next_node

cur_node2 = pre_node
cur_node = head_node.next
while cur_node2:
    if cur_node.val != cur_node2.val:
        print('false')
        exit()
    cur_node2 = cur_node2.next
    cur_node = cur_node.next

print('true')

```
