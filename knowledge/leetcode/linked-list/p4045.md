## 题目

给定两个非空链表，分别表示两个非负整数。

数字按照**逆序**存储，每个节点只存储一位数字。

请将两个数相加，并返回一个表示结果的链表。

可以假设除了数字 `0` 之外，这两个数都不会以 `0` 开头。

**输入格式**

第一行输入第一个链表的节点数量 `n`。

第二行输入 `n` 个整数，表示第一个链表。

第三行输入第二个链表的节点数量 `m`。

第四行输入 `m` 个整数，表示第二个链表。

**输出格式**

输出相加后的链表，节点值之间用空格分隔。

**输入示例**

```text
3
2 4 3
3
5 6 4
```

**输出示例**

```text
7 0 8
```

**说明**

两个链表分别表示：

```text
342
465
```

相加得到：

```text
807
```

因此结果链表为：

```text
7 -> 0 -> 8
```

**数据范围**

-   `1 <= n, m <= 100`
-   `0 <= val <= 9`

## 思路

-   同时遍历两个链表，当前位相加时还要加上**进位** `next_num`。
-   当前节点保存 `sum % 10`，新的进位保存 `sum // 10`。
-   如果一个链表先结束，就继续处理**剩余链表和进位**。
-   最后若还有进位，再新建一个节点接到末尾。

## 代码

```python

class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        cur1 = l1
        cur2 = l2
        next_num = 0
        dummy = ListNode(0)
        node = dummy
        while cur1 and cur2:
            node.next = ListNode((cur1.val + cur2.val + next_num) % 10)
            next_num = (cur1.val + cur2.val + next_num) // 10
            cur2, cur1 = cur2.next, cur1.next
            node = node.next
        
        if cur1:
            cur1.val = cur1.val + next_num
            node.next = cur1
        elif cur2:
            cur2.val = cur2.val + next_num
            node.next = cur2
        elif next_num != 0:
            node.next = ListNode(next_num)
        return dummy.next

```
