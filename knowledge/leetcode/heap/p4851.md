## 题目

维护一个集合，初始时给定一个长度为 `n` 的整数数组，数组中的每个数都在集合中。

接下来需要执行 `m` 次操作，请使用小根堆实现以下功能：

-   `I x`：向集合中**插入**整数 `x`。
-   `PM`：输出当前集合中的**最小值**。
-   `DM`：**删除**当前集合中的最小值。

数据保证执行 `DM` 操作时，当前集合中的最小值唯一。

**输入格式**

第一行输入两个整数 `n` 和 `m`，分别表示初始数组长度和操作次数。

第二行输入 `n` 个整数，表示初始数组。

接下来 `m` 行，每行输入一条操作指令。

**输出格式**

对于每次 `PM` 操作，输出当前集合中的最小值，每个结果占一行。

**输入示例**

```text
3 5
4 1 7
PM
I -5
PM
DM
PM
```

**输出示例**

```text
1
-5
1
```

**说明**

-   初始集合为 `[4, 1, 7]`，最小值为 `1`。
-   执行 `I -5`，插入 `-5`。
-   执行 `PM`，当前最小值为 `-5`。
-   执行 `DM`，删除最小值 `-5`。
-   再次执行 `PM`，当前最小值为 `1`。

**数据范围**

-   `1 <= n, m <= 100000`
-   `-10^9 <= x <= 10^9`

## 思路

-   使用**数组模拟完全二叉树**，满足小根堆中**父节点不大于子节点**的性质。
-   插入元素：先放到数组末尾，再通过 `heapify_up()` **上浮**，恢复小根堆。
-   删除堆顶：先将**堆顶与末尾元素交换**，删除末尾元素，再通过 `heapify_down()` **下沉**。
-   查询最小值：直接返回 `heap[0]`。

## 代码

```python
from typing import List, Optional

class MinHeap:
    def __init__(self) -> None:
        self.heap: List[int] = []
        self.size: int = 0

    def push(self, x: int) -> None:
        self.heap.append(x)
        self.size += 1

        self.heapify_up(self.size - 1)

    def pop(self) -> Optional[int]:
        if self.size == 0:
            return

        self.heap[0], self.heap[-1] = self.heap[-1], self.heap[0]
        self.heap.pop()
        self.size -= 1
        self.heapify_down(0)

    def heapify_up(self, index: int) -> None:
        father_node = (index - 1)//2 #2i + 1 = l
        if father_node >= 0 and self.heap[father_node] > self.heap[index]:
            self.heap[father_node], self.heap[index] = self.heap[index], self.heap[father_node]
            self.heapify_up(father_node)

    def heapify_down(self, index: int) -> None:
        left, right = 2*index+1, 2*index+2

        small_idx = index
        if left < self.size and self.heap[left] < self.heap[small_idx]:
            small_idx = left

        if right < self.size and self.heap[right] < self.heap[small_idx]:
            small_idx = right

        if index != small_idx:
            self.heap[small_idx], self.heap[index] = self.heap[index], self.heap[small_idx]
            self.heapify_down(small_idx)

def main() -> None:
    n, m = map(int, input().split())
    arr = list(map(int, input().split()))
    min_heap = MinHeap()
    for x in arr:
        min_heap.push(x)
    for _ in range(m):
        op = input().split()
        if op[0] == "PM":
            print(min_heap.heap[0])
        elif op[0] == "DM":
            min_heap.pop()
        elif op[0] == "I":
            min_heap.push(int(op[1]))

if __name__ == "__main__":
    main()
```

## 注意点

### 上浮

插入新元素时，先将其放在堆的末尾，然后不断与父节点比较。如果当前节点小于父节点，就交换两者并继续向上比较，直到当前节点不小于父节点或到达根节点。

![image.png](leetcode/assets/堆-1.gif)

### 下沉

删除堆顶时，先将末尾元素与堆顶交换并删除末尾元素，再将新的堆顶与左右孩子比较。如果当前节点不是三者中最小的，就与较小的子节点交换并继续向下比较，直到满足小根堆性质或到达叶子节点。
