## 题目

给定一个整数数组 `nums` 和一个整数 `k`，请找出数组中第 `k` 个最大的元素。

重复元素计入排名，返回数组排序后第 `k` 个最大的元素。

**输入格式**

第一行输入两个整数 `n` 和 `k`，分别表示数组长度和需要查找的排名。

第二行输入 `n` 个整数，表示数组 `nums`。

**输出格式**

输出一个整数，表示数组中第 `k` 大的元素。

**输入示例**

```text
6 2
3 2 1 5 6 4
```

**输出示例**

```text
5
```

**说明**

数组按降序排列后为：

```text
6 5 4 3 2 1
```

其中第 `2` 大的元素为 `5`。

**另一个示例**

```text
9 4
3 2 3 1 2 4 5 5 6
```

**输出示例**

```text
4
```

**说明**

数组按降序排列后为：

```text
6 5 5 4 3 3 2 2 1
```

第 `4` 大的元素为 `4`，重复元素也需要计入排名。

**数据范围**

-   `1 <= k <= n`
-   数组元素可以重复。

## 思路

维护一个大小为 `k`的小根堆，遍历数组不断执行 `heappush()`，当堆大小超过 `k`时，通过 `heappop()`删除最小元素，最终堆中保留最大的 `k`个元素，堆顶 `heap[0]`即为第 `k`大的元素。

## 代码

```python

class Solution:

    def findKthLargest(self, nums: List[int], k: int) -> int:
        heap = []
        for i in range(len(nums)):
            heapq.heappush(heap, nums[i])
            
            if len(heap) > k:
                heapq.heappop(heap)
                
        return heap[0]
```

## 注意点

代码片段使用 `heapq` 和 `List`，独立运行时需要导入 `heapq` 及 `typing.List`。

### heapq.heappush

```python
heapq.heappush(
    heap: list[SupportsRichComparisonT],
    item: SupportsRichComparisonT,
    /
) -> None

# 输入：heap（堆列表）、item（待插入元素）
# 输出：None，直接修改原堆
# heapq 默认按元素的字典序比较，优先比较第一个元素，相同再比较第二个元素。
```

### heapq.heappop

```python
heapq.heappop(
    heap: list[SupportsRichComparisonT],
    /
) -> SupportsRichComparisonT

# 输入：heap（堆列表）
# 输出：弹出并返回堆中的最小元素
```
