## 题目

给定一个整数数组 `nums` 和一个整数 `k`，请找出数组中**出现频率最高的** `k` **个元素**。

返回结果的顺序可以任意。

**输入格式**

第一行输入两个整数 `n` 和 `k`，其中 `n` 表示数组长度，`k` 表示需要返回的元素数量。

第二行输入 `n` 个整数，表示数组 `nums`。

**输出格式**

输出 `k` 个整数，表示出现频率最高的 `k` 个元素，顺序不限。

**输入示例**

```text
6 2
1 1 1 2 2 3
```

**输出示例**

```text
1 2
```

**说明**

-   元素 `1` 出现 `3` 次。
-   元素 `2` 出现 `2` 次。
-   元素 `3` 出现 `1` 次。

因此出现频率最高的两个元素为 `1` 和 `2`。

**另一个示例**

```text
1 1
1
```

**输出示例**

```text
1
```

**数据范围**

-   `1 <= n <= 100000`
-   `1 <= k <= 数组中不同元素的数量`
-   保证前 `k` 个高频元素的集合唯一。

## 思路

-   使用哈希表 `record`统计每个数字的出现频率。
-   维护大小为 `k`的小根堆，存储 `[freq, num]`，优先按频率 `freq`比较。
-   当堆大小超过 `k`时，使用 `heappop()`弹出频率最小的元素。
-   最后堆中保留出现频率最高的 `k`个数字，通过 `res[1]`提取数字并返回。

## 代码

```python
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        record = {}
        for num in nums:
            record[num] = record.get(num, 0) + 1

        heap = []
        for num, freq in record.items():
            heapq.heappush(heap, [freq, num])

            if len(heap) > k:
                heapq.heappop(heap)

        return [res[1] for res in heap]
```

## 注意点

代码片段使用 `heapq` 和 `List`，独立运行时需要导入 `heapq` 及 `typing.List`。
