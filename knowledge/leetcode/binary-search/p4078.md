## 题目

给定一个原本按升序排列、且元素互不相同的整数数组 `nums`。

该数组经过若干次旋转后得到当前序列，请找出数组中的最小值。

例如：

```text
原数组：0 1 2 4 5 6 7
旋转后：4 5 6 7 0 1 2
```

此时最小值为 `0`。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个整数，表示旋转后的数组 `nums`。

**输出格式**

输出数组中的最小值。

**输入示例**

```text
5
3 4 5 1 2
```

**输出示例**

```text
1
```

**说明**

数组由升序数组旋转得到，最小值位于旋转断点处。

## 思路

-   使用**二分查找**，比较 `nums[mid]` 和 `nums[right]`。
-   如果 `nums[mid] > nums[right]`，说明最小值在右半边，令 `left = mid + 1`。
-   否则最小值在 `mid` **或左半边**，令 `right = mid`。
-   当 `left == right` 时，该位置就是最小值。

## 代码

```python
class Solution:
    def findMin(self, nums: List[int]) -> int:
        left, right = 0, len(nums) - 1

        while left < right:  # 修改1：因为 right = mid，所以用 left < right
            mid = (left + right) // 2

            if nums[mid] > nums[right]:
                left = mid + 1
            else:
                right = mid  # 修改2：mid 可能就是最小值，不能丢掉

        return nums[left]  # 修改3：循环结束后再返回
```
