## 题目

给定一个 `m × n` 的整数矩阵 `matrix` 和一个目标值 `target`。

矩阵满足以下性质：

-   每一行中的整数从左到右升序排列。
-   每一行的第一个整数都大于前一行的最后一个整数。

请判断目标值 `target` 是否存在于矩阵中。

**输入格式**

第一行输入两个整数 `m` 和 `n`，分别表示矩阵的行数和列数。

接下来输入 `m` 行，每行包含 `n` 个整数，表示矩阵。

最后一行输入一个整数 `target`。

**输出格式**

如果矩阵中存在 `target`，输出：

```text
true
```

否则输出：

```text
false
```

**输入示例**

```text
3 4
1 3 5 7
10 11 16 20
23 30 34 60
3
```

**输出示例**

```text
true
```

**说明**

矩阵整体可以看作一个升序数组：

```text
1 3 5 7 10 11 16 20 23 30 34 60
```

目标值 `3` 存在于矩阵中，因此输出 `true`。

## 思路

-   先对每一行的**第一个元素做二分**，找到最后一个满足 `matrix[row][0] <= target` 的行。
-   再在这一行中做一次**普通二分查找**，判断 `target` 是否存在。

## 代码

```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        top, bottom = 0, len(matrix) - 1
        while top <= bottom:
            mid = (top + bottom)//2
            if matrix[mid][0] == target:
                return True
            elif matrix[mid][0] > target:
                bottom = mid - 1
            else:
                top = mid + 1

        row = bottom
        left, right = 0, len(matrix[0]) - 1
        while left <= right:
            mid = (left + right)//2
            if matrix[row][mid] == target:
                return True
            elif matrix[row][mid] > target:
                right -= 1
            else:
                left += 1

        return False
```
