## 题目

给定一个升序排列的整数数组 `nums` 和一个目标值 `target`。

如果 `target` 存在于数组中，返回它的下标；如果不存在，则返回它按照升序插入数组后应该所在的位置。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个升序整数，表示数组 `nums`。

第三行输入一个整数 `target`。

**输出格式**

输出一个整数，表示 `target` 的下标或插入位置。

**输入示例**

```text
4
1 3 5 6
5
```

**输出示例**

```text
2
```

**另一个示例**

```text
4
1 3 5 6
2
```

输出：

```text
1
```

**说明**

`2` 不在数组中，插入到下标 `1` 后，数组仍保持升序排列。

## 思路

使用**二分查找**；若找到 `target` 直接返回下标，否则不断缩小搜索区间，循环结束后 `left` **正好指向 target 应插入的位置**。

## 代码

```python
class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right)//2
            if nums[mid] == target:
                return mid
            elif nums[mid] > target:
                right = mid - 1
            else:
                left = mid + 1

        return left
```
