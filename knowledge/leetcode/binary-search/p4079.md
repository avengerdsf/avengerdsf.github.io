## 题目

给定两个已经按升序排列的整数数组 `nums1` 和 `nums2`，请找出并返回这两个数组合并后的中位数。

中位数是指将数组按升序排列后，位于最中间的数。如果数组长度为偶数，则中位数为中间两个数的平均值。

**输入格式**

第一行输入整数 `m`，表示第一个数组的长度。

第二行输入 `m` 个整数，表示数组 `nums1`。

第三行输入整数 `n`，表示第二个数组的长度。

第四行输入 `n` 个整数，表示数组 `nums2`。

**输出格式**

输出两个升序数组的中位数，保留 5 位小数。

**输入示例**

```text
2
1 3
1
2
```

**输出示例**

```text
2.00000
```

**另一个示例**

```text
2
1 2
2
3 4
```

**输出示例**

```text
2.50000
```

## 思路

使用**双指针归并**两个升序数组，每次将较小的元素加入 `res`，最后根据**合并后数组长度的奇偶性**计算中位数。

## 代码

```python
class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        res = []
        i, k = 0, 0
        while i < len(nums1) and k < len(nums2):
            if nums1[i] <= nums2[k]:
                res.append(nums1[i])
                i += 1
            else:
                res.append(nums2[k])
                k += 1

        if i < len(nums1):
            for j in range(i, len(nums1)):
                res.append(nums1[j])
        if k < len(nums2):
            for j in range(k, len(nums2)):
                res.append(nums2[j])

        if len(res) % 2 == 0:
            return (res[len(res) // 2 - 1] + res[len(res) // 2]) / 2
        else:
            return res[len(res) // 2]
```

## 注意点

-   奇数长度：中位数下标为 `len(res) // 2`。
-   偶数长度：取 `len(res) // 2 - 1` **和** `len(res) // 2` 两个位置的平均值。
