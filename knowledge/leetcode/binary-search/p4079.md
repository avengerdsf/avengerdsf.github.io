## 题目

给定两个已经按升序排列的整数数组 `nums1` 和 `nums2`，请找出并返回这两个数组合并后的中位数。

中位数是指将数组按升序排列后，位于最中间的数。如果数组长度为偶数，则中位数为中间两个数的平均值。

**输入格式**

第一行输入整数 `m`，表示第一个数组的长度。

第二行输入 `m` 个整数，表示数组 `nums1`。

第三行输入整数 `n`，表示第二个数组的长度。

第四行输入 `n` 个整数，表示数组 `nums2`。

**输出格式**

输出两个升序数组的中位数，保留 5 位小数。

**输入示例**

```text
2
1 3
1
2
```

**输出示例**

```text
2.00000
```

**另一个示例**

```text
2
1 2
2
3 4
```

**输出示例**

```text
2.50000
```

## 思路

把两个有序数组当作一条排好序的序列，用两个指针依次取较小的数，**走到中间位置就停止**。过程中只保留上一个数 `prev` 和当前数 `cur`。

- 总长度为 `total = m + n`，中间下标为 `mid = total // 2`。下标从 `0` 开始，因此需要取出 `mid + 1` 个数。
- 每次取数前令 `prev = cur`，再将两个数组当前较小的数赋给 `cur`，移动对应指针。
- 总长度为奇数时，答案是 `cur`；总长度为偶数时，答案是 `(prev + cur) / 2`。

时间复杂度为 `O(m+n)`，额外空间复杂度为 `O(1)`。

## 代码

```python
from typing import List


class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        total = len(nums1) + len(nums2)
        mid = total // 2
        i = j = 0
        prev = cur = 0

        for _ in range(mid + 1):
            prev = cur
            if j == len(nums2) or (i < len(nums1) and nums1[i] <= nums2[j]):
                cur = nums1[i]
                i += 1
            else:
                cur = nums2[j]
                j += 1

        return cur if total % 2 else (prev + cur) / 2
```

## 注意点

-   一个数组取完后，继续从另一个数组取数。
-   偶数长度时，停止后 `prev` 和 `cur` 恰好对应中间的两个数。
-   两个数组的总长度至少为 `1`。
