## 题目

给定一个按照非递减顺序排列的整数数组 `nums` 和一个目标值 `target`。

请找出 `target` 在数组中的第一个位置和最后一个位置。

如果数组中不存在 `target`，返回：

```text
-1 -1
```

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个非递减整数，表示数组 `nums`。

第三行输入一个整数 `target`。

**输出格式**

输出两个整数，分别表示 `target` 第一次出现和最后一次出现的下标。

**输入示例**

```text
6
5 7 7 8 8 10
8
```

**输出示例**

```text
3 4
```

**说明**

目标值 `8` 第一次出现在下标 `3`，最后一次出现在下标 `4`。

## 思路

-   第一次二分找 **第一个** `>= target` **的位置**，作为左边界。
-   第二次二分找 **最后一个** `<= target` **的位置**，作为右边界。
-   最后判断 `nums[left] == target`；若不成立说明目标不存在，返回 `[-1, -1]`。

## 代码

```python
class Solution:
    def findRightNum(self, nums, target):
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right)//2
            if nums[mid] <= target:
                left = mid + 1
            else:
                right = mid - 1
        return left - 1
    
    def findLeftNum(self, nums, target):

        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right)//2
            if nums[mid] >= target:
                right = mid - 1
            else:
                left = mid + 1
        return right + 1
        
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        if len(nums) == 0:
            return [-1, -1]

        left = self.findLeftNum(nums, target)
        right = self.findRightNum(nums, target)

        # 修改1：判断 target 是否真的存在
        if left >= len(nums) or nums[left] != target:
            return [-1, -1]

        return [left, right]
```
