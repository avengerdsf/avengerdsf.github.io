## 题目

给定一个整数数组 `nums`，请找出该数组的下一个排列。

下一个排列是指在所有可能的排列中，**字典序刚好大于当前排列的最小排列**。

如果不存在更大的排列，则将数组重新排列成字典序最小的排列，即升序排列。

要求必须**原地修改数组**，只能使用 `O(1)` 的额外空间。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个整数，表示数组 `nums`。

**输出格式**

输出下一个排列，元素之间用空格分隔。

**输入示例**

```text
3
1 2 3
```

**输出示例**

```text
1 3 2
```

**另一个示例**

```text
3
3 2 1
```

**输出示例**

```text
1 2 3
```

**说明**

`3 2 1` 已经是字典序最大的排列，因此返回最小排列 `1 2 3`。

**第三个示例**

```text
3
1 1 5
```

**输出示例**

```text
1 5 1
```

**数据范围**

-   `1 <= n <= 100`
-   `0 <= nums[i] <= 100`
-   数组元素可以重复。

## 思路

-   从右往左找到第一个满足 `nums[i] < nums[i+1]`的位置 `pos`。
-   再从右往左找到第一个 大于 `nums[pos]`的元素，与 `nums[pos]`交换，使排列尽可能小幅度增大。
-   将 `pos`右侧的非递增区间原地反转，得到最小的后缀排列。
-   如果找不到 `pos`，说明当前已经是字典序最大的排列，直接整体反转为最小排列。

## 代码

```python
class Solution:
    def nextPermutation(self, nums: List[int]) -> None:
        pos, j = -1, -1
        n = len(nums)
        for i in range(n - 2, -1, -1):
            if nums[i] < nums[i + 1]:
                pos = i
                break

        if pos == -1:
            nums.reverse()
            return

        for i in range(n - 1, -1, -1):
            if nums[i] > nums[pos]:
                j = i
                break

        nums[j], nums[pos] = nums[pos], nums[j]

        l, r = pos + 1, n - 1
        while l<=r:
            nums[l], nums[r] = nums[r], nums[l]
            l += 1
            r -= 1
```
