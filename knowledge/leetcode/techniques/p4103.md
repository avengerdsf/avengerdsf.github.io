## 题目

给定一个包含 `n+1` 个整数的数组 `nums`，其中每个整数都在 `[1, n]` 范围内。

已知数组中**只有一个重复的数字**，请找出并返回这个重复数。

要求：

-   不能修改原数组。
-   只能使用 `O(1)` 的额外空间。
-   重复数字可能出现两次或多次。

**输入格式**

第一行输入一个整数 `m`，表示数组长度。

第二行输入 `m` 个整数，表示数组 `nums`。

**输出格式**

输出一个整数，表示重复的数字。

**输入示例**

```text
5
1 3 4 2 2
```

**输出示例**

```text
2
```

**说明**

数组中数字 `2` 出现了两次，因此返回 `2`。

**另一个示例**

```text
5
3 1 3 4 2
```

**输出示例**

```text
3
```

**数据范围**

-   `2 <= m <= 100001`
-   `1 <= nums[i] <= m-1`
-   保证只有一个不同的数字重复出现。

## 思路

-   判断是否存在环：将数组看作链表，`nums[i]`表示下一个节点的下标。`slow`每次走一步，`fast`每次走两步，直到第一次相遇。
-   寻找环入口：将 `ptr1`放在第一次相遇点，`ptr2`放回初始位置 `0`，两个指针每次走一步，再次相遇的位置就是重复数字。

## 代码

```python
def findDuplicate(nums: List[int]) -> int:
    slow, fast = nums[0], nums[0]
    n = len(nums)
    while slow < n and fast < n:
        slow = nums[slow]
        fast = nums[nums[fast]]

        if slow == fast:
            break

    ptr1 = fast
    ptr2 = nums[0]

    while ptr1 != ptr2:
        ptr2 = nums[ptr2]
        ptr1 = nums[ptr1]

    return  ptr1
```
