## 题目

给定一个包含 `n` 个元素的整数数组 `nums`，其中每个元素只能是 `0`、`1` 或 `2`，分别代表红色、白色和蓝色。

请在原数组上进行排序，使相同颜色的元素相邻，并按照 `0 → 1 → 2` 的顺序排列。

要求**不能使用内置排序函数**。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个整数，表示数组 `nums`。

**输出格式**

输出排序后的数组，元素之间用空格分隔。

**输入示例**

```text
6
2 0 2 1 1 0
```

**输出示例**

```text
0 0 1 1 2 2
```

**另一个示例**

```text
3
2 0 1
```

**输出示例**

```text
0 1 2
```

**数据范围**

-   `1 <= n <= 300`
-   `nums[i]` 只能为 `0`、`1` 或 `2`。

## 思路

-   初始化：`i、j`指向数组开头，`k`指向末尾；`i`为遍历指针，`j`为下一个 `0`应放的位置，`k`为下一个 `2`应放的位置。
-   遇到 `0`：与 `j`交换，`j < i`时换回来的必定是 `1`，`j == i`时为自身交换，因此 `i、j`同时右移。
-   遇到 `1`：不需要交换，`i`直接右移。
-   遇到 `2`：与 `k`交换，由于换回来的元素未知，需要重新判断，因此只执行 `k -= 1`。
-   循环条件：`i <= k`，直到所有未处理元素都完成分类。

## 代码

```python
class Solution:
    def sortColors(self, nums: List[int]) -> None:
        i, k = 0, len(nums) - 1
        j = 0

        while i <= k:
            if nums[i] == 0:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
                j += 1

            elif nums[i] == 2:
                nums[i], nums[k] = nums[k], nums[i]
                k -= 1
            else:
                i += 1
```
