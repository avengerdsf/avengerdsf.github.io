## 题目

**​**  

给定一个非空整数数组 `nums`，其中除了某个元素只出现一次以外，其余每个元素均出现两次。

请找出并返回那个只出现一次的元素。

要求算法的时间复杂度为 `O(n)`，且只能使用 `O(1)` **的额外空间**。

**输入格式**

输入一组整数，表示数组 `nums`，整数之间用空格分隔。

**输出格式**

输出一个整数，表示只出现一次的元素。

**输入示例**

```text
2 2 1
```

**输出示例**

```text
1
```

**另一个示例**

```text
4 1 2 1 2
```

**输出示例**

```text
4
```

**说明**

数组中 `1` 和 `2` 均出现两次，只有 `4` 出现一次，因此输出 `4`。

**数据范围**

-   `1 <= len(nums) <= 30000`
-   `-30000 <= nums[i] <= 30000`
-   除了一个元素只出现一次，其余元素均恰好出现两次。

## 思路

使用**按位异或运算**，遍历数组执行 `ans ^= num`，利用**相同数字异或为** `0` 的性质，使出现两次的数字相互抵消，最终剩下**只出现一次的元素**。

## 代码

```python
class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        ans = 0
        for num in nums:
            ans ^= num

        return ans
```

## 注意点

### 异或运算知识点

-   `ans ^= num`：等价于 `ans = ans ^ num`，表示**按位异或**。
-   异或规则：二进制位**相同为** `0`**，不同为** `1`。
-   `a ^ a = 0`：**相同数字异或抵消**。
-   `a ^ 0 = a`：**任何数字与** `0` **异或保持不变**。
-   交换律：`a ^ b = b ^ a`。
-   结合律：`(a ^ b) ^ c = a ^ (b ^ c)`。
-   时间复杂度 `O(n)`，额外空间复杂度 `O(1)`。
