## 题目

给定两个以字符串形式表示的非负整数 `num1` 和 `num2`，请计算它们的和，并以字符串形式输出。

要求：

-   **不能直接将整个字符串转换为整数**。
-   **不能使用大整数计算库**。
-   需要模拟整数加法，正确处理每一位的进位。

**输入格式**

第一行输入字符串 `num1`，表示第一个非负整数。

第二行输入字符串 `num2`，表示第二个非负整数。

**输出格式**

输出一个字符串，表示两个非负整数的和。

**输入示例**

```text
11
123
```

**输出示例**

```text
134
```

**另一个示例**

```text
456
77
```

**输出示例**

```text
533
```

**第三个示例**

```text
0
0
```

**输出示例**

```text
0
```

**数据范围**

-   `1 <= len(num1), len(num2) <= 10000`
-   `num1` 和 `num2` 仅包含数字 `0~9`。

## 思路

-   双指针：从两个字符串末尾向前遍历，逐位相加并处理进位。
-   进位处理：使用 `cur_sum % 10`获取当前位，`cur_sum // 10`获取进位。
-   剩余部分：一个字符串遍历结束后，继续处理剩余数字和进位；若进位为 `0`，直接拼接剩余数字。
-   结果处理：使用 `append()`保存每一位数字，最后通过 `''.join(reversed(s))`反转并拼接结果。

## 代码

```python
class Solution:
    def addStrings(self, num1: str, num2: str) -> str:
        n1 = len(num1)
        n2 = len(num2)
        s = []  # 修改1：使用列表存储结果

        ptr1, ptr2 = n1 - 1, n2 - 1
        next_num = 0
        while ptr1 > -1 and ptr2 > -1:
            cur_sum = int(num1[ptr1]) + int(num2[ptr2]) + next_num
            cur_num = cur_sum % 10
            next_num = cur_sum // 10
            s.append(str(cur_num))  # 修改2：直接追加到列表末尾

            ptr1 -= 1
            ptr2 -= 1

        ptr = None
        if ptr1 > -1:
            ptr = ptr1
            num = num1

        if ptr2 > -1:
            ptr = ptr2
            num = num2

        while ptr is not None and ptr > -1:
            if next_num == 0:
                s.extend(reversed(num[:ptr + 1]))  # 修改3：剩余数字逆序加入
                break
            cur_sum = int(num[ptr]) + next_num
            cur_num = cur_sum % 10
            next_num = cur_sum // 10
            s.append(str(cur_num))  # 修改4：直接追加

            ptr -= 1

        if next_num != 0:
            s.append(str(next_num))  # 修改5：追加最终进位

        return ''.join(reversed(s))  # 修改6：统一反转并拼接
```
