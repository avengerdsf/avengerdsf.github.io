## 题目

给定一个非空整数数组 `nums`，请找出其中的多数元素。

多数元素是指在数组中出现次数**严格大于** `⌊n/2⌋` 的元素，其中 `n` 为数组长度。

可以假设数组中一定存在多数元素。

**输入格式**

输入一组整数，表示数组 `nums`，整数之间用空格分隔。

**输出格式**

输出一个整数，表示数组中的多数元素。

**输入示例**

```text
3 2 3
```

**输出示例**

```text
3
```

**说明**

数组长度为 `3`，元素 `3` 出现了 `2` 次，超过 `⌊3/2⌋ = 1`，因此输出 `3`。

**另一个示例**

```text
2 2 1 1 1 2 2
```

**输出示例**

```text
2
```

**说明**

数组长度为 `7`，元素 `2` 出现了 `4` 次，超过 `⌊7/2⌋ = 3`，因此输出 `2`。

**数据范围**

-   `1 <= len(nums) <= 50000`
-   `-10^9 <= nums[i] <= 10^9`
-   保证多数元素一定存在。

## 思路

-   使用栈进行不同元素之间的两两抵消。
-   遍历数组，如果当前元素与栈顶相同则入栈，不同则弹出栈顶。
-   因为多数元素的出现次数严格大于数组长度的一半，所以抵消后剩下的必然是多数元素。

## 代码

```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        stack = []
        for num in nums:
            if stack and stack[-1] != num:
                stack.pop()

            else:
                stack.append(num)

        return stack[-1]
```
