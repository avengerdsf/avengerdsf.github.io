## P4007. 无重复字符的最长子串

给定一个字符串 `s`，请找出其中不包含重复字符的最长子串，并返回该子串的长度。

**输入格式**

输入一个字符串 `s`。

**输出格式**

输出一个整数，表示无重复字符的最长子串长度。

**输入示例**

```text
abcabcbb
```

**输出示例**

```text
3
```

**说明**

最长无重复字符子串可以是：

```text
abc
```

其长度为 `3`。

**数据范围**

-   `1 <= len(s) <= 100000`
-   `s` 由可见字符组成

## 思路

用**滑动窗口**维护当前无重复子串，遇到重复字符就**移动左指针直到窗口内不再重复**，同时记录最大长度。

## 代码

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        record = {}
        slow = 0
        max_len = 0
        for fast in range(len(s)):
            record[s[fast]] = record.get(s[fast], 0) + 1
            while record[s[fast]] > 1:
                record[s[slow]] -= 1
                slow += 1
            
            max_len = max(max_len, fast - slow + 1)
        return max_len

```
