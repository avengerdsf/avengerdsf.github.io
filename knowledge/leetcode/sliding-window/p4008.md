## 题目

给定两个字符串 `s` 和 `p`，请在字符串 `s` 中找到所有字符串 `p` 的字母异位词，并返回这些异位词在 `s` 中的起始下标。

字母异位词是指由相同字母重新排列形成的字符串，也就是说，两个字符串中每个字符出现的次数完全相同。

**输入格式**

第一行输入字符串 `s`。

第二行输入字符串 `p`。

**输出格式**

输出所有满足条件的起始下标，下标之间用空格分隔。

**输入示例**

```text
cbaebabacd
abc
```

**输出示例**

```text
0 6
```

**说明**

下标 `0` 开始的子串：

```text
cba
```

下标 `6` 开始的子串：

```text
bac
```

它们都是 `abc` 的字母异位词。

**数据范围**

-   `1 <= len(s), len(p) <= 100000`
-   `s` 和 `p` 仅由小写英文字母组成

## 思路

用**滑动窗口**维护长度为 `len(p)` 的区间，并用 **长度为 26 的数组** `[]` **作为哈希表**统计字符出现次数；窗口每右移一格就更新两端字符计数，若窗口计数与 `p` 的计数相同，就记录当前起始下标。

## 代码

```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        record_p = [0] * 26
        for ch in p:
            record_p[ord(ch) - ord('a')] += 1

        record_s = [0] * 26
        slow = 0
        res = []
        for fast in range(len(s)):
            record_s[ord(s[fast]) - ord('a')] += 1

            while record_s[ord(s[fast]) - ord('a')] > record_p[ord(s[fast]) - ord('a')]:
                record_s[ord(s[slow]) - ord('a')] -= 1
                slow += 1

            if record_p == record_s:
                res.append(slow)

        return res
```
