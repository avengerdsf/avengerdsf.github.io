## 题目

给定一个字符串 `s` 和一个整数 `k`，请统计长度**至少为 `k`** 且内部不包含重复字符的子串数量。

子串必须由原字符串中连续的一段字符组成。内容相同但位置不同的子串分别计数。

**输入格式**

第一行输入字符串 `s`。

第二行输入整数 `k`。

**输出格式**

输出一个整数，表示长度至少为 `k` 且不包含重复字符的子串数量。

**输入示例**

```text
havefunonleetcode
5
```

**输出示例**

```text
12
```

**说明**

满足条件的子串按长度分类如下：

- 长度为 `5`：`havef`、`avefu`、`vefun`、`efuno`、`etcod`、`tcode`，共 `6` 个。
- 长度为 `6`：`havefu`、`avefun`、`vefuno`，共 `3` 个。
- 长度为 `7`：`havefun`、`avefuno`，共 `2` 个。
- 长度为 `8`：`havefuno`，共 `1` 个。

总数为 `6 + 3 + 2 + 1 = 12`。

**数据范围**

-   `1 <= len(s) <= 10000`
-   `1 <= k <= 10000`
-   `s` 仅由小写英文字母组成

## 思路

用**滑动窗口 + 26 长度数组哈希表**维护无重复区间 `[slow, fast]`。加入 `s[fast]` 后，若该字符重复，就移动 `slow`，直到窗口内所有字符都只出现一次。

设当前窗口长度为 `length = fast - slow + 1`。当 `length >= k` 时，以 `fast` 为右端点的合法子串长度可以依次取 `k`、`k + 1`、……、`length`，因此本轮新增 `length - k + 1` 个合法子串。

例如 `s = "abcde"`、`k = 3`，合法子串为 `abc`、`bcd`、`cde`、`abcd`、`bcde`、`abcde`，总数为 `6`。

## 代码

```python
s = input()
k = int(input())

n = len(s)
record = [0] * 26

slow = 0
ans = 0
for fast in range(n):
    idx = ord(s[fast]) - ord('a')

    record[idx] += 1
    while record[idx] > 1:
        record[ord(s[slow]) - ord('a')] -= 1
        slow += 1

    length = fast - slow + 1
    if length >= k:
        ans += (length - k + 1)

print(ans)
```

## 注意点

-   `slow` 移动：**先减去** `s[slow]` **的计数，再** `slow += 1`。
-   重复判断：要用 `while`，**直到窗口内不再重复**。
-   每轮只统计以 `fast` 为右端点的子串；不同轮次的右端点不同，每个合法子串只计数一次。
-   若 `k > len(s)` 或 `k > 26`，不存在满足条件的子串，答案为 `0`。
