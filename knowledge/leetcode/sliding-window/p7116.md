## 题目

给定一个字符串 `s` 和一个整数 `k`，请找出所有长度为 `k` 且不包含重复字符的子串，并返回满足条件的子串数量。:chatgpt-content-reference{index="0"}

**输入格式**

第一行输入字符串 `s`。

第二行输入整数 `k`。

**输出格式**

输出一个整数，表示长度为 `k` 且不包含重复字符的子串数量。

**输入示例**

```text
havefunonleetcode
5
```

**输出示例**

```text
6
```

**说明**

满足条件的子串包括：

```text
havef
avefu
vefun
efuno
etcod
tcode
```

因此结果为 `6`。:chatgpt-content-reference{index="1"}

**数据范围**

-   `1 <= len(s) <= 10000`
-   `1 <= k <= 10000`
-   `s` 仅由小写英文字母组成

## 思路

用**滑动窗口 + 26 长度数组哈希表**维护无重复区间，重复时移动 `slow`，窗口长度达到 `k` 后累计答案。

## 代码

```python
s = input()
k = int(input())

n = len(s)
record = [0] * 26

slow = 0
ans = 0
for fast in range(n):
    idx = ord(s[fast]) - ord('a')

    record[idx] += 1
    while record[idx] > 1:
        record[ord(s[slow]) - ord('a')] -= 1
        slow += 1

    length = fast - slow + 1
    if length >= k:
        ans += (length - k + 1)

print(ans)
```

## 注意点

-   `slow` 移动：**先减去** `s[slow]` **的计数，再** `slow += 1`。
-   重复判断：要用 `while`，**直到窗口内不再重复**。
-   计数公式：当前窗口长度为 `length` 时，新增 `length - k + 1` 个合法子串。
-   注意：统计的是**长度大于等于** `k`，不是只等于 `k`。
