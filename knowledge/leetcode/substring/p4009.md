## 题目

给定一个整数数组 `nums` 和一个整数 `k`，请统计数组中和等于 `k` 的连续子数组个数。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个整数，表示数组 `nums`。

第三行输入一个整数 `k`。

**输出格式**

输出一个整数，表示和为 `k` 的连续子数组数量。

**输入示例**

```text
3
1 1 1
2
```

**输出示例**

```text
2
```

**说明**

满足条件的连续子数组有：

```text
[1, 1]
[1, 1]
```

因此答案为 `2`。

**数据范围**

-   `1 <= n <= 100000`
-   `-10^9 <= nums[i] <= 10^9`
-   `-10^9 <= k <= 10^9`

## 思路

用**前缀和 + 哈希表**，遍历时记录**当前前缀和**`cur_sum`，如果**之前出现过**`cur_sum - k`，说明存在对应的和为 `k` 的子数组，将其出现次数累加到答案中。

## 代码

```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        record = {0: 1}
        cur_sum, cnt = 0, 0
        for num in nums:
            cur_sum += num
            cnt += record.get(cur_sum - k, 0)
            record[cur_sum] = record.get(cur_sum, 0) + 1

        return cnt
```

## 注意点

-   不能用滑动窗口，针对负数会失效
