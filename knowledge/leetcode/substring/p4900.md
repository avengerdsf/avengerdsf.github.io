## 题目

给定两个长度相同的字符串 `s1` 和 `s2`。

你可以在其中一个字符串中选择两个下标不同的位置，并交换这两个位置上的字符，且最多执行一次交换。

请判断是否能够通过这一次交换，使 `s1` 和 `s2` 相等。

**输入格式**

第一行输入字符串 `s1`。

第二行输入字符串 `s2`。

**输出格式**

如果可以通过至多一次交换使两个字符串相等，输出：

```text
true
```

否则输出：

```text
false
```

**输入示例**

```text
bank
kanb
```

**输出示例**

```text
true
```

**说明**

交换 `bank` 中下标 `0` 和下标 `3` 的字符后：

```text
kanb
```

与 `s2` 相等。

**数据范围**

-   `1 <= len(s1), len(s2) <= 100000`
-   `s1` 和 `s2` 由英文字母组成

## 思路

遍历两个字符串，记录**字符不同的位置下标**；如果不同位置为 `0` 个则已经相等，如果正好为 `2` 个，就检查这两个位置的字符能否**交叉对应**，否则返回 `false`。

## 代码

```python
s = input()
t = input()

record = []
if len(s) != len(t):
    print('false')
    exit()

for i in range(len(s)):
    if s[i] != t[i]:
        record.append(i)

if len(record) == 0:
    print('true')
    exit()

if len(record) == 2:
    i, j = record[0], record[1]
    if s[i] == t[j] and s[j] == t[i]:
        print('true')
        exit()

print('false')

```

## 注意点

-   **错误 1：不应该记录每个字符出现过的所有下标，而应该直接记录** `s[i] != t[i]` **的位置。** 例如 `s = "aaabbb"`、`t = "ababab"`，真正不同的位置只有 `1` 和 `4`，因此只需要记录 `diff = [1, 4]`。
-   **错误 2：不能用** `record[ch][-1] != i` **判断当前位置是否不同。** 例如字符 `a` 在 `s` 中的位置是 `[0, 1, 2]`，但 `t[4] = 'a'` 并不代表它一定对应 `s[2]`，重复字符会导致这种人为配对错位。
