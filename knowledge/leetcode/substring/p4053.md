## 题目

给定两个字符串 `s` 和 `t`，请在字符串 `s` 中找出一个最短子串，使这个子串包含字符串 `t` 中的所有字符。

如果 `t` 中某个字符出现多次，那么最短子串中该字符也必须至少出现相同次数。

如果不存在满足条件的子串，输出空字符串。

**输入格式**

第一行输入字符串 `s`。

第二行输入字符串 `t`。

**输出格式**

输出 `s` 中包含 `t` 所有字符的最短子串。

**输入示例**

```text
ADOBECODEBANC
ABC
```

**输出示例**

```text
BANC
```

**说明**

`BANC` 中包含 `A`、`B`、`C`，并且是满足条件的最短子串。

**数据范围**

-   `1 <= len(s), len(t) <= 100000`
-   `s` 和 `t` 由英文字母组成

## 思路

-   用两个哈希表分别记录 `s` 当前窗口和 `t` 的字符次数，`valid` 表示**已经满足要求的字符种类数**。
-   `fast` 向右扩展窗口，某字符次数**刚好达到** `t` **的要求**时，`valid += 1`。
-   当 `valid == max_valid` 时，说明窗口已经覆盖 `t`，不断移动 `slow`**缩小窗口并更新最短答案**。
-   如果移除 `s[slow]` 后某字符次数**低于** `t` **的要求**，则 `valid -= 1`，停止收缩。

## 代码

```python
s = input()
t = input()

max_valid = 0
n = len(s)
record_s = {}
record_t = {}
for ch in t:
    if record_t.get(ch):
        record_t[ch] += 1
    else:
        record_t[ch] = 1
        max_valid += 1

slow = 0
valid = 0
min_str = ""
min_len = 10 ** 18
for fast in range(n):
    record_s[s[fast]] = record_s.get(s[fast], 0) + 1
    if record_t.get(s[fast]) and record_s[s[fast]] == record_t[s[fast]]:
        valid += 1

    while valid == max_valid:
        if fast - slow + 1 < min_len:
            min_len = fast - slow + 1
            min_str = s[slow: fast + 1]
        record_s[s[slow]] -= 1
        if record_t.get(s[slow]) and record_s[s[slow]] < record_t[s[slow]]:
            valid -= 1
        slow += 1

print(min_str)

```

## 注意点

-   **错误 1：缩窗口的条件写错了。** 应该在 `valid == max_valid` 时不断缩小窗口，而不是只在当前字符数量超出 `t` 的需求时缩。
-   **错误 2：**`min_str` **初始化成了** `None`**。** 如果不存在满足条件的覆盖子串，题目通常要求输出空字符串 `""`，而不是 `None`。
