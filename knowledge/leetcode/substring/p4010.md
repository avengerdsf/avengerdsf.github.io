## 题目

给定一个整数数组 `nums` 和一个整数 `k`，有一个大小为 `k` 的滑动窗口从数组最左侧移动到最右侧。

每次窗口向右移动一个位置，请输出当前窗口中的最大值。

**输入格式**

第一行输入两个整数 `n` 和 `k`，分别表示数组长度和滑动窗口大小。

第二行输入 `n` 个整数，表示数组 `nums`。

**输出格式**

输出每个滑动窗口中的最大值，结果之间用空格分隔。

**输入示例**

```text
8 3
1 3 -1 -3 5 3 6 7
```

**输出示例**

```text
3 3 5 5 6 7
```

**说明**

滑动窗口依次为：

```text
[1 3 -1] -3 5 3 6 7
1 [3 -1 -3] 5 3 6 7
1 3 [-1 -3 5] 3 6 7
1 3 -1 [-3 5 3] 6 7
1 3 -1 -3 [5 3 6] 7
1 3 -1 -3 5 [3 6 7]
```

对应的最大值为：

```text
3 3 5 5 6 7
```

**数据范围**

-   `1 <= k <= n <= 100000`
-   `-10^9 <= nums[i] <= 10^9`

## 思路

-   维护一个单调队列，**队列里存数组下标**，并保证对应的值**从队头到队尾递减**。
-   新元素进入时，从队尾删除所有**比它小的元素**。
-   如果队头下标已经**滑出窗口范围**，就删除队头。
-   当窗口长度达到 `k` 时，**队头下标对应的元素就是当前窗口最大值**。

## 代码

```python
from collections import deque

n, k = map(int, input().split())
nums = list(map(int, input().split()))

q = deque()
result = []

for i in range(len(nums)):
    if q and q[0] < i - k + 1:
        q.popleft()

    while q and nums[q[-1]] < nums[i]:
        q.pop()

    q.append(i)

    if i >= k - 1:
        result.append(nums[q[0]])

print(' '.join(map(str, result)))

```
