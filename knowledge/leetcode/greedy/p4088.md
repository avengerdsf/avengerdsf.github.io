## 题目

给定一个仅由小写英文字母组成的字符串 `s`，请将字符串划分为尽可能多的连续片段。

划分需要满足以下条件：

-   同一个字母最多只能出现在一个片段中。
-   所有片段按原顺序拼接后，必须得到原字符串 `s`。
-   在满足上述条件的前提下，划分的片段数量应尽可能多。

请返回每个片段的长度。

**输入格式**

输入一个字符串 `s`。

**输出格式**

输出每个片段的长度，整数之间用空格分隔。

**输入示例**

```text
ababcbacadefegdehijhklij
```

**输出示例**

```text
9 7 8
```

**说明**

字符串可以划分为：

```text
ababcbaca | defegde | hijhklij
```

三个片段的长度分别为 `9`、`7`、`8`。

每个字母只出现在其中一个片段中，且片段数量最多。

**另一个示例**

```text
eccbbbbdec
```

**输出示例**

```text
10
```

**数据范围**

-   `1 <= len(s) <= 500`
-   `s` 仅由小写英文字母组成。

## 思路

-   使用哈希表记录每个字符第一次和最后一次出现的下标，形成区间。
-   按区间左端点升序排序，依次合并存在重叠的区间。
-   最后计算每个合并区间的长度 `right - left + 1`，得到划分结果。

## 代码

```python
class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        record = {}
        for i in range(len(s)):
            ch = s[i]
            if not record.get(ch):
                record[ch] = (i, i)
            else:
                tmp = record[ch]
                record[ch] = (tmp[0], i)

        vals = sorted(record.values(), key=lambda x: x[0])

        res = []
        for val in vals:
            if not res:
                res.append(val)
            else:
                last_x, last_y = res[-1]
                if  last_x <= val[0] <= last_y:
                    res[-1] = (min(last_x, val[0]), max(last_y, val[1]))
                else:
                    res.append(val)

        r = []
        for val in res:
            r.append(val[1] - val[0] + 1)
        return r
```
