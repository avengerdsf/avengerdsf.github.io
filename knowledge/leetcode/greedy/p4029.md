## 题目

给定一个长度为 `n` 的整数数组 `prices`，其中 `prices[i]` 表示第 `i` 天的股票价格。

你只能选择某一天买入股票，并在未来某一天卖出股票，最多只能完成一次买卖交易。

请计算能够获得的最大利润。如果无法获得利润，则返回 `0`。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个整数，表示每天的股票价格。

**输出格式**

输出一个整数，表示能够获得的最大利润。

**输入示例**

```text
6
7 1 5 3 6 4
```

**输出示例**

```text
5
```

**说明**

在第 `2` 天以价格 `1` 买入，第 `5` 天以价格 `6` 卖出。

最大利润为 `6 - 1 = 5`。

注意必须**先买入，再卖出**，不能在买入前卖出。

**另一个示例**

```text
5
7 6 4 3 1
```

**输出示例**

```text
0
```

**数据范围**

-   `1 <= n <= 100000`
-   `0 <= prices[i] <= 10000`

## 思路

思路：遍历股票价格，维护历史最低买入价 `min_price`和之后的最高卖出价 `max_price`，不断更新最大利润 `ans`。

## 代码

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        min_price, max_price = 10**18, 0
        ans = 0
        for i in range(len(prices)):
            if prices[i] < min_price:
                min_price = prices[i]
                max_price = prices[i]
            else:
                max_price = max(max_price, prices[i])

            ans = max(ans, max_price - min_price)

        return ans
```
