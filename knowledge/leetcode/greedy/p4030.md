## 题目

给定一个长度为 `n` 的非负整数数组 `nums`，你最初位于数组的第一个下标。

数组中的每个元素 `nums[i]` 表示从当前位置最多可以向前跳跃的步数。

请判断是否能够到达数组的最后一个下标。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个非负整数，表示数组 `nums`。

**输出格式**

如果能够到达最后一个下标，输出：

```text
true
```

否则输出：

```text
false
```

**输入示例**

```text
5
2 3 1 1 4
```

**输出示例**

```text
true
```

**说明**

先从下标 `0` 跳到下标 `1`，再从下标 `1` 跳跃 `3` 步到达最后一个下标。

**另一个示例**

```text
5
3 2 1 0 4
```

**输出示例**

```text
false
```

**说明**

无论如何跳跃，都会被困在下标 `3` 的位置，因为 `nums[3] = 0`，无法继续到达最后一个下标。

## 思路

-   初始化：`idx = 0`，`max_idx = 0`，分别表示当前遍历位置和**最远可达下标**。
-   遍历：只有 `idx <= max_idx`，才能保证当前位置可达，并更新 `max_idx = max(max_idx, idx + nums[idx])`。
-   判断：如果 `max_idx >= len(nums) - 1`，说明能够到达终点；否则继续遍历，直到当前位置不可达。

## 代码

```python
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        idx = 0
        max_idx = 0
        while idx < len(nums) and idx <= max_idx:
            max_idx = max(max_idx, nums[idx] + idx)
            idx += 1

        if max_idx >= len(nums) - 1:
            return True

        return False
```
