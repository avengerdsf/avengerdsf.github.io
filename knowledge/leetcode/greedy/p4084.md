## 题目

给定一个长度为 `n` 的非负整数数组 `nums`，你最初位于数组的第一个下标。

数组中的每个元素 `nums[i]` 表示从当前位置最多可以向前跳跃的步数。

请计算到达数组最后一个下标所需要的**最少跳跃次数**。

假设总是能够到达数组的最后一个下标。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个非负整数，表示数组 `nums`。

**输出格式**

输出一个整数，表示到达最后一个下标所需的最少跳跃次数。

**输入示例**

```text
5
2 3 1 1 4
```

**输出示例**

```text
2
```

**说明**

从下标 `0` 开始：

-   第一次跳跃：从下标 `0` 跳到下标 `1`。
-   第二次跳跃：从下标 `1` 跳到下标 `4`。

因此最少需要 `2` 次跳跃。

**另一个示例**

```text
5
2 3 0 1 4
```

**输出示例**

```text
2
```

**数据范围**

-   `1 <= n <= 10000`
-   `0 <= nums[i] <= 1000`
-   保证能够到达最后一个下标。

## 思路

-   判断终点：如果 `idx + nums[idx] >= n - 1`，说明再跳一次就能到达终点。
-   贪心选择：遍历当前位置能够跳到的所有下标，选择下一次能跳得最远的位置 `next_idx`。
-   更新位置：将 `idx`更新为 `next_idx`，`ans += 1`，继续寻找下一跳。

## 代码

```python
def jump(self, nums: List[int]) -> int:
        n = len(nums)
        idx = 0
        ans = 0
        while idx < n - 1:
            if idx + nums[idx] >= n - 1:
                return ans + 1
            next_idx = idx
            next_max = 0

            for i in range(1, min(nums[idx], n - 1 - idx) + 1):
                if i + nums[i + idx] > next_max:
                    next_max = i + nums[i + idx]
                    next_idx = i + idx
                # print(i, i + idx,  nums[i + idx], i + nums[i + idx])
            ans += 1
            idx = next_idx

        return ans
```
