## 题目

给定两个字符串 `word1` 和 `word2`，请计算将 `word1` 转换为 `word2` 所需的最少操作次数。

每次可以执行以下三种操作之一：

-   **插入**一个字符。
-   **删除**一个字符。
-   **替换**一个字符。

每种操作的代价均为 `1`。

**输入格式**

第一行输入字符串 `word1`。

第二行输入字符串 `word2`。

**输出格式**

输出一个整数，表示将 `word1` 转换为 `word2` 所需的最少操作次数。

**输入示例**

```text
horse
ros
```

**输出示例**

```text
3
```

**说明**

-   `horse → rorse`：替换 `h` 为 `r`。
-   `rorse → rose`：删除 `r`。
-   `rose → ros`：删除 `e`。

因此最少需要 `3` 次操作。

**另一个示例**

```text
intention
execution
```

**输出示例**

```text
5
```

## 思路

**1\. 定义状态**

`dp[i][j]` 表示**将** `word1` **前** `i` **个字符转换为** `word2` **前** `j` **个字符所需的最少操作次数**。

**2\. 状态转移方程**

当 `word1[i-1] == word2[j-1]` 时，末尾字符相同，不需要操作：

$$
dp[i][j] = dp[i-1][j-1]
$$

当 `word1[i-1] != word2[j-1]` 时，选择三种操作中代价最小的一种：

$$
dp[i][j] = \min
\begin{cases}
dp[i-1][j]+1 \\
dp[i][j-1]+1 \\
dp[i-1][j-1]+1
\end{cases}
$$

-   `dp[i-1][j]+1`：**删除**当前字符。
-   `dp[i][j-1]+1`：**插入**当前字符。
-   `dp[i-1][j-1]+1`：**替换**当前字符。

**3\. 初始状态和边界条件**

-   `dp[0][0] = 0`：两个空字符串不需要操作。
-   `dp[i][0] = i`：将前 `i` 个字符全部删除。
-   `dp[0][j] = j`：向空字符串插入 `j` 个字符。

**4\. 状态转移方程求解**

-   从左到右遍历两个字符串，根据**末尾字符是否相同**更新 `dp[i][j]`。
-   字符相同则直接继承，字符不同则取**插入、删除、替换的最小代价**。
-   最后返回 `dp[n][m]`，即两个完整字符串的最小编辑距离。

## 代码

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        n, m = len(word1), len(word2)

        # 修改1：不能只取较短长度，需要完整的二维 DP
        dp = [[0] * (m + 1) for _ in range(n + 1)]

        # 修改2：初始化空字符串的编辑距离
        for i in range(n + 1):
            dp[i][0] = i

        for j in range(m + 1):
            dp[0][j] = j

        # 修改3：遍历两个字符串的完整长度
        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if word1[i - 1] != word2[j - 1]:
                    # 修改4：增加替换操作
                    dp[i][j] = min(
                        dp[i - 1][j],
                        dp[i][j - 1],
                        dp[i - 1][j - 1]
                    ) + 1
                else:
                    dp[i][j] = dp[i - 1][j - 1]

        return dp[n][m]  # 修改5：直接返回完整字符串的编辑距离
```
