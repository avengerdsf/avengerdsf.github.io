## 思路

### 定义状态

先说明每个下标对应的位置或前缀，再说明状态保存的是数量、最优值或可行性。下标起点与代码一致。

| 类型 | `i` 的含义 | `j` 的含义 |
| --- | --- | --- |
| 背包 DP | 前 `i` 个物品 | 目标容量或金额 |
| 二维路径 DP | 第 `i` 行 | 第 `j` 列 |
| 区间 DP | 子区间左端点 | 子区间右端点 |
| 双序列 DP | 第一串前 `i` 个字符 | 第二串前 `j` 个字符 |

### 状态转移方程

列出到达当前状态的选择，再把选择与较小规模的状态联系起来。计数问题累加各条来源路径；最优值问题取最大值或最小值；可行性问题合并满足条件的选择。

### 初始状态和边界条件

确定无需继续转移就能直接得到的状态，并检查合法下标范围。网格问题关注起点、首行和首列；双序列问题关注空前缀；回文问题关注单个字符与相邻两个字符。

### 状态转移方程求解

根据状态依赖决定遍历方向。依赖上方和左方的网格状态按行、列递增计算；回文区间依赖内部区间，左端点从右向左计算；一次选取的背包容量倒序更新。最后按状态定义选择答案：覆盖全部输入的状态直接给出整体结果，以某个位置结尾的状态则需要比较各个结尾的结果。
