## 题目

机器人每次只能向**下**或者向**右**移动一步，目标是到达网格的右下角。

请计算从左上角到右下角共有多少条不同的路径。

**输入格式**

输入两个整数 `m` 和 `n`，分别表示网格的行数和列数。

**输出格式**

输出一个整数，表示不同路径的数量。

**输入示例**

```text
3 7
```

**输出示例**

```text
28
```

**另一个示例**

```text
3 2
```

**输出示例**

```text
3
```

**说明**

当 `m = 3`、`n = 2` 时，共有三条路径：

-   右 → 下 → 下
-   下 → 右 → 下
-   下 → 下 → 右

因此输出 `3`。

**数据范围**

-   `1 <= m, n <= 100`
-   答案保证不超过 `2 × 10^9`。

## 思路

**1\. 定义状态**

`path[i][j]` 表示**从左上角到达位置** `(i,j)` **的不同路径数量**。

**2\. 状态转移方程**

因为机器人只能**向右或向下移动**，所以只能从上方或左方到达当前位置：

$$
path[i][j] = path[i-1][j] + path[i][j-1]
$$

**3\. 初始状态和边界条件**

-   `path[0][0] = 1`，起点本身算一条路径。
-   **第一行和第一列均初始化为** `1`，因为只能沿一个方向到达。

**4\. 状态转移方程求解**

从左上到右下遍历，累加**上方和左方的路径数量**，最后返回 `path[m-1][n-1]`。

## 代码

```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        path = [[0] * (n) for _ in range(m)]
        path[0][0] = 1
        for i in range(1, m):
            path[i][0] = 1
        for j in range(1, n):
            path[0][j] = 1
        for i in range(1, m):
            for j in range(1, n):
                path[i][j] = path[i - 1][j] + path[i][j - 1]

        return path[m - 1][n - 1]
```
