## 题目

给定一个字符串 `s`，请找出其中最长的回文子串，并返回该子串。

回文串是指正向读取和反向读取完全相同的字符串。

**注意：**

-   子串必须连续。
-   如果存在多个长度相同的最长回文子串，返回任意一个即可。

**输入格式**

输入一个字符串 `s`。

**输出格式**

输出一个字符串，表示最长回文子串。

**输入示例**

```text
babad
```

**输出示例**

```text
bab
```

**说明**

`bab` 和 `aba` 都是符合条件的最长回文子串，长度均为 `3`。

**另一个示例**

```text
cbbd
```

**输出示例**

```text
bb
```

**说明**

最长回文子串为 `bb`，长度为 `2`。

**数据范围**

-   `1 <= len(s) <= 1000`
-   `s` 仅由数字和英文字母组成。

## 思路

### 定义状态

`dp[i][j]` 表示**从下标** `i` **到** `j` **的子串是否为回文串**，即 `s[i:j+1]` 是否回文。

### 状态转移方程

-   如果 `s[i] != s[j]`，两端不同，直接为 `False`。
-   如果 `s[i] == s[j]`，则需要判断内部子串是否为回文：

$$
dp[i][j] = dp[i+1][j-1]
$$

即**两端相同，内部也是回文，整个子串才是回文**。

### 初始状态和边界条件

-   `i == j`：单个字符一定是回文，`dp[i][j] = True`。
-   `j == i + 1`：两个字符相同就是回文。
-   其余状态初始化为 `False`。

### 状态转移方程求解

-   `i` **从右往左遍历**，`j` **从** `i` **往右遍历**，保证内部状态 `dp[i+1][j-1]` 已经计算完成。
-   如果 `dp[i][j] = True`，且当前子串更长，就更新 `start` **和** `max_len`。
-   最后返回 `s[start:start+max_len]`。

## 代码

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        n = len(s)
        dp = [[False] * (n + 1) for _ in range(n + 1)]
        start = 0
        max_len = 0

        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                if i ==j:
                    dp[i][j] = True
                elif s[i] == s[j]:
                    if j == i + 1:
                        dp[i][j] = True
                    else:
                        dp[i][j] = dp[i + 1][j - 1]

                if dp[i][j] and j - i + 1 >max_len:
                    start = i
                    max_len = j - i + 1

        return s[start: start + max_len]
```
