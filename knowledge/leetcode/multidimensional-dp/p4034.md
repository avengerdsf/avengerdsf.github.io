## 题目

给定一个 `m × n` 的非负整数矩阵 `grid`，其中每个位置的数字表示经过该位置的路径代价。

机器人从矩阵的**左上角**出发，每次只能**向右或向下移动一步**，最终到达矩阵的右下角。

请计算从左上角到右下角的**最小路径总和**。

路径总和包括起点和终点的数值。

**输入格式**

第一行输入两个整数 `m` 和 `n`，分别表示矩阵的行数和列数。

接下来输入 `m` 行，每行包含 `n` 个非负整数，表示矩阵 `grid`。

**输出格式**

输出一个整数，表示最小路径总和。

**输入示例**

```text
3 3
1 3 1
1 5 1
4 2 1
```

**输出示例**

```text
7
```

**说明**

最小路径为：

```text
1 → 3 → 1 → 1 → 1
```

路径总和为 `1 + 3 + 1 + 1 + 1 = 7`。

**另一个示例**

```text
2 3
1 2 3
4 5 6
```

**输出示例**

```text
12
```

**说明**

最小路径为 `1 → 2 → 3 → 6`，路径总和为 `12`。

**数据范围**

-   `1 <= m, n <= 200`
-   `0 <= grid[i][j] <= 100`

## 思路

### 定义状态

`dp[i][j]` 表示**从左上角到达位置** `(i,j)` **的最小路径总和**，直接在原矩阵 `grid` 上更新。

### 状态转移方程

由于只能**向右或向下移动**，因此选择上方和左方中**路径和较小的一边**，再加上当前位置的值：

$$
dp[i][j] = \min(dp[i-1][j],\ dp[i][j-1]) + grid[i][j]
$$

### 初始状态和边界条件

-   `dp[0][0] = grid[0][0]`，起点的路径和就是自身。
-   **第一行**只能从左侧到达，依次累加左侧路径和。
-   **第一列**只能从上方到达，依次累加上方路径和。

### 状态转移方程求解

-   从左上到右下遍历，选择**上方和左方的最小路径和**，加上当前值并原地更新。
-   最后返回 `grid[m-1][n-1]`，即最小路径总和。

## 代码

```python
class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        for i in range(1, m):
            grid[i][0] += grid[i - 1][0] 
            
        for j in range(1, n):
            grid[0][j] += grid[0][j - 1] 

        for i in range(1, m):
            for j in range(1, n):
                grid[i][j] = min(grid[i - 1][j], grid[i][j - 1]) + grid[i][j]

        return grid[m - 1][n - 1]
```
