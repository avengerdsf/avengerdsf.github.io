## 题目

给定两个字符串 `text1` 和 `text2`，请返回这两个字符串的最长公共子序列的长度。

如果两个字符串不存在公共子序列，则返回 `0`。

**注意：**

-   子序列可以不连续，但必须保持字符的相对顺序。
-   公共子序列必须同时存在于两个字符串中。
-   要求返回的是最长公共子序列的长度，而不是子序列本身。

**输入格式**

第一行输入字符串 `text1`。

第二行输入字符串 `text2`。

**输出格式**

输出一个整数，表示最长公共子序列的长度。

**输入示例**

```text
abcde
ace
```

**输出示例**

```text
3
```

**说明**

最长公共子序列为 `ace`，长度为 `3`。

**另一个示例**

```text
abc
abc
```

**输出示例**

```text
3
```

**第三个示例**

```text
abc
def
```

**输出示例**

```text
0
```

**说明**

两个字符串没有公共子序列，因此输出 `0`。

**数据范围**

-   `1 <= len(text1), len(text2) <= 1000`
-   两个字符串仅由小写英文字母组成。

  

## 思路

### 定义状态

`dp[i][j]` 表示 `text1` **前** `i` **个字符和** `text2` **前** `j` **个字符的最长公共子序列长度**。

### 状态转移方程

如果 `text1[i-1] == text2[j-1]`，说明两个前缀的最后一个字符相同，可以接在之前的公共子序列后面：

$$
dp[i][j] = dp[i-1][j-1] + 1
$$

否则，两个末尾字符不能同时作为公共子序列的结尾，需要**分别舍弃其中一个字符，取最大值**：

$$
dp[i][j] = \max(dp[i-1][j], dp[i][j-1])
$$

### 初始状态和边界条件

-   `dp[0][j] = 0`：第一个字符串为空。
-   `dp[i][0] = 0`：第二个字符串为空。
-   `1 <= i <= n`，`1 <= j <= m`。

### 状态转移方程求解

-   从左到右遍历两个字符串，逐步更新 `dp[i][j]`。
-   最后返回 `dp[n][m]`，表示两个完整字符串的最长公共子序列长度。

## 代码

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        n, m = len(text1), len(text2)
        dp = [[0] * (m + 1) for _ in range(n + 1)]
        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    # 如果最后一个字符不相等，就删掉其中一个字符，取更优结果
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

        return dp[n][m]
```
