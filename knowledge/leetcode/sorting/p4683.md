## 题目

给定一个长度为 `n` 的整数数组，请使用快速排序将数组按从小到大的顺序排列。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个整数，表示待排序数组。

**输出格式**

输出排序后的数组，元素之间用空格分隔。

**输入示例**

```text
6
5 2 3 1 4 6
```

**输出示例**

```text
1 2 3 4 5 6
```

**数据范围**

-   `1 <= n <= 100000`
-   `-10^9 <= nums[i] <= 10^9`

## 思路

-   选基准：选择一个 `pivot`。
-   左右划分：把**小于 pivot 的放左边，大于 pivot 的放右边**。
-   递归排序：分别对左右两部分继续快速排序。

## 代码

```python
class Solution:
    def quickSort(self, nums: List[int], l: int, r: int) -> None:
        if l >= r:
            return
        
        i = l
        for j in range(l, r):
            if nums[j] <= nums[r]:
                nums[j], nums[i] = nums[i], nums[j]
                i += 1

        nums[r], nums[i] = nums[i], nums[r]

        self.quickSort(nums, l, i - 1)
        self.quickSort(nums, i + 1, r)
```

## 注意点

-   `pivot` 是 `nums[r]`，所以 `range(l, r)`不能包含** `**r`。
-   `i` 表示 **下一个小于等于** `pivot` **的元素应该放的位置**。
-   满足条件时要 **先交换，再** `i += 1`。
-   遍历结束后要把 `pivot` **交换到** `i` **的位置**。
-   递归区间是 `l ~ i-1` **和** `i+1 ~ r`，不能再包含 `i`。
-   终止条件必须是 `l >= r`。
