## 题目

给定一个未排序的整数数组 `nums`，找出数字连续的最长序列，并返回该序列的长度。

要求算法的时间复杂度尽量达到 `O(n)`。

**输入格式**

第一行输入一个整数 `n`，表示数组中元素的个数。

第二行输入 `n` 个整数，表示数组 `nums`。

**输出格式**

输出最长连续序列的长度。

**输入示例**

```text
6
100 4 200 1 3 2
```

**输出示例**

```text
4
```

**说明**

最长连续序列为：

```text
1 2 3 4
```

因此最长连续序列的长度为 `4`。

**数据范围**

-   `1 <= n <= 100000`
-   `-10^9 <= nums[i] <= 10^9`

## 解题思路

-   **建立集合**：把所有数字放进 `set`，方便快速判断某个数字是否存在。
-   **找起点**：如果 `x - 1` 不在集合中，说明 `x` 是连续序列起点。
-   **向后查找**：不断检查 `x + 1、x + 2...` 是否存在。
-   **记录最大长度**：更新最长连续序列长度。

## 代码

```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        max_len = 0
        s = set(nums)
        for num in s:
            if num - 1 not in s:
                cur_num = num
                while cur_num + 1 in s:
                    cur_num += 1

                max_len = max(max_len, cur_num - num + 1)

        return max_len
```

## set 去重

```python
nums = [100, 4, 200, 1, 3, 2, 2]
s = set(nums)
print(s)  # {1, 2, 3, 4, 100, 200}
```

-   `set(nums)` 自动去掉重复元素
-   得到的是集合，无序
-   需要列表时再转回
