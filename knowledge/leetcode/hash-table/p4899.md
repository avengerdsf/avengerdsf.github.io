## 题目

请设计并实现一个满足 LRU（最近最少使用）缓存约束的数据结构。

缓存具有固定容量 `capacity`，支持以下两种操作：

-   `get key`：如果 `key` 存在于缓存中，返回对应的值，并将该键标记为最近使用；如果不存在，返回 `-1`。
-   `put key value`：将键值对写入缓存。如果 `key` 已存在，则更新其值并将其标记为最近使用；如果缓存容量已满，则删除最久未使用的键值对。

**输入格式**

第一行输入两个整数 `capacity` 和 `m`，分别表示缓存容量和操作次数。

接下来 `m` 行，每行表示一次操作：

```text
put key value
```

或：

```text
get key
```

**输出格式**

对于每次 `get` 操作，输出对应的查询结果。

**输入示例**

```text
2 9
put 1 1
put 2 2
get 1
put 3 3
get 2
put 4 4
get 1
get 3
get 4
```

**输出示例**

```text
1
-1
-1
3
4
```

**说明**

缓存容量为 `2`。

执行 `get 1` 后，键 `1` 变为最近使用。

执行 `put 3 3` 时，键 `2` 是最久未使用的，因此被淘汰。

执行 `put 4 4` 时，键 `1` 是最久未使用的，因此被淘汰。

**数据范围**

-   `1 <= capacity <= 10000`
-   `1 <= m <= 100000`
-   `0 <= key, value <= 10^9`

## 思路

-   **建立有序字典**：用 `OrderedDict` 保存缓存内容，字典中的顺序表示使用先后。
-   **get 操作**：如果 `key` 不存在返回 `-1`；存在时先删除，再重新插入到末尾，表示它刚被使用。
-   **put 操作**：如果 `key` 已存在，先删除旧值，再把新值插入末尾。
-   **容量超限**：删除最前面的元素，因为它是最久没有被使用的。

## 代码

```python
from collections import OrderedDict

class LRU:
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = OrderedDict()

    def get(self, key):
        if key not in self.cache:
            return -1

        val = self.cache.pop(key)
        self.cache[key] = val
        return val

    def put(self, key, val):
        if key in self.cache:
            self.cache.pop(key)

        self.cache[key] = val

        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)

def main():
    capacity, m = map(int, input().split())
    order_dict = LRU(capacity)
    for _ in range(m):
        order = list(input().split())
        tp = order[0]
        if tp == 'put':
            key = int(order[1])
            val = int(order[2])
            order_dict.put(key, val)
        elif tp == 'get':
            key = int(order[1])
            val = order_dict.get(key)
            print(val)

if __name__ == "__main__":
    main()
```

## 注意点

### OrderedDict

`OrderedDict` 是一个**会记录键值对插入顺序的字典**，并支持方便地调整和删除最前/最后的元素，很适合实现 LRU 缓存。

### pop(key)

`pop(key)`：删除指定 `key`，并返回对应的 `value`。

```python
val = cache.pop(key)
```

### popitem(last=False)

`popitem(last=False)`：删除并返回第一个键值对，LRU 中用于删除最久未使用的元素。

```python
cache.popitem(last=False)
```

`popitem(last=True)`：删除并返回最后一个键值对。

### cache[key] = val

`cache[key] = val`：新增或修改键值对，新插入的元素位于末尾。

```python
cache[key] = val
```
