## 题目

给定一个字符串数组，将字母异位词组合在一起。

字母异位词是指由重新排列源单词中的所有字母得到的新单词。两个字符串包含的字母及其出现次数完全相同，只是排列顺序不同。

**输入格式**

第一行输入一个整数 `n`，表示字符串的数量。

第二行输入 `n` 个字符串，字符串之间用空格分隔。

**输出格式**

将所有字母异位词分到同一组。

每组输出一行，组内字符串按照它们在原输入中的先后顺序输出。

**输入示例**

```text
6
eat tea tan ate nat bat
```

**输出示例**

```text
eat tea ate
tan nat
bat
```

**数据范围**

-   `1 <= n <= 1000`
-   输入字符串仅由小写英文字母组成

## 解题思路

1.  **排序作 key**：异位词排序后结果相同。
2.  **哈希表分组**：相同 `key` 的字符串放到一起。
3.  **最后排序**：组内排序，再按组大小排序。

## 代码

```python
def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        record = {}
        res = []
        for sub_str in strs:
            key = "".join(sorted(sub_str))

            if not record.get(key):
                record[key] = [sub_str]
            else:
                record[key].append(sub_str)

        for key in record.keys():
            record[key].sort()
            res.append(record[key])

        res.sort(key=lambda x: len(x))
        return res
```

## 注意点

### `key=lambda x: x[0]`

**等价写法**

```python
key=lambda x: x[0]
```

等价于：

```python
def f(x):
    return x[0]

list.sort(key=f)
```

### sort 与 sorted 的区别

```python
nums = [3, 1, 2]

# sort：原地排序，返回 None
nums.sort()
print(nums)  # [1, 2, 3]

# sorted：返回新列表，原对象不变
nums = [3, 1, 2]
new_nums = sorted(nums)
print(nums)      # [3, 1, 2]
print(new_nums)  # [1, 2, 3]
```

-   `list.sort()`：只用于列表，原地修改，返回 `None`
-   `sorted()`：可用于任何可迭代对象，返回新列表
-   两者都支持 `key` 和 `reverse` 参数
