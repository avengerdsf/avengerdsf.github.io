## 题目

**P4003. 移动零**

给定一个整数数组 `nums`，将所有 `0` 移动到数组末尾，同时保持所有非零元素的相对顺序不变。

要求在原数组上进行操作，不能额外复制一个新的数组。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个整数，表示数组 `nums`。

**输出格式**

输出移动零后的数组。

**输入示例**

```text
5
0 1 0 3 12
```

**输出示例**

```text
1 3 12 0 0
```

**说明**

将所有非零元素按照原来的相对顺序移动到前面，再把 `0` 放到数组末尾。

**数据范围**

-   `1 <= n <= 100000`
-   `-10^9 <= nums[i] <= 10^9`

## 思路

用**双指针**，`fast` 负责遍历数组，`slow` 指向下一个非零元素应该放的位置；如果 `fast` 指向非零元素，就交换 `nums[fast]` 和 `nums[slow]`，然后 `fast` **和** `slow` **同时右移**；如果是 `0`，则只移动 `fast`。

![move_zero_1020304506_cn.gif](leetcode/assets/双指针-1.gif)

## 代码

```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1
```
