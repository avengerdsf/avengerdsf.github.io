## 题目

给定一个长度为 `n` 的非负整数数组 `height`，其中每个元素表示宽度为 `1` 的柱子的高度。

![image.png](leetcode/assets/双指针-3.png)

请计算这些柱子排列后，下雨时能够接住多少雨水。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个非负整数，表示数组 `height`。

**输出格式**

输出一个整数，表示能够接住的雨水总量。

**输入示例**

```text
12
0 1 0 2 1 0 1 3 2 1 2 1
```

**输出示例**

```text
6
```

**说明**

对于每个位置，能够接住的雨水量由左侧最高柱子和右侧最高柱子中的较小值决定。

该示例最终能够接住的雨水总量为 `6`。

**数据范围**

-   `1 <= n <= 100000`
-   `0 <= height[i] <= 100000`

## 思路

-   双指针：左右指针**从两端向中间移动**。
-   记录最高柱：维护 `left_max` 和 `right_max`。
-   计算雨水：**哪边最高柱更低，就计算哪边** `最高柱 - 当前高度`，然后移动该指针。
-   累加结果：直到**左右指针相遇**。

![image.png](leetcode/assets/双指针-4.gif)

## 代码

```python
class Solution:
    def trap(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        max_left, max_right, max_velocity = 0, 0, 0
        while left < right:
            max_left = max(max_left, height[left])
            max_right = max(max_right, height[right])

            if height[right] < height[left]:
                max_velocity = max_right - height[right]
                right -= 1
            else:
                max_velocity = max_left - height[left]
                left += 1

        return max_velocity
```

## 注意点

针对这两类接雨水问题可以记成：

-   **盛最多水的容器**：哪边矮，移动哪边。
-   **接雨水**：哪边矮，先处理哪边，再移动哪边。

区别是：

-   盛水容器算的是 **两根柱子之间的面积**。
-   接雨水算的是 **当前位置能积多少水**。
