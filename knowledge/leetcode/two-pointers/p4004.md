## 题目

给定一个长度为 `n` 的整数数组 `height`。

数组中的第 `i` 个元素表示一条竖线的高度，第 `i` 条竖线的两个端点分别为 `(i, 0)` 和 `(i, height[i])`。

请找出两条竖线，使它们与 x 轴共同组成一个容器，并且这个容器能够装最多的水。

返回容器能够储存的最大水量。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个整数，表示数组 `height`。

**输出格式**

输出一个整数，表示能够储存的最大水量。

**输入示例**

```text
9
1 8 6 2 5 4 8 3 7
```

**输出示例**

```text
49
```

**说明**

![image.png](leetcode/assets/双指针-2.png)

选择下标 `1` 和 `8` 的两条竖线：

```text
height[1] = 8
height[8] = 7
```

容器宽度为：

```text
8 - 1 = 7
```

有效高度为：

```text
min(8, 7) = 7
```

因此面积为：

```text
7 × 7 = 49
```

**数据范围**

-   `2 <= n <= 100000`
-   `0 <= height[i] <= 10000`

## 思路

双指针从两端向中间移动，每次计算当前面积，并移动较短的一边，同时记录最大面积。

## 代码

```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        max_velocity = 0
        while left < right:
            if height[left] > height[right]:
                valid_height = height[right]
                left += 1
            else:
                valid_height = height[left]
                right -= 1

            max_velocity = max(max_velocity, valid_height * (right - left))

        return max_velocity
```

## 注意点

上述代码对输入 `[1, 8, 6, 2, 5, 4, 8, 3, 7]` 返回 `7`，题目要求的最大面积为 `49`。当前实现移动了较高的一侧，并在移动后使用新的宽度计算面积。双指针应先按当前两端计算面积，再移动较短的一侧。
