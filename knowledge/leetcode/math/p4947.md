## 题目

给定一个整数 `n`，请判断它是否为丑数。

丑数是指**只包含质因数** `2`、`3` **和** `5` **的正整数**。

特别地，`1` 也被认为是丑数。

**输入格式**

输入一个整数 `n`。

**输出格式**

如果 `n` 是丑数，输出 `true`，否则输出 `false`。

**输入示例**

```text
6
```

**输出示例**

```text
true
```

**说明**

`6 = 2 × 3`，只包含质因数 `2` 和 `3`，因此是丑数。

**另一个示例**

```text
14
```

**输出示例**

```text
false
```

**说明**

`14 = 2 × 7`，包含质因数 `7`，因此不是丑数。

**第三个示例**

```text
1
```

**输出示例**

```text
true
```

**数据范围**

-   `-2^31 <= n <= 2^31 - 1`

## 思路

思路：遍历质因数 `2、3、5`，如果当前数字能被整除，就不断整除该因数；不能整除则跳过，最后判断剩余数字是否为 `1`，是则为丑数，否则不是。

## 代码

```python
arr = [2,3,5]
num = int(input())

if num == 1:
    print("true")
    exit()

for a in arr:
    while num % a == 0:  
        num //= a

    if num  == 1:
        print("true")
        exit()     
        
print("false")
```
