## 题目

给定一个非负整数 `n`，请计算 `n!` 的末尾有多少个连续的 `0`。

其中：

`n! = n × (n-1) × ... × 2 × 1`

规定 `0! = 1`。

**输入格式**

输入一个非负整数 `n`。

**输出格式**

输出一个整数，表示 `n!` 末尾连续 `0` 的数量。

**输入示例**

```text
5
```

**输出示例**

```text
1
```

**说明**

`5! = 120`，末尾有 `1` 个 `0`。

**另一个示例**

```text
10
```

**输出示例**

```text
2
```

**说明**

`10! = 3628800`，末尾有 `2` 个连续的 `0`。

**数据范围**

-   `0 <= n <= 10000`

## 思路

阶乘末尾每个 `0` 都由 `2 × 5` 产生，而因数 `2` 的数量远多于 `5`，所以只需要统计 `n!` 中因数 `5` 的数量。

-   每次执行 `n //= 5`，统计当前包含的因数 `5` 的数量。
-   将结果累加到 `ans`，直到 `n == 0`。
-   注意：`25` **包含两个因数** `5`，`125` **包含三个**，因此需要重复整除。

## 代码

```python
def trailingZeroes (n):
    i = 5
    cnt = 0
    while n:
        n //= i
        cnt += n

    return cnt
```
