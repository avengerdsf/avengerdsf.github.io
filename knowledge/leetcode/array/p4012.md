## 题目

**P4012. 合并区间**

给定一个区间数组 `intervals`，其中 `intervals[i] = [start_i, end_i]`。

请合并所有重叠的区间，并返回合并后的不重叠区间。

**输入格式**

第一行输入一个整数 `n`，表示区间数量。

接下来 `n` 行，每行输入两个整数 `start` 和 `end`，表示一个区间。

**输出格式**

输出合并后的所有区间，每个区间输出一行。

**输入示例**

```text
4
1 3
2 6
8 10
15 18
```

**输出示例**

```text
1 6
8 10
15 18
```

**说明**

区间 `[1,3]` 和 `[2,6]` 存在重叠，因此合并为：

```text
1 6
```

其余区间互不重叠。

**数据范围**

-   `1 <= n <= 100000`
-   `0 <= start_i <= end_i <= 10^9`

## 思路

先按区间左端点**从小到大排序**，再依次遍历；如果当前区间左端点落在 `res` 最后一个区间内，就**更新右端点完成合并**，否则直接加入 `res`。

## 代码

```python
n = int(input())
res = []
intervals = [list(map(int, input().split())) for _ in range(n)]
intervals.sort(key = lambda x:x[0])

i = 0
while i < len(intervals):
    compare = res[-1]
    if compare[0] <= intervals[i][0] <= compare[1]:
        res.pop()
        res.append([min(intervals[i][0], intervals[i][0]), max(intervals[i][1], intervals[i][1])])
    else:
        res.append(intervals[i])
    i += 1

for a in res:
    print(' '.join(map(str, a)))

```
