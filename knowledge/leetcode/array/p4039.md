## 题目

给定一个未排序的整数数组 `nums`，请找出其中缺失的最小正整数。

要求算法的时间复杂度为 `O(n)`，并且只能使用 `O(1)` 的额外空间。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个整数，表示数组 `nums`。

**输出格式**

输出缺失的第一个正整数。

**输入示例**

```text
4
3 4 -1 1
```

**输出示例**

```text
2
```

**说明**

数组中存在正整数 `1`，但不存在 `2`，因此缺失的第一个正整数为 `2`。

**数据范围**

-   `1 <= n <= 100000`
-   `-10^9 <= nums[i] <= 10^9`

## 思路

用**原地哈希**，把值为 `i` 的数字放到下标 `i-1` 的位置；整理完成后再次遍历数组，找到第一个满足 `nums[i] != i + 1` 的位置，返回 `i + 1`。

## 代码

```python
class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        n = len(nums)

        for i in range(n):
            while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
                nums[nums[i] - 1], nums[i] = nums[i], nums[nums[i] - 1]

        for i in range(n):
            if nums[i] != i + 1:
                return i + 1

        return n + 1
```
