## 题目

给定一个整数数组 `nums`，请找出一个具有最大和的连续子数组，并返回该子数组的最大和。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个整数，表示数组 `nums`。

**输出格式**

输出一个整数，表示连续子数组的最大和。

**输入示例**

```text
9
-2 1 -3 4 -1 2 1 -5 4
```

**输出示例**

```text
6
```

**说明**

最大和的连续子数组为：

```text
4 -1 2 1
```

其元素和为：

```text
6
```

**数据范围**

-   `1 <= n <= 100000`
-   `-10^9 <= nums[i] <= 10^9`

## 思路

用 **DP**，`dp[i]` 表示**以** `nums[i-1]` **结尾的最大子数组和**；如果前面的最大和 `dp[i-1] < 0`，继续加只会让当前结果变小，所以**从当前元素重新开始**，否则就接在前面继续累加。

## 代码

```python
n = int(input())

nums = list(map(int, input().split()))

dp = [-10*18] * (n + 1)
for i in range(1, n + 1):
    dp[i] = max(nums[i - 1], dp[i-1] + nums[i - 1])

max_num = 0
for i in range(1, n + 1):
    max_num = max(max_num, dp[i])

print(max_num)
```
