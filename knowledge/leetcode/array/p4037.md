## 题目

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置。

**输入格式**

第一行输入两个整数 `n` 和 `k`，分别表示数组长度和向右轮转的位置数。

第二行输入 `n` 个整数，表示数组 `nums`。

**输出格式**

输出轮转后的数组，元素之间用空格分隔。

**输入示例**

```text
7 3
1 2 3 4 5 6 7
```

**输出示例**

```text
5 6 7 1 2 3 4
```

**说明**

原数组：

```text
1 2 3 4 5 6 7
```

向右轮转 `3` 个位置后：

```text
5 6 7 1 2 3 4
```

## 思路

先将整个数组**整体反转**，再分别反转**前** `k` **个元素**和**从** `k` **开始到末尾的元素**，即可得到向右轮转后的结果。

## 代码

```python
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        l, r = 0, len(nums) - 1

        self.reverse(l, r, nums)

        self.reverse(l, k - 1, nums)
        self.reverse(k, r, nums)

    def reverse(self, l, r, nums):
        while l < r :
            nums[l], nums[r] = nums[r], nums[l]
            l += 1
            r -= 1
```
