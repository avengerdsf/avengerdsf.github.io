## 二分查找

> 先定义搜索区间的语义，再决定 `while` 条件和边界收缩方式。

| 模板 | 区间 | 循环条件 | 适合场景 |
| --- | --- | --- | --- |
| 闭区间 | `[l, r]` | `l <= r` | 普通查找、左右边界 |
| 半开区间 | `[l, r)` | `l < r` | lower_bound 风格 |

闭区间模板：

```cpp
while (l <= r) {
    int mid = l + (r - l) / 2;
    if (check(mid)) {
        r = mid - 1;
    } else {
        l = mid + 1;
    }
}
```

常见问题：

- 左右边界语义和 `while` 条件不匹配。
- 找左边界时命中后直接返回，导致无法继续向左收缩。
- `mid = (l + r) / 2` 在大整数范围可能溢出。

## 滑动窗口

核心流程不是“双指针”三个字，而是维护一个**可增量更新的合法窗口**：

1. 右指针加入新元素并更新窗口状态。
2. 当窗口不合法时持续移动左指针并恢复合法状态。
3. 在题目要求的时机统计答案。

```cpp
for (int r = 0, l = 0; r < n; ++r) {
    add(a[r]);
    while (!valid()) {
        remove(a[l++]);
    }
    update_answer(l, r);
}
```

常见问题：合法窗口可能有多个，答案统计位置必须与题目定义一致，不能看到“合法”就机械地累加一次。

## DFS / BFS

先判断问题结构，再选择遍历方式：

- 树上 DFS 通常记录父节点即可避免回边。
- 一般图需要 `visited`。
- 无权最短路径优先 BFS。
- 多源扩散问题把全部起点同时入队。

```cpp
queue<int> q;
for (int s : sources) {
    q.push(s);
    dist[s] = 0;
}

while (!q.empty()) {
    int u = q.front();
    q.pop();
    for (int v : graph[u]) {
        if (dist[v] != -1) continue;
        dist[v] = dist[u] + 1;
        q.push(v);
    }
}
```

## 并查集

并查集适合处理动态合并和连通性查询。基础优化是：

- 路径压缩。
- 按秩或按集合大小合并。

```cpp
int find(int x) {
    if (parent[x] == x) return x;
    return parent[x] = find(parent[x]);
}
```

判断是否在同一集合只比较 `find(a) == find(b)`，不要直接比较 `parent[a]` 和 `parent[b]`。

## 拓扑排序

拓扑排序处理有向图中的依赖顺序：

1. 统计每个节点入度。
2. 所有入度为 0 的节点入队。
3. 每弹出一个节点，就把它指向节点的入度减 1。
4. 新出现的 0 入度节点继续入队。

如果最终处理节点数小于 `n`，说明图中存在环。

```cpp
while (!q.empty()) {
    int u = q.front();
    q.pop();
    ++count;
    for (int v : graph[u]) {
        if (--indegree[v] == 0) q.push(v);
    }
}
```

## 动态规划

DP 优先写清楚状态语义，再写转移：

> `dp[i]` 或 `dp[i][j]` 到底表示什么，必须能用一句完整的话说明。

检查顺序：

1. 状态定义。
2. 初始状态。
3. 状态转移。
4. 遍历顺序。
5. 不可达状态如何表示。

| 类型 | 关键点 |
| --- | --- |
| 最大子段和 | 当前状态是否必须以 `i` 结尾 |
| LIS | `dp[i]` 的结尾位置语义 |
| 0/1 背包 | 容量逆序 |
| 完全背包 | 容量正序 |
| 分组背包 | 每组最多选一个，循环层级不能乱 |
| 区间 / 多段 DP | 明确阶段、区间与决策 |
