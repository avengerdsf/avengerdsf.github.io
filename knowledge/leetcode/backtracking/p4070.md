## 题目

给定一个仅包含数字 `2` 到 `9` 的字符串 `digits`，请返回这些数字在电话按键上能够表示的所有字母组合。

数字与字母的对应关系如下：

```text
2 -> abc
3 -> def
4 -> ghi
5 -> jkl
6 -> mno
7 -> pqrs
8 -> tuv
9 -> wxyz
```

**输入格式**

输入一个字符串 `digits`，其中只包含数字 `2` 到 `9`。

**输出格式**

输出所有可能的字母组合，每个组合输出一行。

**输入示例**

```text
23
```

**输出示例**

```text
ad
ae
af
bd
be
bf
cd
ce
cf
```

**说明**

数字 `2` 可以对应 `a、b、c`，数字 `3` 可以对应 `d、e、f`。

从每个数字对应的字母集合中各选择一个字母，即可得到所有可能的组合。

## 思路

-   用哈希表保存**数字对应的字母集合**。
-   DFS 按 `digits` 的位置向后递归，每一层遍历当前数字对应的所有字母。
-   选择一个字母加入 `tmp` 后递归下一位，返回时执行 `tmp.pop()` **回溯**。
-   当 `i == len(digits)` 时，说明已经组成一个完整字符串，加入 `res`。

## 代码

```python
class Solution:
    def __init__(self):
        self.phone = {
            "2":"abc",
            "3": "def",
            "4": "ghi",
            "5": "jkl",
            "6": "mno",
            "7": "pqrs",
            "8": "tuv",
            "9": "wxyz"
        }
        self.digits = None
        self.res = []

    def letterCombinations(self, digits: str) -> List[str]:
        # 请在这里实现
        self.digits = digits
        self.dfs(0, [])
        return self.res

    def dfs(self, i, tmp):
        if i >= len(self.digits):
            self.res.append(''.join(tmp[:]))
            return

        for s in self.phone[self.digits[i]]:
            tmp.append(s)
            self.dfs(i + 1, tmp)
            tmp.pop()
```
