## 题目

给定一个 `m × n` 的字符网格 `board` 和一个字符串 `word`。

请判断是否能够在网格中找到这个单词。

单词必须按照相邻单元格中的字母顺序组成，相邻单元格只能是**上、下、左、右**四个方向。

同一个单元格中的字母在同一个单词中**不能重复使用**。

**输入格式**

第一行输入两个整数 `m` 和 `n`，分别表示网格的行数和列数。

接下来输入 `m` 行，每行包含 `n` 个字符，表示字符网格。

最后一行输入字符串 `word`。

**输出格式**

如果能够在网格中找到该单词，输出：

```text
true
```

否则输出：

```text
false
```

**输入示例**

```text
3 4
A B C E
S F C S
A D E E
ABCCED
```

**输出示例**

```text
true
```

**说明**

可以按照相邻字符：

```text
A -> B -> C -> C -> E -> D
```

组成字符串 `ABCCED`，因此返回 `true`。

  

## 思路

-   从所有可能的起点开始搜索。
-   当前格子加入 `tmp`，并标记为**已访问**。
-   每次递归先检查刚加入的字符是否和 `word` 对应位置一致，不一致就**剪枝**。
-   匹配则继续向**上下左右四个方向**搜索。
-   回溯时执行 `tmp.pop()` **并恢复** `record[i][j] = False`。

## 代码

```python
class Solution:
    def __init__(self):
        self.board = None
        self.word = None
        self.res = False
        self.record = None

    def exist(self, board: List[List[str]], word: str) -> bool:
        self.board = board
        self.word = word
        self.record = [[False] * len(board[0]) for _ in range(len(board))]
        for i in range(len(board)):
            for j in range(len(board[0])):
                if self.board[i][j] == word[0]:
                    self.dfs(i, j, [])
        return self.res

    def dfs(self, i, j, tmp):
        if len(tmp) == len(self.word):
            if ''.join(tmp) == self.word:
                self.res = True
            return

        if tmp and tmp[-1] != self.word[len(tmp) - 1]:
            return

        is_bound = 0 <= i < len(self.board) and 0 <= j < len(self.board[i])
        if is_bound and not self.record[i][j]:
            tmp.append(self.board[i][j])
            self.record[i][j] = True
            self.dfs(i + 1, j, tmp)
            self.dfs(i, j + 1, tmp)
            self.dfs(i, j - 1, tmp)
            self.dfs(i - 1, j, tmp)
            tmp.pop()
            self.record[i][j] = False
```
