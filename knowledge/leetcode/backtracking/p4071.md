## 题目

给定一个由互不相同的正整数组成的数组 `candidates` 和一个目标值 `target`。

请找出所有和等于 `target` 的组合。

同一个数字可以被**重复选择多次**，不同组合的顺序不影响结果。

**输入格式**

第一行输入一个整数 `n`，表示数组长度。

第二行输入 `n` 个整数，表示数组 `candidates`。

第三行输入一个整数 `target`。

**输出格式**

输出所有和等于 `target` 的组合，每个组合输出一行。

**输入示例**

```text
4
2 3 6 7
7
```

**输出示例**

```text
2 2 3
7
```

**说明**

数字可以重复选取：

```text
2 + 2 + 3 = 7
7 = 7
```

因此共有两种组合。

## 思路

-   `j` 从 `i` 开始，保证**只能往后选，避免重复组合**。
-   递归时传 `j` 而不是 `j + 1`，保证**当前数字可以重复使用**。
-   回溯时只需要恢复这次选择：`tmp.pop()` **和** `tmp_sum -= num`。

## 代码

```python
class Solution:
    def __init__(self):
        self.candidates = None
        self.target = None
        self.res = []

    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        self.candidates = candidates
        self.target = target
        self.dfs(0, [], 0)
        return self.res

    def dfs(self, i, tmp, tmp_sum):
        if tmp_sum == self.target:
            self.res.append(tmp[:])
            return

        if tmp_sum > self.target:
            return

        for j in range(i,len(self.candidates)):
            num = self.candidates[j]
            tmp.append(num)
            tmp_sum += num
            self.dfs(j, tmp, tmp_sum)
            tmp.pop()
            tmp_sum -= num
```

## 注意点

-   每层都从整个 `candidates` 重新遍历，会导致**相同组合以不同顺序重复出现**。
-   回溯时又额外递归“不选当前数”的分支，导致**搜索路径重复**。
