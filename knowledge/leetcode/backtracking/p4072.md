## 题目

给定一个整数 `n`，表示括号对数。

请生成所有由 `n` 对括号组成的合法括号字符串。

合法括号需要满足：

-   左括号 `(` 和右括号 `)` 的数量都为 `n`。
-   任意位置之前，右括号数量不能超过左括号数量。
-   最终所有括号能够完全匹配。

**输入格式**

输入一个整数 `n`。

**输出格式**

输出所有合法括号字符串，每个字符串输出一行。

**输入示例**

```text
3
```

**输出示例**

```text
((()))
(()())
(())()
()(())
()()()
```

## 思路

-   使用**回溯**构造字符串，分别记录已经使用的左括号数量 `left` 和右括号数量 `right`。
-   当 `left < n` 时，可以继续加入左括号。
-   当 `left > right` 时，才能加入右括号，保证任意时刻右括号不会多于左括号。
-   当 `left == right == n` 时，得到一个合法括号字符串。

## 代码

```python
class Solution:
    def __init__(self):
        self.n = None
        self.res = []

    def generateParenthesis(self, n: int) -> List[str]:
        self.n = n
        self.dfs(0, 0, [])
        return self.res

    def dfs(self, left, right, tmp):
        if left == right and right == self.n:

            self.res.append(''.join(tmp[:]))
            return

        if left > self.n or right > self.n:
            return

        tmp.append('(')
        self.dfs(left + 1, right, tmp)
        tmp.pop()
        if left > right:
            tmp.append(')')
            self.dfs(left, right + 1, tmp)
            tmp.pop()
```

## 注意点

-   回溯中每次做出选择后，递归结束都要**撤销本层选择，恢复进入这一层前的状态**。
