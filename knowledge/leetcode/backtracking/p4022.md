## 题目

给定一个由互不相同整数组成的数组 `nums`，请输出该数组的所有子集。

子集中元素的相对顺序保持与原数组一致，每个元素最多选择一次。

幂集包含空集以及数组本身。

**输入格式**

输入若干个互不相同的整数，表示数组 `nums`。

**输出格式**

输出数组的所有子集，每个子集输出一行。

空集输出为空行。

**输入示例**

```text
1 2 3
```

**输出示例**

```text

1
1 2
1 2 3
1 3
2
2 3
3
```

**说明**

数组 `[1, 2, 3]` 一共有 `2^3 = 8` 个子集。

## 思路

-   对每个元素都有两种选择：**选它**或**不选它**。
-   递归进入下一位，直到 `i == len(nums)`，把当前 `tmp` 加入结果。
-   选择当前元素后要 `tmp.pop()`，完成**回溯**，再进入“不选当前元素”的分支。

## 代码

```python
class Solution:
    def __init__(self):
        self.nums = None
        self.res = []

    def subsets(self, nums: List[int]) -> List[List[int]]:
        self.nums = nums
        self.dfs(0, [])
        return self.res

    def dfs(self, i, tmp):
        if i == len(self.nums):
            self.res.append(tmp[:])
            return
        
        tmp.append(self.nums[i])
        self.dfs(i + 1, tmp)
        tmp.pop()
        self.dfs(i + 1, tmp)
```
