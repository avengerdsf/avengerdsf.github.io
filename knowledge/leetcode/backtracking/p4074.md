## 题目

给定一个字符串 `s`，请将字符串划分成若干个子串，使得每个子串都是回文串。

请返回所有可能的划分方案。

回文串是指正着读和反着读都相同的字符串。

**输入格式**

输入一个字符串 `s`。

**输出格式**

输出所有合法的回文划分方案。

每种方案输出一行，子串之间用空格分隔。

**输入示例**

```text
aab
```

**输出示例**

```text
a a b
aa b
```

**说明**

字符串 `aab` 有两种合法划分：

```text
a | a | b
aa | b
```

其中每一部分都是回文串。

## 思路

-   从位置 `i` 开始，枚举**当前子串的结束位置** `j`。
-   如果 `s[i:j]` 是**回文串**，就加入 `tmp`，继续从 `j` 位置递归切分。
-   当 `i == len(s)` 时，说明整个字符串已经切完，把当前方案加入 `res`。
-   递归返回后执行 `tmp.pop()`，**回溯尝试其他切分位置**

## 代码

```python
class Solution:
    def __init__(self):
        self.res = []
        self.s = None

    def partition(self, s: str) -> List[List[str]]:
        self.s = s
        self.dfs(0, [])
        return self.res

    def dfs(self, i, tmp):
        if i == len(self.s):
            self.res.append(tmp[:])
            return

        for j in range(i + 1, len(self.s) + 1):
            if self.s[i:j] == self.s[i:j][::-1]:  
                tmp.append(self.s[i:j])
                self.dfs(j, tmp)
                tmp.pop()
```
