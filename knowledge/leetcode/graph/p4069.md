## 题目

请实现一个 Trie（前缀树），支持以下操作：

-   `insert(word)`：向前缀树中插入字符串 `word`。
-   `search(word)`：判断字符串 `word` 是否完整存在于前缀树中。
-   `startsWith(prefix)`：判断前缀树中是否存在以 `prefix` 开头的字符串。

**输入格式**

第一行输入一个整数 `m`，表示操作次数。

接下来输入 `m` 行，每行表示一次操作：

```text
insert word
search word
startsWith prefix
```

**输出格式**

对于 `search` 和 `startsWith` 操作，输出判断结果：

```text
true
```

或：

```text
false
```

**输入示例**

```text
6
insert apple
search apple
search app
startsWith app
insert app
search app
```

**输出示例**

```text
true
false
true
true
```

**说明**

插入 `apple` 后：

-   `search("apple")` 为 `true`。
-   `search("app")` 为 `false`，因为 `app` 只是前缀，还没有作为完整单词插入。
-   `startsWith("app")` 为 `true`。
-   插入 `app` 后，`search("app")` 为 `true`。

## 思路

-   每个 Trie 节点保存**子节点映射**和一个**是否为完整单词结尾的标记**。
-   `insert`：按字符逐个向下创建节点，最后把结尾节点标记为 `is_end = True`。
-   `search`：逐字符查找，全部找到后还要判断**最后节点是否是单词结尾**。
-   `startsWith`：逐字符查找，只要前缀能完整走完就返回 `True`。

## 代码

```python
class Trie:
    def __init__(self):
        self.child = {}
        self.is_end = False

    def insert(self, word: str) -> None:
        node = self
        for ch in word:
            if ch not in node.child:
                node.child[ch] = Trie()
            
            node = node.child[ch]
        
        node.is_end = True

    def search(self, word: str) -> bool:
        node = self
        for ch in word:
            node = node.child[ch]
            
        return node.is_end
            

    def startsWith(self, prefix: str) -> bool:
        node = self
        
        for ch in prefix:
            if ch not in node.child:
                return False
            
            node = node.child[ch]
        
        return True
```
