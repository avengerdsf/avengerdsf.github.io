## 题目

你需要学习 `numCourses` 门课程，课程编号为 `0` 到 `numCourses - 1`。

给定一个数组 `prerequisites`，其中：

```text
[a, b]
```

表示如果想学习课程 `a`，必须先完成课程 `b`。

请判断是否可以完成所有课程。

**输入格式**

第一行输入两个整数 `numCourses` 和 `m`，分别表示课程数量和先修关系数量。

接下来输入 `m` 行，每行两个整数 `a` 和 `b`，表示课程 `a` 需要先完成课程 `b`。

**输出格式**

如果可以完成所有课程，输出：

```text
true
```

否则输出：

```text
false
```

**输入示例**

```text
2 1
1 0
```

**输出示例**

```text
true
```

**说明**

学习课程 `1` 之前先完成课程 `0`，因此可以完成所有课程。

**另一个示例**

```text
2 2
1 0
0 1
```

输出：

```text
false
```

因为课程 `0` 和课程 `1` 互相依赖，形成了环，无法完成所有课程。

## 思路

-   建图：记录**当前课程是哪些课程的前置课程**。
-   入度：用数组记录**每门课程还剩多少门前置课程**。
-   先把**入度为 0 的课程**加入队列。
-   每学完一门课程，就把它能解锁的课程**前置数量减 1**；减到 `0` 就加入队列。
-   最后判断完成的课程数是否等于 `numCourses`。

## 代码

```python
class Solution:
    def __init__(self, num_courses: int, prerequisites: List[List[int]]):
        self.num_courses = num_courses
        self.prerequisites = prerequisites

        # courses[x]：x 是哪些课程的前置课程
        self.courses = {}

        # record[i]：课程 i 还有多少门前置课程
        self.record = [0] * num_courses

        for prerequisite in prerequisites:
            pre_course = prerequisite[1]
            cur_course = prerequisite[0]

            if pre_course not in self.courses:
                self.courses[pre_course] = [cur_course]
            else:
                self.courses[pre_course].append(cur_course)

            self.record[cur_course] += 1

    def canFinish(self) -> bool:
        q = deque()

        # 加入的是课程编号，不是前置课程数量
        for i in range(self.num_courses):
            if self.record[i] == 0:
                q.append(i)

        cnt = 0

        while q:
            cur_course = q.popleft()
            cnt += 1

            # 只处理以当前课程为前置的课程
            for v in self.courses.get(cur_course, []):
                self.record[v] -= 1

                if self.record[v] == 0:
                    q.append(v)

        return cnt == self.num_courses
```
