## 题目

给定一个 `m × n` 的网格 `grid`，其中：

-   `0` 表示空单元格。
-   `1` 表示新鲜橘子。
-   `2` 表示腐烂橘子。

每过 `1` 分钟，腐烂橘子会使其上、下、左、右四个方向相邻的新鲜橘子变腐烂。

请计算直到所有新鲜橘子都腐烂所需要的最短时间。

如果无法使所有新鲜橘子腐烂，则输出 `-1`。

**输入格式**

第一行输入两个整数 `m` 和 `n`，分别表示网格的行数和列数。

接下来输入 `m` 行，每行包含 `n` 个整数，表示网格 `grid`。

**输出格式**

输出一个整数，表示所有新鲜橘子腐烂所需的最短时间。

如果无法全部腐烂，输出：

```text
-1
```

**输入示例**

```text
3 3
2 1 1
1 1 0
0 1 1
```

**输出示例**

```text
4
```

**说明**

腐烂橘子会同时向上下左右四个方向扩散，经过 `4` 分钟后所有新鲜橘子都腐烂。

## 思路

-   先遍历网格，把所有**初始腐烂橘子同时加入队列**，作为多个 BFS 起点。
-   按层进行 BFS，每一层表示 **1 分钟**，将上下左右相邻的新鲜橘子变成腐烂并加入下一层。
-   只要这一层确实腐烂了新的橘子，就让 `res += 1`。
-   BFS 结束后再次遍历网格，如果还有新鲜橘子 `1`，返回 `-1`；否则返回最短扩散时间 `res`。

## 代码

```python
class Solution:
    def __init__(self):
        self.grid = None
        self.res = 0

    def orangesRotting(self, grid: List[List[int]]) -> int:
        self.grid = grid
        roots = []
        for i in range(len(grid)):
            for j in range(len(grid[0])):
                if grid[i][j] == 2:
                    roots.append((i, j))

        self.bfs(roots)

        for i in range(len(grid)):
            for j in range(len(grid[0])):
                if grid[i][j] == 1:
                    return -1

        return self.res

    def bfs(self, roots):
        q = deque()
        for root in roots:
            q.append(root)

        dx, dy = [-1, 1, 0, 0], [0, 0, -1 ,1]
        while q:
            tmp = []
            while q:
                cur_node = q.popleft()
                for k in range(4):
                    i, j = cur_node[0] + dx[k], cur_node[1] + dy[k]
                    is_bound = 0 <= i < len(self.grid) and 0 <= j < len(self.grid[0])
                    if is_bound and self.grid[i][j] == 1:
                        self.grid[i][j] = 2
                        tmp.append((i, j))
            if tmp:
                self.res += 1
            for node in tmp:
                q.append(node)
```
