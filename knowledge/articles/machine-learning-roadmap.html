源内容在哪里？

完整公式、结构说明和代码示例仍以公开仓库 machine-learning-notes ↗ 为准。本页只负责建立学习顺序和章节之间的关系。

1. 监督学习：先理解“模型如何从标注数据学习”

第一阶段建立机器学习最基本的训练视角：模型、预测、损失函数、梯度下降和泛化。线性回归适合用于建立“预测值—误差—参数更新”的直觉，逻辑回归则把这个框架推进到分类问题。

  • 线性回归：模型表达、代价函数、梯度下降与特征缩放。
  • 逻辑回归：Sigmoid、决策边界、分类损失与梯度更新。
  • 过拟合：训练误差并不等价于泛化能力，正则化用于约束模型复杂度。

2. 深度学习：把单个模型扩展成可组合的网络

理解线性模型之后，再进入神经网络会更自然。重点不是先背 API，而是理解一层网络如何完成线性变换与非线性映射，以及多层网络如何通过前向传播组合起来。

  • 神经网络层与前向传播。
  • 使用 PyTorch 构建、训练和执行网络。
  • Sigmoid、ReLU、线性激活的选择。
  • Softmax 多分类与多标签分类的区别。

3. 模型评估：判断问题到底出在模型还是数据

训练出一个模型以后，下一步不是继续盲目调参，而是建立诊断框架。训练集、验证集和测试集承担不同角色；偏差、方差和学习曲线帮助判断下一步应该增加模型能力、增加数据还是调整数据分布。

  1. 先建立正确的数据划分。
  2. 用验证集选择模型和超参数。
  3. 观察偏差、方差和学习曲线。
  4. 结合错误分析决定数据或模型的下一轮迭代。

4. 决策树：学习另一类完全不同的模型结构

决策树不依赖神经网络式的连续参数更新，它通过特征划分递归构造决策结构。理解熵和信息增益以后，再进入随机森林和 XGBoost，会更容易理解 Bagging 与 Boosting 的差别。

  • 决策树、熵、信息增益与连续特征阈值。
  • One-hot 编码与离散特征处理。
  • 回归树中的叶节点预测和方差下降。
  • 随机森林的 Bagging 与随机特征子集。
  • XGBoost 的 Boosting、梯度修正与正则化。

5. 无监督学习：没有标签时如何发现结构

最后进入没有显式标签的数据问题。K-means 负责聚类，异常检测关注低概率样本，推荐系统处理用户—物品关系，PCA 则从高维空间中提取主要变化方向。

  • K-means：簇分配、质心更新、随机初始化与聚类数量。
  • 异常检测：高斯分布、概率阈值和特征选择。
  • 推荐系统：协同过滤、均值归一化与基于内容的推荐。
  • PCA：预处理、SVD、投影、重建与主成分数量选择。

如何使用这套笔记

每学一个主题，建议保持同一套阅读顺序：

  1. 先明确问题定义和输入输出。
  2. 理解目标函数或评价指标。
  3. 看清参数如何更新或结构如何生成。
  4. 最后再对应 NumPy / PyTorch 实现。

这样做的目标，是避免“会调用库但不知道算法在解决什么问题”，也避免只停留在公式而无法映射到工程代码。
