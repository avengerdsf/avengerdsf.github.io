# 个人主页与知识库重新规划

日期：2026-10-03。基线：main `8425112`。设计范围为现有原生主页与 Quartz 5 知识库；保留笔记正文、Quartz 插件和算法演示，不迁移框架。

## 目标与已确认边界

访问者可以在首页了解作者与项目，通过一个明确入口进入知识库，再沿原始目录逐级找到笔记。阅读时正文是视觉中心，导航随时可用，窗口变窄后工具不会遮挡内容。

唯一外部笔记源为 `avengerdsf/machine-learning-notes`。源仓库自动同步到 `/knowledge/machine-learning/`；本仓库 `knowledge/` 继续保存力扣等本地笔记。外部源的相对目录、文件名、资源路径和内容应在构建中完整保留。

采用现有技术栈上的统一阅读皮肤。整体替换为新框架会引入路由与插件迁移；继续叠加旧主页卡片和装饰则不能解决页面职责重叠。这两种方案均不采用。

## 核对与参考

2026-10-03 已读取最新本地 README、首页、Quartz 配置、`site-ui` 组件、共享主题生成器和部署工作流。公开首页通过 HTTP 返回 200，其样式入口与本地一致；浏览器抓取暂时超时，公开知识页未取得可视截图。最终视觉结论必须以本次完整构建的实际页面和截图为准。

以下为作者维护或官方实例，仅借鉴页面职责和阅读结构，不引入其全部功能：

- [Jacky Zhao 的个人知识库](https://jzhao.xyz/)：作者介绍、精选写作和近期笔记各有明确入口，首页不承担全部内容浏览。借鉴简介与入口分离。
- [Quartz 5 官方实例](https://quartz.jzhao.xyz/)：全文搜索、目录浏览与正文大纲服务于 Markdown 阅读。保留当前已工作的这些能力，不额外增加关系图和反向链接区域。
- [Maggie Appleton 的数字花园](https://maggieappleton.com/garden)：主题与内容入口明确，文章是独立内容页。借鉴内容层次，不照搬其多类型标签、增长阶段和元数据。
- [VitePress 官方布局说明](https://vitepress.dev/reference/default-theme-layout)：明确区分 `home` 与 `doc`，文档页承载大纲等阅读功能。本项目以现有原生主页和 Quartz 页实现相同职责划分。

## 页面职责

| 页面 | 应显示 | 不承担 |
| --- | --- | --- |
| `/` | 简短作者身份与研究方向；知识库主入口；已有项目；GitHub | 全目录树、文章正文、重复知识库预览、长篇能力说明 |
| `/knowledge/` | 知识库标题；一级笔记目录；搜索入口 | 全部后代文章列表、个人履历、项目卡片 |
| `/knowledge/<目录>/` | 当前目录标题；直属子目录与直属文章；上一级入口 | 把深层文章扁平化、插入其他主题内容 |
| `/knowledge/<文章>` | 单一文章标题与正文；目录树；按需正文大纲；编辑入口 | 能力/项目介绍、装饰性数据统计、重复文章标题 |

首页保留真实项目名称、简短介绍与源码入口。知识入口直接进入 `/knowledge/` 或真实一级目录，不链接到已无对应内容的首页锚点。主导航控制在“首页/项目/知识库/GitHub”与主题切换这组必要目的地内。

目录卡片只表达目录名及可点击方向；文章行只表达文章标题。正文中的原有注释、表格、技术标签、算法说明都属于内容，应保留。目录标题取元数据，文件组织仍取原始路径，两者不得互相替代。

## 悬浮导航与阅读布局

### 共同规则

顶栏使用固定悬浮表面，距视口顶端约 12px，单行主体高度约 56px。它独立于正文卡片，轻边框、轻阴影、适度模糊即可。首页与知识页采用同一颜色、字体、边框和控件尺寸。

主内容初始顶部留出不少于 96px，正文标题和锚点设置约 84px 的滚动避让值。导航不因滚动而覆盖文章第一行，也不在打开搜索后漂浮于搜索遮罩之上。搜索弹层和目录抽屉的层级高于顶栏。

按钮触摸区域至少 40px，窄屏优先 44px。主题、目录开关、关闭等图标必须有清晰的可访问名称。键盘焦点可见，当前导航或当前目录项目有明确状态。交互遵守减少动态效果偏好。

### 桌面（大于约 900px）

知识页顶部工具栏包含品牌/首页、搜索、目录开关、主题切换及必要操作。阅读主动作是搜索与目录；“新增笔记”“编辑本文”降低视觉权重，不能挤压标题区。上一级为真实父目录链接，直接访问深层 URL 后同样有效。

左侧目录树宽约 220–260px，位于顶栏以下并 sticky；树内容独立滚动，不使页面横向溢出。可关闭目录以扩大阅读区；关闭后开关仍然可见，重新打开恢复使用。选中文章高亮，当前路径可在树中定位。

文章栏可用宽度上限约 820px，内边距约 24–36px，标题和正文对齐。超宽窗口保持舒适行长；代码、表格和公式可占文章栏全宽并在自身内横向滚动。正文不因为屏幕变宽而扩展到不可阅读的整屏行长。

右侧正文大纲仅在有标题且剩余宽度充足时出现（约 1200px 以上），宽约 180–210px。较窄桌面隐藏右栏即可；若提供大纲按钮，不得再额外堆叠一条常驻工具栏。目录页无正文大纲，不为不存在的右栏预留空白。

### 窄屏（约 900px 及以下）

正文为单栏，外侧留白约 12–18px，文章内边距约 16–22px。顶栏仍固定可用，但收起可选操作：品牌/首页、搜索、目录开关、主题切换优先；编辑/新增放入紧凑操作区或菜单，避免两行工具栏占据首屏。

目录使用覆盖式抽屉，宽度不大于 `min(320px, 视口宽度 - 40px)`，带可见关闭按钮与遮罩。打开期间背景不可滚动；点击遮罩、关闭按钮、按 Escape 或选择文章可关闭。关闭后恢复触发按钮焦点和背景滚动；不要让隐藏目录里的链接进入正常 Tab 顺序。

目录开关的 `aria-expanded` 必须随实际状态变化，窄屏初始为关闭。窗口跨越断点后不能遗留遮罩、body 滚动锁或不可见的展开状态。无需为了响应式重建文章数据。

最窄验证为 375px（附加 320px 容错检查）；品牌与控件不重叠，标题可换行，长代码仅在代码块内横向滚动。页面不得有整体横向滚动条。

## 视觉 token 与文案清理

继续使用 `assets/css/site.css` 的共享 token，由现有 `prepare-knowledge.mjs` 注入 Quartz。保留蓝色 `#3f66f2` 与深浅主题；不另建重复的主题来源。

| 项目 | 建议 |
| --- | --- |
| 背景 | 当前浅色 `#f7f8fb` / 深色 `#0c111b`，以纯色为主 |
| 表面 | 白色 / 深蓝灰，边框代替厚重阴影 |
| 字体 | 现有 Inter 与中文系统回退；代码沿用 IBM Plex Mono |
| 正文字号 | 16–17px，行高约 1.75；导航与目录不靠极小字区分层级 |
| 标题 | 页面标题约 28–40px；正文二级约 21–24px；保持固定层次 |
| 圆角 | 控件约 10–12px，常规表面约 16–20px；减少 30px 大胶囊卡片 |
| 间距 | 使用 8px 基础节奏，标题与正文优先于装饰留白 |
| 动态 | 约 180ms 的简单颜色/透明度反馈，不以大幅入场动画隐藏初始内容 |

删除首页重复英文 eyebrow、`Public`、`Type`、重复技术 tag、过时 `Updated 2026.08`、介绍同一方向的 Now/Capability 双重模块和无作用的“当前只收录…”等解释小字。页脚保留必要作者信息即可。空目录只需一句简短状态，不增加建设说明。

不能把“无多余小字”理解为隐藏必要按钮、访问名称、错误提示或笔记正文。正文元信息不新增发布时间、阅读分钟、篇数、关系图等仪表盘区域。

## 同步与来源行为

每次部署从确认的外部源同步。现有每小时计划任务和手动运行保留；本地与外部源均构建为同一个 Quartz 站点。同步失败应使工作流失败，不把半成品发布成正常站点。

外部源根目录挂载到 `machine-learning/`，其内部章节保持原相对路径。`README.md` 仅作为生成目录页的输入；若渲染需要 `index.md`，应在构建副本中派生，不能改写源仓库或删失资源。深层 README、图片、空格/中文/大小写路径、相对链接必须有代表性用例验证。

外部文章“编辑本文”和“新增笔记”指向外部源的真实文件/目录；本地文章指向本仓库 `knowledge/`。URL slug 不能反推原始文件名，应继续使用源文件相对路径。同步不引入 README 中整棵树的扁平列表到当前目录页。

## 独立验收标准

1. **页面职责**：首页没有笔记正文和完整树；根页仅显示一级目录；主题页与深层目录仅显示直属项；深层文章可直接打开、刷新、回到父目录。
2. **统一视觉**：首页、目录页、文章页的品牌、顶栏、控件、蓝色、主题、字体与边框一致；无旧英文 eyebrow/Public/Type 等文案残留；无双重标题或重复返回入口。
3. **悬浮避让**：1440px、1024px、768px、375px 窗口均检查顶栏初始和滚动状态；标题、代码、搜索和锚点定位不被顶栏遮挡。
4. **目录关闭**：桌面关闭/重开后正文宽度正常；375px 抽屉可通过按钮、遮罩、Escape 和文章选择关闭；关闭后背景可滚动、触发按钮可聚焦；跨断点无遗留遮罩/锁滚动。
5. **阅读完整性**：最长标题、较深目录、代码、表格、KaTeX 公式与图片不造成整页横向滚动；普通段落行长受控；短页不因空右栏留下明显不合理空白。
6. **既有能力**：搜索可打开、输入、选结果、关闭；主题从首页到知识页保持；两数之和代码折叠与演示继续工作；无运行时错误和损坏内链。
7. **原始树与内容**：本地笔记与外部同步文件的相对树及资源完整；当前层列表不扁平化后代；draft/unlisted 行为不回退；正文未被为排版而删改。
8. **自动同步**：推送/计划/手动三个入口使用同一同步过程；以外部章节、深层 Markdown、图片和特殊路径构建检查证明目录和来源链接正确。
9. **证据**：完整构建成功；相关自动测试与源码验证通过；保存上述代表视口的首页、目录、文章、窄屏抽屉与滚动截图。仅源码通过不能代替视觉验收。
