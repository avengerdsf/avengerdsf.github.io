## 设计要求核对

### 统一视觉与文案

首页与知识页均使用纯色背景、统一蓝色主动作、轻边框、白色或深色表面和同一控件节奏。实际计算样式确认正文与标题采用同一 Inter 和中文系统 fallback。旧 Public、Type、英文 eyebrow、篇数和阅读分钟等装饰文案已移除；正文技术内容未被当成文案噪声删除。深浅主题和跨页持久化正常。

### 页面职责与目录层次

首页呈现简短作者介绍、真实项目和知识入口。根目录仅显示两类真实一级笔记，主题目录显示直属子目录/文章，没有摊平后代。文章独立阅读，编辑和新增位于更多操作中。真实当前文章在目录树有选中态；页面标题与展开路径表达当前层次，不重复增加面包屑。

### 响应式与悬浮阅读

390px 的顶栏为单行，正文单栏；768px 工具栏与阅读区稳定；1024px 使用目录与正文两栏；1440/2048px 正文行长受控，目录和 TOC 不挤压正文。标题、初始位置和锚点避让有实际证据。代码、表格、公式和演示保留；最终报告内48个知识页响应式记录的整体横向溢出均为0。

目录页只有实际存在的内容时保留自然留白，没有为填满屏幕伪造笔记。关闭桌面目录后中心区域正常；手机抽屉按钮、遮罩、Escape、选择文章和跨断点关闭/恢复由正式浏览器回归覆盖，独立审计另复核了按钮焦点、背景恢复与深树滚动。

### 原始同步与来源

manifest 的唯一外部源为 `avengerdsf/machine-learning-notes`。外部源挂载到 `machine-learning/`，保留章节相对树、文件名和资源；README 与真实 index 共存，仅缺失目录首页时派生元数据。独立比较53个源文件（21篇Markdown）后，缺失或改变列表为空。

编辑/新增使用真实文件相对路径和源仓库映射，派生目录不会伪造编辑链接。每小时计划、推送和手动部署都调用同一个同步脚本。路径保护拒绝父路径、checkout重叠和真实祖先重定向；同步只重建 content，不清理源 checkout 或 Quartz 插件。Windows npm 已改为 Node npm-cli 参数调用；标题插件提供明确 prebuilt dist 入口，主智能体提供 fresh 隔离安装成功证据。

## 本轮纠正：目录与文章入口应统一为卡片

用户指出上轮“风格统一”的结论遗漏了相邻层入口结构差异。源码重新核对证实：目录入口使用网格卡片（四边1px边框、16px圆角、20px内边距、最小高度80px），文章入口仍是行列表（无四边边框和圆角、14px 8px内边距、最小高度56px）。上轮只核对颜色、字体、顶栏和页面职责，不应据此泛称全部入口风格一致。

原设计中“文章行只表达文章标题”现已纠正为“文章入口使用与目录相同卡片基础，只有folder/document图标语义不同”。此轮统一范围包括grid列数与gap、四边border、radius、background、padding、minHeight、内容排列、图标/箭头尺寸和位置、标题字体/字重/行高/颜色、hover与focus-visible，详见更新后的设计说明。两种入口不能继续维护各自独立的视觉规格。

本轮独立复核通过。已逐张读取最终390px/1440px的力扣题型、二分查找文章入口、哈希表“两数之和”入口和机器学习章节真实笔记入口八张截图，确认卡片结构一致。上一轮A1–A4证据继续保留；本轮通过依据为新的共享卡片实现、跨层计算样式比较和八张实际截图，不能沿用上一轮只检查颜色/字体的结论。


### 本轮关闭记录（A5）

A5/P2：目录与文章入口分用卡片和行列表。现已由两类共同使用 `kb-entry-list/link/icon/label/title/arrow`，不再有独立文章行视觉规则。标题采用已确认的共享650字重与1.5行高；两类hover共同使用accent边框和surface-muted背景，符合一致性要求。

独立读取的八张证据均在 `ui-checkpoints/card-unification/`：`folder-{390,1440}.png`、`topic-{390,1440}.png`、`nested-{390,1440}.png`、`synced-folder-{390,1440}.png`。它们分别覆盖题型目录、二分查找笔记、“两数之和”笔记与机器学习章节的多篇笔记。390px全部单列，1440px全部两列；卡片四边边框、圆角、背景、内边距、最小高度、标题、图标占位和箭头布局一致，唯一语义差异是folder/document的SVG路径。只含一篇笔记的页面仍占相同单个网格单元，没有恢复整行列表。

主智能体先在旧构建验证跨层计算样式断言确实失败（minHeight 56/72、border 0/1、radius 0/16、grid none/grid、标题字号和字重不同），再在新构建运行完整54个响应式用例与卡片比较，`ui-checkpoints/card-unification/report.json` 为 `unifiedEntryCards:true`。比较覆盖320/390/768/1024/1440/2048px，计算样式比较覆盖grid列数/gap、卡片形状/尺寸/背景与标题；图标、箭头与hover由共享样式规则和独立视觉检查核对。主智能体另通过用户实际浏览器tab刷新后二分目录确认同一白色圆角文档卡片可见，处理了SPA旧页面缓存影响。

A5状态：已关闭。本轮未修改笔记组织、源文件内容或文章阅读正文。独立审计没有新增未关闭的实质问题；设计说明与审计报告已按本轮实际共享规则同步纠正。

## 本轮纠正：公共控件的导航稳定性（A6）

上一轮只比较了页面加载完成后的截图与计算样式，没有覆盖目录到文章之间的导航帧。静态外观一致不足以证明公共工具在切换过程中稳定；这一点已加入设计验收。

### 根因与修复范围

A6/P2：旧CSS按有无TOC将`--kb-grid-width`设为1084/1288px，再由该值计算固定左栏起点。独立实际1440px导航中，力扣目录→哈希表→两数之和→上级的sidebar及“知识目录”标题x为178→178→76→178，横移102px。主智能体的旧rAF回归在进入两数之和的第3帧复现178→76并失败。

最终实现固定公共主体为左栏和正文两列、以同一公共壳起点定位。TOC改为独立固定区域，仅1368px及以上且有内容时显示；其存在与否不再重算左栏和正文位置。根文档`scrollbar-gutter:stable`固定滚动条占位，body `min-width:0`允许窄屏收缩。主动关闭目录仍可改变阅读布局；导航本身保持已选择的开关状态。

本轮只调整公共框架和尺寸规则，未修改Quartz SPA、Google Fonts或explorer的异步重建逻辑。实际生成的主要CSS链接原本已带data-persist，字体重挂与树清空区间在源码中存在，但本轮受测导航没有复现相关闪帧；不能表述为“字体问题已修复”。
