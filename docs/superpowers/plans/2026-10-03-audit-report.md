## 设计要求核对

### 统一视觉与文案

首页与知识页均使用纯色背景、统一蓝色主动作、轻边框、白色或深色表面和同一控件节奏。实际计算样式确认正文与标题采用同一 Inter 和中文系统 fallback。旧 Public、Type、英文 eyebrow、篇数和阅读分钟等装饰文案已移除；正文技术内容未被当成文案噪声删除。深浅主题和跨页持久化正常。

### 页面职责与目录层次

首页呈现简短作者介绍、真实项目和知识入口。根目录仅显示两类真实一级笔记，主题目录显示直属子目录/文章，没有摊平后代。文章独立阅读，编辑和新增位于更多操作中。真实当前文章在目录树有选中态；页面标题与展开路径表达当前层次，不重复增加面包屑。

### 响应式与悬浮阅读

390px 的顶栏为单行，正文单栏；768px 工具栏与阅读区稳定；1024px 使用目录与正文两栏；1440/2048px 正文行长受控，目录和 TOC 不挤压正文。标题、初始位置和锚点避让有实际证据。代码、表格、公式和演示保留；最终报告内48个知识页响应式记录的整体横向溢出均为0。

目录页只有实际存在的内容时保留自然留白，没有为填满屏幕伪造笔记。关闭桌面目录后中心区域正常；手机抽屉按钮、遮罩、Escape、选择文章和跨断点关闭/恢复由正式浏览器回归覆盖，独立审计另复核了按钮焦点、背景恢复与深树滚动。

### 原始同步与来源

manifest 的唯一外部源为 `avengerdsf/machine-learning-notes`。外部源挂载到 `machine-learning/`，保留章节相对树、文件名和资源；README 与真实 index 共存，仅缺失目录首页时派生元数据。独立比较53个源文件（21篇Markdown）后，缺失或改变列表为空。

编辑/新增使用真实文件相对路径和源仓库映射，派生目录不会伪造编辑链接。每小时计划、推送和手动部署都调用同一个同步脚本。路径保护拒绝父路径、checkout重叠和真实祖先重定向；同步只重建 content，不清理源 checkout 或 Quartz 插件。Windows npm 已改为 Node npm-cli 参数调用；标题插件提供明确 prebuilt dist 入口，主智能体提供 fresh 隔离安装成功证据。
